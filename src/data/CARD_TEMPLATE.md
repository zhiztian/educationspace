## 适用范围

- **讨论对象**：这个概念覆盖哪些数 / 哪些图形 / 哪些场景
- **不讨论 / 排除**：哪些对象不属于这个概念的领地（必须明示）
- **最容易误入的边界**：学生最常把谁错误地拉进来 / 错误地排除掉

## 精确定义

一句话给出最严谨的定义。引用课标 2022 措辞为佳。

## 多角度逼近

至少 3 个角度，从不同维度切入同一概念。**不是凑数**——每个角度要给一个具体例子或反例。

1. **数学定义角度**：……
2. **几何 / 数轴角度**：……
3. **生活类比角度**：（用比喻时必须收紧边界，避免误解）
4. **反例角度**：什么不是 X

## 必背（可选）

只有当某内容确实需要快速调用时才使用：100 以内质数、特殊角度、单位换算。

## 常见陷阱

| 错误说法 | 正确认识 |
|---------|---------|
| "X 是 Y" | ❌ 错。理由 |
| "凡是 A 都是 B" | ❌ 错。反例 |

## 与相邻概念关系

把这个概念放进概念地图。说清楚和兄弟节点的边界与包含关系：

```
父概念 = A ∪ B
本概念 ⊂ 父概念
本概念 ∩ 兄弟概念 = ∅
```

## 撰写规范

### 必须包含的 H2（按顺序）

1. **适用范围** —— 概念覆盖范围 + 排除项 + 边界（修复"骨架"的关键节）
2. **精确定义**
3. **多角度逼近**
4. **常见陷阱**
5. **与相邻概念关系**

### 可选 H2

- **必背** —— 仅当确实需要硬记时
- 该概念特有的子项（如 07 的「求法：短除法」、04 的「运算规律」）—— 放在「多角度逼近」和「常见陷阱」之间

### 抢答练习不写成 H2

抢答题统一放 frontmatter `quiz` 字段，触发例题模式。**至少 3 题**，建议覆盖：
- 至少 1 道**泽泽题**（直接判断 / 口答，难度 1–2）
- 至少 1 道**笑笑题**（边界 / 反例，难度 3）
- 至少 1 道**抢答题**（容易误判，难度 2–3）

### 不要

- ❌ 用「高频陷阱 / 抢答陷阱」等异名 —— 一律「常见陷阱」
- ❌ 用「关键 / 例题」等通用词 —— 用「必背」更具体
- ❌ 把抢答练习写成 H2
- ❌ 写大段引言；H1 = title 就够了，定义直接进 `## 精确定义`

### H2 是分页边界

每个 H2 = 专注模式投屏一页。
- 一页内容过长 → 分页器自动续切并加「（续）」
- **每页最多 5–7 行核心信息**；表格超过 8 行建议显式拆成两节
