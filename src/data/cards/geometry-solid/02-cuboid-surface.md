## 适用范围

- **讨论对象**：长方体 / 正方体
- **最容易误入的边界**：实际场景常缺面（无盖、通风管）；"表面积"和"体积"混用

## 精确定义

> ⭐ **表面积**：立体图形**所有面的面积之和**
> 单位：cm² / dm² / m²（**面积单位**，不是 cm³）

```
   长方体：6 个长方形面
   正方体：6 个正方形面
```

## 多角度逼近

1. **求和角度**：把 6 个面面积加起来
2. **公式角度**：S = 2(ab+ah+bh) 或 6a²
3. **展开角度**：展开成平面图后变成长方形面积问题
4. **生活角度**：包装纸、油漆面、瓷砖

## 公式

### 长方体

> ⭐ **S = 2 × (长×宽 + 长×高 + 宽×高)**
> 即 **S = 2(ab + ah + bh)**

推导：
- 上 + 下 = 2 × 长 × 宽
- 前 + 后 = 2 × 长 × 高
- 左 + 右 = 2 × 宽 × 高
- 合 = 2(ab + ah + bh)

### 正方体

> ⭐ **S = 6 × 棱长² = 6a²**

推导：6 个相同正方形

## 实际场景"缺面"问题

| 场景 | 面数 | 公式 |
|------|------|------|
| 完整长方体 | 6 面 | 2(ab+ah+bh) |
| 无盖（如水箱、鱼缸） | **5 面**（无上盖） | 完整 - 长×宽 |
| 通风管 / 烟囱（4 侧面） | **4 面**（无上下底） | 2ah + 2bh = 2h(a+b) |
| 抽屉（无前面） | 5 面（无前盖） | 完整 - 长×高 |
| 长椅围铁丝 | 棱长和 | 不是表面积，参 gs-01 |

> ⭐ **审题第一步：先数有几个面**

## 例题

### 例 1：完整长方体

长 = 8、宽 = 5、高 = 3 cm
S = 2(8×5 + 8×3 + 5×3)
   = 2(40 + 24 + 15)
   = 2 × 79
   = **158 cm²**

### 例 2：无盖水箱

长 50、宽 40、高 30 cm（开口向上无盖）
- 底：50 × 40 = 2000
- 前后：2 × 50 × 30 = 3000
- 左右：2 × 40 × 30 = 2400
- S = **7400 cm²**

### 例 3：通风管（4 侧面）

底面长 a、宽 b，高 h（无上下底）
S = 2ah + 2bh = 2h(a+b)

## 表面积 vs 体积（必须区分）

| 项目 | 表面积 | 体积 |
|------|-------|------|
| 是什么 | 外面所有面面积 | 占空间大小 |
| 单位 | cm² | cm³ |
| 公式 | 6a² 或 2(ab+ah+bh) | a³ 或 abh |
| 计算关键 | 加（6 面） | 乘（3 边） |

## 常见陷阱

| 错误 | 正确 |
|------|------|
| 长方体 S = abh | ❌ 错。abh 是**体积** |
| 表面积单位写 cm³ | ❌ 错。**cm²** |
| 无盖水箱也算 6 面 | ❌ 错。**5 面**（少一个上盖） |
| 通风管算 6 面 | ❌ 错。**4 面**（少上下底） |
| 正方体 6a 算表面积 | ❌ 错。**6a²**（要平方） |
| 长方体 2(a+b+h) | ❌ 错。那是棱长公式（×4 才对）|

## 与相邻概念关系

| 相邻概念 | 关系 |
|---------|------|
| 体积 | 单位 / 公式 / 含义都不同 |
| 各面（长方形/正方形） | 表面积 = 各面面积之和 |
| 包装 / 装修 | 油漆 / 包装纸 / 贴纸场景 |
| 圆柱表面积 | 类似思路（侧面 + 上下底） |
