## 适用范围

- **讨论对象**：圆锥形物体
- **最容易误入的边界**：体积忘 ÷ 3；高用斜高（母线）替代

## 精确定义

> ⭐ **圆锥**：1 个**圆**作底面 + 1 个**曲面**（侧面） + 1 个顶点
> 顶点到底面圆心的距离 = **高**（h）
> 顶点到底面圆边的距离 = **母线**（l，斜的）

```
          ●  ← 顶点（锥顶）
         /│\
        / │ \         母线 l（侧棱）
       /  │  \
      /   │ h \       高（垂直）
     /    │    \
    ╱─────●─────╲     底面：圆，半径 r
              r
```

## 多角度逼近

1. **结构角度**：1 圆底面 + 1 曲面侧 + 1 顶点 + 1 高
2. **展开角度**：侧面展开是**扇形**
3. **等积角度**：V圆锥 = (1/3) V等底等高圆柱
4. **生活角度**：圆锥沙堆、漏斗、冰激凌甜筒、铅笔芯

## 圆锥三要素

| 要素 | 数量 |
|------|------|
| 顶点 | **1** |
| 面 | **2**（1 底 + 1 侧）|
| 高 | **1**（注意区别于圆柱的"无数"）|
| 底 | 1 个圆 |
| 母线 | 无数条（顶点到底面圆周的所有线段） |

## 公式

| 量 | 公式 |
|----|------|
| 底面积 | S底 = πr² |
| 体积 | **V = (1/3) × πr² × h** |

> ⭐ **V圆锥 = (1/3) × V圆柱（等底等高时）**

## 重要：1/3 的来源

> 实验：把同底等高的圆锥装满水倒入圆柱，**正好 3 次倒满**

```
   圆柱 ←─ 圆锥（等底等高）
   ┌──┐    │\
   │  │    │ \
   │  │    │  \      装 3 次圆锥水 = 1 次圆柱水
   │  │    │   \     ⇒ V锥 = V柱 × 1/3
   │  │    └────●
   └──┘
```

## 圆柱 vs 圆锥（必背对比）

| 项目 | 圆柱 | 圆锥 |
|------|------|------|
| 顶点 | 0 | **1** |
| 面 | 3（2底+1侧） | **2**（1底+1侧）|
| 高 | 无数 | **1** |
| 侧面展开 | 长方形 | **扇形** |
| 体积 | πr²h | **(1/3)πr²h** |
| 同底等高时 | V柱 = 3 × V锥 | V锥 = (1/3) V柱 |

## 例题

### 例 1：常规体积

底面半径 = 3 cm，高 = 5 cm
V = (1/3) × 3.14 × 9 × 5 = **47.1 cm³**

### 例 2：圆柱削成最大圆锥

圆柱 V = 60 cm³ → 削成最大圆锥（等底等高） V锥 = 60 × 1/3 = **20 cm³**
削去部分 = 60 - 20 = 40 cm³

### 例 3：圆锥沙堆

底面周长 = 12.56 m → r = 12.56÷6.28 = 2 m，高 1.5 m
V = (1/3) × 3.14 × 4 × 1.5 = **6.28 m³**

## 常见陷阱

| 错误 | 正确 |
|------|------|
| V = πr²h（漏 1/3） | ❌ 错。圆锥要 **× 1/3** |
| 圆锥有 2 个底 | ❌ 错。只有 **1 个底**（顶点不是底） |
| 高 = 母线 | ❌ 错。**高是垂直**；母线是斜的 |
| 圆锥侧面展开是长方形 | ❌ 错。**扇形** |
| 圆柱削成圆锥 V = V柱 - 1/3 | ❌ 错。圆锥 = V柱 × 1/3，削去 = V柱 × 2/3 |
| 圆锥几条高 = 无数 | ❌ 错。**只有 1 条**（圆柱才无数）|

## 与相邻概念关系

| 相邻概念 | 关系 |
|---------|------|
| 圆柱 | 等底等高 → 体积 1:3 |
| 圆 | 底面是圆 |
| 扇形 | 圆锥侧面展开图 |
| 容器 | 漏斗 / 冰激凌甜筒 / 沙堆 |
| 比例 | V锥 / V柱 = 1/3 是固定比例 |
