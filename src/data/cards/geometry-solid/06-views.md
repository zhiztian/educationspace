## 适用范围

- **讨论对象**：立体图形从不同角度观察得到的平面图
- **最容易误入的边界**：左右视图反着画；圆柱立放和躺放视图弄错

## 精确定义

> ⭐ **三视图**：从**正面 / 上面 / 侧面**三个方向看到的物体形状

```
              ┌─正面视─┐    
              │       │
         ────┤  物体  ├─── 侧面视
              │       │
              └─俯视──┘
              (上方)
```

## 多角度逼近

1. **方向角度**：正 / 上 / 侧 三个互相垂直的方向
2. **画法角度**：每个方向"看到的轮廓"画成平面图
3. **还原角度**：根据三视图推回原立体形状（高阶）
4. **生活角度**：建筑设计图、家具组装图、零件图

## 常见物体的三视图

| 物体 | 正面视 | 侧面视 | 上面视 |
|------|-------|-------|-------|
| 正方体 | 正方形 | 正方形 | 正方形 |
| 长方体 | 长方形 | 长方形 | 长方形 |
| 圆柱（立放） | 长方形 | 长方形 | **圆**（外圆） |
| 圆柱（躺放） | 长方形 | 圆 | 长方形 |
| 圆锥（立放） | 等腰三角形 | 等腰三角形 | **圆 + 圆心点** |
| 球 | 圆 | 圆 | 圆 |
| 圆台 | 等腰梯形 | 等腰梯形 | 圆环 |

## 圆柱立放视图（详解）

```
      ╱──╲          长方形            长方形
     │ ●  │          │  │             │  │
      ╲──╱           │  │             │  │
                     │  │             │  │
       俯视          └──┘             └──┘
       (圆)         正面视             侧面视
```

## 多个小正方体拼图

> 给出 几个小正方体堆叠的图，要求画出三视图

例：2×2×1 砌块（4 个小正方体平铺一层）
- 正面：2 × 1 长方形
- 侧面：1 × 1 正方形
- 上面：2 × 2 正方形

## 视图还原立体（反推）

> 给三视图，反推原物体形状

- **关键**：上面视图告诉**底面布局**；正面 / 侧面视图告诉**层次高度**

例：正面 = ▣（1 个）、侧面 = ▣、上面 = ▣ → 1 个小正方体
例：正面 = ▣▣（2 个）、侧面 = ▣、上面 = ▣▣ → 2 个排成一行

## 视图与立体唯一性

> 一组三视图**未必能唯一**确定一个立体（小正方体堆叠尤其如此）

例：正面 = "L"型 + 侧面 = 长方形 → 可能多种摆法；要求最少几个、最多几个时要分情况

## 常见陷阱

| 错误 | 正确 |
|------|------|
| 圆柱躺放视图当立放 | 立放：正面长方形、上面圆 |
| 圆锥俯视当成三角形 | ❌ 错。**俯视是圆**（带顶点投影） |
| 球的视图分大小不同的圆 | ❌ 错。**完全相同的圆** |
| 长方体三视图都一样 | ❌ 错。**尺寸不同**（长×高 / 长×宽 / 宽×高）|
| 看不清"看到的"和"挡住的" | 看到的画实线；遮挡的画虚线（高年级） |
| 左视图 / 右视图无区别 | 一般"侧视图"指**左视**；左右对称物体两边一样 |

## 与相邻概念关系

| 相邻概念 | 关系 |
|---------|------|
| 长方体 / 正方体 / 圆柱 / 圆锥 / 球 | 各自有典型三视图 |
| 平面 / 立体 | 三视图是用平面"描述"立体 |
| 工程图 / 家具图 | 实际应用三视图设计 |
| 空间想象 | 视图 ↔ 立体相互转换是核心训练 |
