## 适用范围

- **讨论对象**：最基础的两种立体图形
- **最容易误入的边界**：把长方体当成"二维长方形"；忘了正方体是长方体特例

## 精确定义

> ⭐ **长方体**：6 个面都是**长方形**（含至多 2 对正方形）的立体图形
> ⭐ **正方体**：6 个面都是**正方形**的特殊长方体（长 = 宽 = 高）

```
       ┌──────────┐
      /│         /│
     / │        / │           长 a
    /  │       /  │           宽 b
   ┌──────────┐   │           高 h
   │   │      │   │
   │   └──────│───┘
   │  /       │  /
   │ /        │ /
   │/         │/
   └──────────┘
```

## 多角度逼近

1. **要素角度**：6 面 + 12 棱 + 8 顶点
2. **形状角度**：每面是长方形（正方体则是正方形）
3. **包含角度**：正方体 ⊂ 长方体
4. **生活角度**：纸盒、冰箱、骰子、墨水瓶外包装

## 长方体三要素

| 要素 | 数量 | 备注 |
|------|------|------|
| 面 | **6** | 相对的 2 面完全相同 |
| 棱 | **12** | 平行的 4 条棱长度相等；3 组 |
| 顶点 | **8** | 三棱相交处 |

> ⭐ **长方体相交于一顶点的 3 条棱 → 长、宽、高**

## 长方体 vs 正方体对比

| 项目 | 长方体 | 正方体 |
|------|-------|-------|
| 面 | 6 个长方形 | 6 个正方形 |
| 棱 | 3 组 × 4，每组等长 | 12 条全等长 |
| 顶点 | 8 | 8 |
| 长宽高 | 三者一般不等 | 三者相等（都叫**棱长** a）|

## 棱长之和

| 图形 | 公式 |
|------|------|
| 长方体 | (a + b + h) × 4 |
| 正方体 | a × 12 |

例：长 5、宽 4、高 3 的长方体棱长和 = (5+4+3)×4 = 48 cm

## 展开图

> ⭐ **长方体展开图**：6 个长方形（相对的 2 个完全相同）
> **正方体展开图**：6 个相同正方形，共有 **11 种**经典展开方式

```
   常见正方体展开图（"1-4-1 型"，最常见）：
     ┌──┐
     │  │
   ┌──┼──┼──┬──┐
   │  │  │  │  │
   └──┴──┴──┴──┘
     │  │
     └──┘
```

> 判断展开图能否折成正方体：6 块组合不超出"1-4-1 / 2-3-1 / 2-2-2 / 3-3"四类

## 常见陷阱

| 错误 | 正确 |
|------|------|
| "正方体不是长方体" | ❌ 错。正方体**是**特殊长方体 |
| 长方体 6 面都不一样 | ❌ 错。**相对面完全相同**（共 3 对） |
| 长方体只有 6 条棱 | ❌ 错。**12 条** |
| 长 + 宽 + 高 = 棱长和 | ❌ 错。要 ×4（每方向 4 条） |
| 正方体棱长和 = 6a | ❌ 错。**12a** |

## 与相邻概念关系

| 相邻概念 | 关系 |
|---------|------|
| 长方形 / 正方形 | 长方体 / 正方体的"面" |
| 表面积 | 6 个面面积之和 |
| 体积 | 长 × 宽 × 高 / a³ |
| 圆柱 / 圆锥 | 同为立体图形不同种类 |
| 包装 / 盒子 | 实际生活应用 |
