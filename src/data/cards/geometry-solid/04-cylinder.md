## 适用范围

- **讨论对象**：圆柱形物体
- **最容易误入的边界**：表面积漏掉某个底；侧面积公式记成 πr²h

## 精确定义

> ⭐ **圆柱**：上下两个**完全相同的圆**作底面，连接两圆的曲面作**侧面**

```
       ╱──────╲
      │   ●   │      ← 上底（圆）r
       ╲──────╱
       │      │      ← 侧面（曲面，展开是长方形）
       │ 高 h │
       │      │
       ╲──────╱
        ●           ← 下底（圆）r
```

## 多角度逼近

1. **结构角度**：3 个面（2 圆 + 1 曲面）
2. **展开角度**：侧面展开 = 长方形（长 = 底面周长 = 2πr，宽 = 高 h）
3. **柱体通用**：V = 底面积 × 高
4. **生活角度**：易拉罐、水管、纸杯、墨水瓶

## 圆柱组成

| 部分 | 数量 | 形状 |
|------|------|------|
| 底面 | 2 个 | 完全相同的**圆** |
| 侧面 | 1 个 | **曲面**（展开是长方形） |
| 高 | 多条（无数）| 两底面的距离（垂直距离） |

## 公式（必背）

| 量 | 公式 |
|----|------|
| 底面周长 | C = 2πr |
| 底面积 | S底 = πr² |
| 侧面积 | **S侧 = 2πr × h** = 底面周长 × 高 |
| 表面积 | **S表 = S侧 + 2 × S底 = 2πrh + 2πr²** |
| 体积 | **V = πr² × h** = 底面积 × 高 |

## 侧面展开图（核心理解）

> ⭐ **圆柱侧面 → 展开成长方形**
> 长方形的**长 = 圆柱底面周长 = 2πr**
> 长方形的**宽 = 圆柱的高 = h**

```
       展开
   ┌──────────────────┐
   │                  │   宽 = h
   │                  │
   └──────────────────┘
   ←—— 长 = 2πr ——→
```

> ⭐ **当 2πr = h 时，展开是正方形**

## 体积通用公式：V = 底面积 × 高

> 长方体、正方体、圆柱都满足 **V = 底面积 × 高**

| 立体 | 底面积 | 公式展开 |
|------|-------|---------|
| 长方体 | a × b | abh |
| 正方体 | a² | a³ |
| 圆柱 | πr² | πr²h |

## 例题

### 例 1：表面积 + 体积

底面半径 4 cm，高 10 cm
- S侧 = 2 × 3.14 × 4 × 10 = **251.2 cm²**
- S底 = 3.14 × 16 = 50.24 cm²
- S表 = 251.2 + 2 × 50.24 = **351.68 cm²**
- V = 3.14 × 16 × 10 = **502.4 cm³**

### 例 2：实际场景缺面

无盖水桶（去掉上底）：
S = S侧 + 1 × S底（只有下底）

通风管（去掉两底）：
S = S侧（只算曲面）

## 常见陷阱

| 错误 | 正确 |
|------|------|
| 圆柱有 2 个面 | ❌ 错。**3 个**（2 底 + 1 侧）|
| 侧面积 = πr²h | ❌ 错。πr²h 是**体积**；侧面积 = **2πr×h** |
| 表面积漏侧面 | 表面积 = 侧 + 2底（**3 部分**）|
| 表面积漏一个底（无盖） | 实际场景**先数有几个面** |
| 高错当成斜距 | 高是**两底之间的垂直距离** |
| V = 2πrh | ❌ 错。那是侧面积 |

## 与相邻概念关系

| 相邻概念 | 关系 |
|---------|------|
| 圆 | 底面是圆，公式都涉及 πr² / 2πr |
| 长方体 / 正方体 | 都满足 V = 底面积 × 高 |
| 圆锥 | 等底等高时 V锥 = V柱 × 1/3 |
| 长方形 | 圆柱侧面展开图 |
| 容器 | 水桶 / 罐头 / 油桶常见容积题 |
