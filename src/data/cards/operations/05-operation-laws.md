## 适用范围

- **讨论对象**：整数 / 小数 / 分数 的四则运算简便计算
- **不讨论 / 排除**：减法和除法**没有**自己的交换律 / 结合律
- **最容易误入的边界**：以为减法 / 除法也有交换律；分配律方向用反；带括号"减号 / 除号"时忘变号

## 精确定义（五大运算律）

| 运算律 | 字母表达 | 适用 |
|--------|---------|------|
| 加法交换律 | a + b = b + a | + |
| 加法结合律 | (a + b) + c = a + (b + c) | + |
| 乘法交换律 | a × b = b × a | × |
| 乘法结合律 | (a × b) × c = a × (b × c) | × |
| 乘法分配律 | (a + b) × c = a × c + b × c | × 与 +、− |

> ⭐ **关键**：**减法和除法没有自己的交换律 / 结合律**。简便时如要变换，借助加法 / 乘法律（如 a − b − c = a − (b + c)）

## 多角度逼近

1. **几何角度**：分配律 = 大长方形面积 = 两小长方形面积之和
   ```
   ┌────┬──┐
   │ a×c│b×c│   (a+b) × c = a×c + b×c
   └────┴──┘
        c
   ```
2. **生活角度**：3 个 5 元 + 7 个 5 元 = (3+7) 个 5 元（提取相同因数）
3. **凑整角度**：25 × 4 = 100、125 × 8 = 1000、5 × 2 = 10 → 用交换 + 结合凑出来
4. **反向角度**：分配律可正用（拆开）也可反用（合并提公因数）

## 简便计算"对子"（必背）

| 对子 | 积 |
|------|----|
| 2 × 5 | 10 |
| 4 × 25 | 100 |
| 8 × 125 | 1000 |
| 25 × 4 | 100 |
| 25 × 8 | 200（= 4×25×2） |

## 典型简便套路

### 凑整（交换 + 结合）

`25 × 17 × 4 = 25 × 4 × 17 = 100 × 17 = 1700`

### 拆数 + 分配律

`99 × 26 = (100 − 1) × 26 = 2600 − 26 = 2574`
`102 × 35 = (100 + 2) × 35 = 3500 + 70 = 3570`

### 反向分配律（提公因数）

`35 × 8 + 35 × 2 = 35 × (8 + 2) = 350`
`102 × 38 − 2 × 38 = (102 − 2) × 38 = 3800`

### 减法的"配对"

`378 − 47 − 53 = 378 − (47 + 53) = 378 − 100 = 278`（注意 47 + 53 = 100）

### 除法的"配对"

`800 ÷ 25 ÷ 4 = 800 ÷ (25 × 4) = 800 ÷ 100 = 8`

## 常见陷阱

| 错误 | 正确 |
|------|------|
| "5 − 3 = 3 − 5" | ❌ 减法**没有**交换律 |
| "12 ÷ 3 = 3 ÷ 12" | ❌ 除法**没有**交换律 |
| `378 − 47 − 53 = 378 − (47 − 53)` | ❌ 错。减号后加括号 → 内部要变号；正确是 `378 − (47 + 53)` |
| `(a + b) × c = a × c + b`（漏乘） | ❌ 分配律的精髓是**每一项都要乘** |
| `99 × 26 = 100 × 26 − 1` | ❌ 漏乘。应是 `100 × 26 − 1 × 26` |
| 反用分配律时找不到公因数 | 看每一项里**共同的乘数** |

## 与相邻概念关系

| 相邻概念 | 关系 |
|---------|------|
| 运算顺序 | 律可以**改变**顺序，但要保证结果不变 |
| 简便计算 | 律是简便的"工具箱" |
| 字母表示数 | 用 a、b、c 表达普遍规律 |
| 方程 | 解方程时用律化简两边 |
| 几何 | 长方形面积是分配律的几何模型 |
