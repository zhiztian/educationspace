## 适用范围

- **讨论对象**：整数乘法（小数乘法见 dp-05，分数乘法见 fr-08）
- **最容易误入的边界**：竖式第二行对位错；末尾 0 漏处理；表内乘法不熟拖慢中高年级所有计算

## 精确定义

**乘法**：求几个相同加数的和的简便运算。`因数 × 因数 = 积`

```
3 × 4 = 3 + 3 + 3 + 3 = 12
        └─ 4 个 3 相加
```

> ⭐ **必背**：九九乘法表（2~9）—— 中年级以上的所有计算都建立在这上面

## 多角度逼近

1. **相同加数连加**：3 × 4 = 4 个 3 相加
2. **几何角度**：3 × 4 = 长 3、宽 4 的长方形面积（也是后面长方形面积公式的根）
3. **倍数角度**：3 × 4 表示"3 的 4 倍"
4. **数轴角度**：每次跳 3 格，跳 4 次

## 整十 / 整百乘法（末尾 0 处理）

```
23 × 30 = 23 × 3 × 10 = 69 × 10 = 690     ← 末尾添 1 个 0
40 × 50 = 4 × 5 × 100 = 20 × 100 = 2000   ← 末尾共添 2 个 0；注意 4×5=20 自带 1 个 0，总共 3 个 0
```

## 两位数乘两位数竖式

例：`23 × 45`

```
        2  3
     ×  4  5
     ────────
     1  1  5      ← 23 × 5（个位）
  9  2  0         ← 23 × 4（十位，要左移一位 / 末位对齐十位）
     ────────
  1  0  3  5
```

> 💡 **对位口诀**：
> 第二行（乘十位的结果）的**最后一位**要写在**十位**上 —— 等价于"末尾空一位"

## 三位数乘两位数

```
       2  4  5
    ×     1  2
    ─────────
       4  9  0      ← 245 × 2
    2  4  5         ← 245 × 1（左移一位）
    ─────────
    2  9  4  0
```

## 估积（看位数）

| 因数 | 积 |
|------|---|
| 三位 × 一位 | 三位 或 四位 |
| 三位 × 两位 | 四位 或 五位 |
| 四位 × 两位 | 五位 或 六位 |

> 看最高位相乘是否 ≥ 10 → 大于则多一位

## 常见陷阱

| 错误 | 正确 |
|------|------|
| 第二行个位对齐第一行个位 | ❌ 错。乘十位的结果要左移一位（与十位对齐） |
| 23 × 30 = 23 × 3 写成 69 | ❌ 漏末尾 0。应是 690 |
| "0 × 0 = 0 + 0 = 0" 套相加理解 | 0 × 任何 = 0 直接记，不要硬套连加（0 个 0 相加） |
| 进位忘加 | 乘出来的进位要加到下一步的乘积上 |
| 乘除混合时被加减号"骗" | 乘除优先 —— 见 op-04 |

## 与相邻概念关系

| 相邻概念 | 关系 |
|---------|------|
| 加法 | 乘法 = 相同加数的连加；加法是基础 |
| 除法 | 互为逆运算（a × b = c ⇔ c ÷ a = b ⇔ c ÷ b = a） |
| 因数 / 倍数 | 因数 × 因数 = 积；积是因数的倍数 |
| 长方形面积 | 长 × 宽 = 面积，是乘法的几何模型 |
| 运算律 | 乘法满足交换、结合、分配律 |
| 运算顺序 | 与加减混合时优先；与除法同级 |
