## 适用范围

- **讨论对象**：自然数、整数、（高年级）小数 / 分数 的加减
- **不讨论 / 排除**：本卡只讲整数加减法的概念与竖式（小数加减见 dp-04，分数加减见 fr-07）
- **最容易误入的边界**：连续退位忘借；进位漏写；混淆"被减数 / 减数 / 差"

## 精确定义

- **加法**：把两个或多个数**合并**成一个数的运算。`加数 + 加数 = 和`
- **减法**：已知两个数的和与其中一个加数，求**另一个加数**的运算。`被减数 − 减数 = 差`
- **加法和减法互为逆运算**：A + B = C ⇔ C − B = A ⇔ C − A = B

## 多角度逼近

1. **合并 / 分开**：加法 = 合起来；减法 = 拿走 / 比较多少
2. **数轴角度**：加法向右走；减法向左走
3. **逆运算角度**：减法本质是"已知和与一个加数，求另一个加数"
4. **生活场景**：买东西付钱（加）、找零（减）、温度变化、楼层升降

## 竖式要点

| 操作 | 关键 |
|------|------|
| 加法竖式 | 数位对齐（个位对个位）；满十进一；进位标在前一位上方 |
| 减法竖式 | 数位对齐；不够减向前一位借 1（借的是 10）；连续退位时一格一格往前借 |

例：`1000 − 367`

```
   0 9 9 10
   1 0 0 0     ← 个位 0 减 7 不够，向十位借；十位 0 也是 0 → 再向百位借
 −   3 6 7      百位 0 → 千位借 1，千位 1 → 0
 ───────
     6 3 3
```

## 验算方法

| 原算式 | 验算 |
|--------|------|
| `加数 + 加数 = 和` | 用 `和 − 一个加数 = 另一个加数` |
| `被减数 − 减数 = 差` | 用 `差 + 减数 = 被减数`（首选）；或 `被减数 − 差 = 减数` |

## 常见陷阱

| 错误 | 正确 |
|------|------|
| "加法验算就是再算一遍" | ⚠️ 不严格。**用减法验算更可靠**（同一个错可能算两次） |
| 连续退位忘借（1000 − 367 算成 743） | 借位要一格一格往前；一旦借了，那一位减 1 |
| 进位漏写 / 加错位 | 进位"1"写在前一位上方，下一步加上 |
| "0 是减法的最小结果" | ❌ 错。整数范围内可以负（5 − 8 = −3），小学一般限制被减数 ≥ 减数 |
| 把"差"理解成"两数相减取绝对值" | 严格地 **差 = 被减数 − 减数**，是有方向的（小学先按大减小） |

## 与相邻概念关系

| 相邻概念 | 关系 |
|---------|------|
| 乘法 | 乘法 = 相同加数的简便加法（3 + 3 + 3 + 3 = 3 × 4） |
| 减法 ↔ 加法 | 互为逆运算 |
| 运算顺序 | 同级运算从左往右；与乘除混合时**乘除优先** |
| 运算律 | 加法满足交换律、结合律；减法**不满足**（5 − 3 ≠ 3 − 5） |
| 估算 | 加减估算把每个数看成最接近的整十 / 整百 |
