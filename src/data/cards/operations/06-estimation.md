## 适用范围

- **讨论对象**：四则运算的"大致结果"判断
- **不讨论 / 排除**：要求精确解的题不能只估
- **最容易误入的边界**：把估算当成"精算"；估完不会判断偏大偏小

## 精确定义

**估算**：把数**化为接近的整十、整百、整千**（或便于心算的数），快速求出**近似结果**的方法。

> ⭐ 估算结果用 **≈**（约等于），不用 =

## 多角度逼近

1. **四舍五入角度**：≤ 4 看小，≥ 5 看大
2. **生活角度**：菜场算钱、超市估总价、看时间够不够
3. **验算角度**：精算后用估算判断"答案是否合理"
4. **数据规模角度**：解决"几位数"问题

## 各运算的估算策略

| 运算 | 策略 | 例子 |
|------|------|------|
| 加法 | 各加数四舍五入到最接近的整十 / 整百 | 297 + 503 ≈ 300 + 500 = 800 |
| 减法 | 同上 | 813 − 198 ≈ 800 − 200 = 600 |
| 乘法 | 因数都四舍五入到整十 / 整百 | 53 × 28 ≈ 50 × 30 = 1500 |
| 除法 | 被除数和除数都化为整十 / 整百 | 387 ÷ 19 ≈ 400 ÷ 20 = 20 |

## 估算偏大 / 偏小的判断

| 因数变化 | 结果 |
|---------|------|
| 因数都变小 | 估算结果**偏小** |
| 因数都变大 | 估算结果**偏大** |
| 一大一小 | 看哪个变化更显著（高年级） |
| 加数变大 / 变小 | 与因数同理 |
| 除法：被除数变大 或 除数变小 | 商**偏大** |
| 除法：被除数变小 或 除数变大 | 商**偏小** |

## 估算的实用场景

### 判断答案合理性

`23 × 45 = ?` 学生算成 1035 vs 105 → 估 20 × 50 = 1000，1035 ≈ 1000 ✓，105 远不对 ✗

### 判断结果范围

200 元买 30 元 / 件的本子，**够买几本**？ → 200 ÷ 30 ≈ 6.x → **能买 6 本**（带余除法）

### 比较大小

`297 × 41` 和 `298 × 39` 哪个大？两个都约 12000，需要精算（或更精细估算）

## 常见陷阱

| 错误 | 正确 |
|------|------|
| 估算用 = 写 | ❌ 错。估算用 **≈** |
| 估完忘了**判断偏大偏小** | 高年级题目常问这个 |
| 把因数估到差距很大的数（53 → 100） | 应**就近**整十（53 → 50） |
| "估算 = 不精确不重要" | 估算是**速判 + 验算**的关键工具 |
| 除法估错方向（如 387÷19 看成 300÷20） | 接近 387 的整百是 400 不是 300 |

## 与相邻概念关系

| 相邻概念 | 关系 |
|---------|------|
| 精算 | 估算 ≠ 精算；估算用于检验精算 |
| 四舍五入 | 是估算的核心方法 |
| 应用题 | "够不够 / 至少 / 至多" 类题目常用估算 |
| 试商 | 试商本质是除法估算 |
| 大小比较 | 数据量大时先估再比 |
