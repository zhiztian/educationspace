## 适用范围

- **讨论对象**：完成某项工作 / 任务 / 加工的问题
- **最容易误入的边界**：忘把"总量设 1"；时间和工效搞反

## 精确定义

> ⭐ **工程问题三量**：工作总量、工作效率（每单位时间完成的份额）、工作时间
> **基本公式**：工作总量 = 工效 × 时间

## 多角度逼近

1. **率的角度**：把总量当 1，工效 = 1/天数
2. **方程角度**：合作时间 t，列 (v_甲 + v_乙) × t = 1
3. **生活角度**：水管注水 / 印刷 / 加工件
4. **比的角度**：工效比 = 时间比的反比

## 核心套路："总量设为 1"

> ⭐ 把总工作量看作"**1**"（单位 1，无单位）
> 工效 = 1 ÷ 单独完成的天数

| 单独完成天数 | 工效（每天做） |
|------|------|
| 甲 6 天 | 1/6 |
| 乙 12 天 | 1/12 |
| 合作 t 天 | 工效 = 1/6 + 1/12 |

## 经典题型

### 1. 合作时间

> 甲单独 6 天，乙单独 12 天，合作几天完成？

```
甲工效 = 1/6
乙工效 = 1/12
合工效 = 1/6 + 1/12 = 2/12 + 1/12 = 3/12 = 1/4

合作时间 = 1 ÷ 1/4 = 4 天
```

### 2. 求单独工效（已知合作）

> 甲乙合作 6 小时完成，甲单独 10 小时；乙单独几小时？

```
合工效 = 1/6
甲工效 = 1/10
乙工效 = 1/6 - 1/10
       = 5/30 - 3/30 = 2/30 = 1/15

乙单独 = 1 ÷ 1/15 = 15 小时
```

### 3. 部分合作 + 单独完成

> 甲乙合作 2 天后甲离开，乙单独再做 4 天完成；甲单独 8 天完成；求乙单独？

```
设乙工效 = x
合作 2 天完成 = 2(1/8 + x) = 1/4 + 2x
乙单独再 4 天完成 = 4x
合计 = 1：
   1/4 + 2x + 4x = 1
   6x = 3/4
   x = 1/8
   
乙单独 = 1 ÷ 1/8 = 8 天
```

### 4. 部分完成型

> 甲做 4 天剩 1/3，求甲单独完成需几天？

```
4 天完成 = 1 - 1/3 = 2/3
1 天完成 = 2/3 ÷ 4 = 1/6
全部完成 = 1 ÷ 1/6 = 6 天
```

## 注水排水（特殊型）

> 进水管 = 正工效；排水管 = 负工效

例：进水管 5 小时注满，排水管 8 小时排空。同时打开几小时注满？

```
进 = 1/5；排 = 1/8
净注 = 1/5 - 1/8 = 8/40 - 5/40 = 3/40
注满 = 1 ÷ 3/40 = 40/3 ≈ 13.33 小时
```

> ⚠️ 若进 < 排 → **永远注不满**

## 多人协作（≥3）

> 仍然"工效相加"

例：甲单独 4 天，乙单独 6 天，丙单独 12 天，三人合作几天完成？

```
合工效 = 1/4 + 1/6 + 1/12
       = 3/12 + 2/12 + 1/12 = 6/12 = 1/2
合作时间 = 1 ÷ 1/2 = 2 天
```

## 工效比 vs 时间比（高级）

> ⭐ **工效比 = 时间比的反比**

| 甲时间 | 乙时间 | 工效比 |
|------|------|------|
| 6 天 | 12 天 | 12 : 6 = 2 : 1 |
| 4 小时 | 5 小时 | 5 : 4 |

## 一般公式

```
   合作时间 t = 1 ÷ (1/t_甲 + 1/t_乙)
            = (t_甲 × t_乙) / (t_甲 + t_乙)   ← 两人时常用
```

例：甲 6，乙 12 → t = (6×12)/(6+12) = 72/18 = **4** ✓

## 常见陷阱

| 错误 | 正确 |
|------|------|
| 直接把天数相加 / 平均 | ❌ 错。要算工效相加 |
| 不设总量为 1 | 必须**设 1**才能用率思想 |
| 合作时间 = (6+12)/2 = 9 | ❌ 错。合作快于任何一个 |
| 排水当成"减时间" | 排水是**减工效**（注负数） |
| 工效比和时间比同向 | 工效比 = 时间比**反比** |
| 两人合作但只算一人工效 | 必须**相加**两人工效 |

| 相邻概念 | 关系 |

| 行程问题 | 结构相同（速度↔工效，时间↔时间，路程↔总量）|
