## 适用范围

- **讨论对象**：含多步推理 / 逆推 / 分配 / 植树等综合题型
- **最容易误入的边界**：还原方向反；盈亏公式记错；植树边界算错

## 精确定义

> 综合多步应用题：**需要 2 步以上 / 涉及多个关系**的应用题
> 包括：**还原、盈亏、植树、过桥、年龄**等

## 多角度逼近

1. **逆推角度**：还原问题
2. **方程角度**：盈亏 / 年龄通用
3. **段数角度**：植树 / 锯木 / 上楼
4. **画图角度**：均能借助图

## 类型 1：还原问题（逆推）

> ⭐ **逆推法**：已知最终结果，按相反运算倒推

| 正向 | 逆向 |
|------|------|
| + a | - a |
| - a | + a |
| × a | ÷ a |
| ÷ a | × a |

例：一个数 → +5 → ÷2 → ×3 → -7 = 11，求原数？

```
正向：原 → +5 → ÷2 → ×3 → -7 = 11
逆向（倒读）：11 → +7 → ÷3 → ×2 → -5 = 原

11 + 7 = 18
18 ÷ 3 = 6
6 × 2 = 12
12 - 5 = 7

原数 = 7
验证：7+5=12 ÷2=6 ×3=18 -7=11 ✓
```

## 类型 2：盈亏问题

> ⭐ **(盈 + 亏) ÷ 两次分配差 = 人数**

例：分糖每人 5 颗多 8 颗（盈），每人 7 颗少 4 颗（亏）

```
人数 = (8 + 4) ÷ (7 - 5) = 12 ÷ 2 = 6 人
糖数 = 5 × 6 + 8 = 38 颗
（验证：7 × 6 - 4 = 38 ✓）
```

### 全是盈

> 多 X、多 Y（X > Y）：**(X - Y) ÷ 差**

例：每人 4 颗多 12，每人 6 颗多 2

```
人数 = (12 - 2) ÷ (6 - 4) = 5 人
糖 = 4×5+12 = 32（验证 6×5+2 = 32 ✓）
```

### 全是亏

> 少 X、少 Y（X > Y）：**(X - Y) ÷ 差**

> 公式总结：**绝对差 ÷ 分配差 = 人数**

## 类型 3：植树问题

> ⭐ 关键看**两端是否栽**

| 类型 | 棵数 |
|------|------|
| 两端都栽（线段）| 段 + 1 |
| 只栽一端 | 段 |
| 两端不栽 | 段 - 1 |
| 围圈（封闭）| 棵 = 段（首尾重合）|

### 例 1：两端栽

> 100 米路，每 5 米一棵，两端栽
- 段 = 100/5 = 20
- 棵 = 20+1 = **21**

### 例 2：圆形

> 周长 100，每 5 米栽，圆形（封闭）
- 段 = 100/5 = 20
- 棵 = **20**

### 例 3：锯木（类似）

> 锯一根木 4 段，几次？
- **3 次**（n 段 = n-1 次）

### 例 4：上楼

> 1 层到 4 层，几层楼梯？
- 4 - 1 = **3 段**

## 类型 4：年龄问题

> ⭐ **关键**：年龄差**永远不变**

例：父今年 36，子 8；几年后父是子 3 倍？

```
设几年后 = x
则：(36+x) = 3(8+x)
36+x = 24+3x
12 = 2x
x = 6 年
```

例：父子年龄和 56；2 年前父是子 3 倍。父子今年各几岁？

```
设 2 年前子 = x，父 = 3x；和 = 4x
2 年前和 = 56-2-2 = 52
4x = 52 → x = 13
2 年前子 13、父 39 → 今年子 15、父 41
```

## 类型 5：过桥 / 火车

> ⭐ **总路程 = 桥长 + 车长**

例：火车长 200 m，过 800 m 大桥用 50 秒，速度？
- 总路 = 800 + 200 = 1000
- 速度 = 1000 / 50 = **20 m/s**

> 火车过隧道 / 完全过 / 完全在桥上 → 路程不同！

## 类型 6：周期问题

> ⭐ 找**周期** → 用除法看**余数**对应位置

例：今天星期一，1000 天后是星期几？

```
1000 ÷ 7 = 142 余 6
星期一 + 6 = 星期日
```

## 类型 7：抽屉原理（鸽巢原理 / 高级）

> N 个物体放 K 个抽屉，至少有 ⌈N/K⌉ 个物体在同一抽屉

例：10 双袜子（10 红 10 蓝），至少摸几只保证有同色？
- 最坏 = 一只红 + 一只蓝 = 2
- 第 3 只必同色 → 答 **3 只**

## 解综合题的总策略

```
1. 先识别题型（还原 / 盈亏 / 植树 / ...）
2. 套对应公式 / 思想
3. 复杂题 → 转方程 / 画图
4. 检验：代回 / 算 2 种解法对比
```

## 常见陷阱

| 错误 | 正确 |
|------|------|
| 还原忘倒序 | 必须从结果开始**倒读** |
| 还原每步用同一运算 | 必须**取反**运算 |
| 盈亏公式记成"盈 - 亏" | (盈+亏) 或 (大亏-小亏) |
| 植树两端栽用"段=棵" | 棵 = 段+1 |
| 年龄"差"也变 | ❌ 错。年龄差**不变** |
| 火车过桥忽略车长 | 总路 = 桥长 + 车长 |
| 周期问题不取余数 | 必须看余数对应位置 |
