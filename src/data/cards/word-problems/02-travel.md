## 适用范围

- **讨论对象**：和"行驶"相关的问题
- **最容易误入的边界**：相遇 / 追及公式混；流水问题方向反

## 精确定义

> ⭐ **行程三量**：路程（s）、速度（v）、时间（t）
> **基本公式**：s = v × t

## 多角度逼近

1. **公式角度**：基本三式 + 相遇 / 追及 / 流水变形
2. **画图角度**：箭头标方向 + 已知量
3. **同向 / 相向 / 流水**：核心区别在"速度合"
4. **生活角度**：上下学路上、火车相遇、轮船过河

## 三大典型问题

### 1. 相遇问题（相向而行）

> ⭐ **相遇路程 = 速度和 × 相遇时间**

```
   ●───→        ←───●
   A 走         B 走
   <───── 总路程 ─────>

   v_合 = v_A + v_B
   t_相遇 = 总路程 / v_合
```

例：AB 距 200 km，甲 60 km/h，乙 40 km/h 相向出发
→ 速度和 = 100 km/h
→ 相遇时间 = 200 ÷ 100 = **2 小时**
→ 甲走 = 60×2 = 120；乙走 = 40×2 = 80（合 200 ✓）

### 2. 追及问题（同向，快追慢）

> ⭐ **追及距离 = 速度差 × 追及时间**

```
   ●───→  ●───→
   B（后） A（前）
   <─初差─>

   v_差 = v_后 - v_前 （后必须比前快）
   t_追 = 初差 / v_差
```

例：A 在前 40 km/h，B 在后 60 km/h，相距 20 km
→ 速度差 = 20 km/h
→ 追及时间 = 20 ÷ 20 = **1 小时**

> ⚠️ 后面慢于前面 → **永远追不上**

### 3. 流水问题（船在水中）

> 静水速 = 船在静水中的速度
> 水流速 = 河水的流速

> ⭐ **顺水速 = 静水 + 水流**
> ⭐ **逆水速 = 静水 - 水流**

| 已知 | 求 |
|------|------|
| 顺、逆水速 | 静水 = (顺+逆)/2；水流 = (顺-逆)/2 |
| 静水、水流 | 顺水 = 静+流；逆水 = 静-流 |

例：船顺水 30 km/h，逆水 18 km/h
- 静水 = (30+18)/2 = **24 km/h**
- 水流 = (30-18)/2 = **6 km/h**

## 关键判断：相向 / 相对 / 同向 / 背向

| 类型 | 速度合 / 差 | 相对位置 |
|------|------|------|
| 相向（迎面）| 速度**和** | 缩短 → 相遇 |
| 同向（追及）| 速度**差** | 后追前 |
| 背向（背离）| 速度**和** | 拉远 |

## 综合题：分段行程

> 全程不同段速度不同 → **分段算时间或路程**，再合

例：A 到 B 共 60 km，前 30 km 走 1 小时，后 30 km 走 0.5 小时
- 平均速度 ≠ (60+30) ÷ 2
- 平均速度 = **总路程 / 总时间** = 60 ÷ 1.5 = **40 km/h**

> ⭐ 平均速度 = **总路程 ÷ 总时间**（不是速度的平均）

## 例题汇总

### 例 1：求相遇地点

A 60 km/h B 40 km/h 相向，相距 200 km；问相遇时距 A 多远？
- 相遇时间 = 2 h
- A 走了 = 60×2 = **120 km** ← 答

### 例 2：火车过桥

火车长 200 m，过 800 m 大桥用 50 秒，火车速度？
- 总路程 = 桥长 + 车长 = 800 + 200 = **1000 m**
- 速度 = 1000 ÷ 50 = **20 m/s** = 72 km/h

### 例 3：顺逆水时间

船顺水 60 km 用 4 小时，逆水 60 km 用 6 小时，求水流速？
- 顺水 = 60 ÷ 4 = 15 km/h
- 逆水 = 60 ÷ 6 = 10 km/h
- 水流 = (15 - 10) / 2 = **2.5 km/h**

## 常见陷阱

| 错误 | 正确 |
|------|------|
| 相遇用速度差 | ❌ 错。相向用**速度和** |
| 追及用速度和 | ❌ 错。同向追用**速度差** |
| 后慢于前还能追上 | ❌ 错。永远追不上 |
| 顺水速 = 静水（无水流） | 必须是**静+流** |
| 平均速度 = (速度1+速度2)/2 | ❌ 错。是**总路程/总时间** |
| 火车过桥忽略车长 | 总路程 = 桥长 + 车长 |
| 单位不统一直接算 | km/h 和分钟必须先换算 |

## 与相邻概念关系

| 相邻概念 | 关系 |
|---------|------|
| 速度 / 时间单位 | 一定要单位统一 |
| 比例（路程 = 速度 × 时间）| 速度定 → 正比例 |
| 应用题策略 | 画图找等量关系最有效 |
| 工程问题 | 结构类似（"工效"对应"速度"）|
| 火车 / 船 / 飞机 | 实际场景 |
