## 适用范围

- **讨论对象**：所有应用题
- **最容易误入的边界**：见数就算，不分析关系；漏掉关键词

## 精确定义

> ⭐ **应用题**：用数学方法解决实际生活中的问题
> 关键技能：把**文字描述 → 数学模型**

## 多角度逼近

1. **审题角度**：圈关键词
2. **分析角度**：找数量关系
3. **建模角度**：算式 / 方程 / 图
4. **验证角度**：合理性检验

## 通用 4 步法

```
1. 审题   ：圈出已知 / 未知 / 关键词 / 单位
2. 分析   ：找出数量关系（等量关系或运算关系）
3. 列式   ：算术法（直接写式子）或方程法（设 x）
4. 检验   ：代回 + 合理性 + 写"答："
```

## 关键词 → 运算对照

| 词 | 提示运算 |
|----|---------|
| 一共 / 总共 | 加 |
| 剩 / 用去 / 比…多/少 | 减 |
| …的 N 倍 / 平均一组 N | 乘 / 除 |
| 平均每…多少 | 除 |
| …比…多几 | 减 |
| …是…的几倍 | 除 |
| …是…的几分之几 | 除（分数） |
| 增加几% / 多几% | 乘（含百分数） |

## 算术法 vs 方程法

| 对比 | 算术法 | 方程法 |
|------|-------|-------|
| 思路 | 顺向（已知→未知）| 设未知数→列等式 |
| 难度 | 难度大时，要倒推 | 直接翻译题意 |
| 适合 | 简单 / 直接关系 | 复杂、含两未知 |
| 形式 | 直接列式 | 设 x → 列方程 |

> ⭐ **小技巧**：直接列式难时，用方程法

## 画图 / 线段图（强力工具）

> ⭐ 把抽象的数量关系**画出来**：和差 / 倍比 / 分数题尤其有用

### 例：和差线段图

> 甲乙共 60，甲比乙多 8，求各几

```
   乙：├─────────┤
       甲：├─────────┼──+8──┤
           ↑                ↑
           乙               甲
   
   甲+乙 = 60
   甲 - 乙 = 8
   → 甲 = (60+8)/2 = 34
   → 乙 = (60-8)/2 = 26
```

### 例：倍数线段图

> 甲是乙的 3 倍，共 60

```
   乙：├──┤
   甲：├──┼──┼──┤
   合 = 4 段 = 60
   1 段 = 15
   → 乙 = 15，甲 = 45
```

## 检验合理性

| 维度 | 例 |
|------|------|
| 数学正确 | 代回原题验证 |
| 数量合理 | 人 / 件数不能负 / 不能小数 |
| 范围合理 | 速度不能 1000 km/h（步行） |
| 单位 | 答的单位要对 |

例：求人数得 12.5 → ❌ 不合理，重算

## 多余条件 / 隐藏条件

| 类型 | 应对 |
|------|------|
| 多余条件 | 只用与问题相关的 |
| 隐藏条件 | 推理 / 常识补出 |
| 单位不一致 | **先换算统一**再算 |

例（隐藏）：一辆汽车每小时行 60 km，从 A 到 B 用 4 小时，求路程
- 隐藏：路程 = 速度 × 时间（公式）
- 答：60 × 4 = 240 km

## 写答规范

> ⭐ 必须写完整的"答：…"句子

| 错 | 对 |
|----|-----|
| 答：12 | 答：每天看 12 页 |
| 答：100 | 答：一共有 100 个 |

## 常见陷阱

| 错误 | 正确 |
|------|------|
| 不审题直接算 | 必须先审题 |
| 关键词漏掉 | 圈出"一共/还剩/比…多" |
| 单位不一致 | 必须**先换算** |
| 答案不写"答" | 必须写完整答 |
| 答案不合理（人 -3）不重算 | 必须重新核对 |
| 多余条件硬要用 | 仅用相关条件 |

## 与相邻概念关系

| 相邻概念 | 关系 |
|---------|------|
| 各运算 | 应用题用四则运算 |
| 方程 | 复杂题用方程法 |
| 图形 / 测量 | 部分应用题涉及周长面积体积 |
| 比例 / 百分数 | 高年级常见类型 |
| 各专题（行程/工程/购物等） | 通用策略覆盖 |
