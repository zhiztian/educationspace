## 适用范围

- **讨论对象**：折扣、利息、纳税、利润等经济应用
- **最容易误入的边界**：原价 / 现价分不清；利息忘乘时间；利润率分母错

## 精确定义

> ⭐ 经济类应用 = **百分数应用题的特殊场景**
> 三大概念：**折扣 / 利息 / 纳税**

## 多角度逼近

1. **公式角度**：套对应公式
2. **单位 1 角度**：原价 / 本金 / 销售额是单位 1
3. **生活角度**：买卖、存钱、纳税场景
4. **方程角度**：求原价 / 求本金常用方程

## 折扣（discount）

> ⭐ **几折 = 百分之几十**（如八折 = 80%）

| 说法 | 等于 |
|------|------|
| 八折 | 80% |
| 七五折 | 75% |
| 九折 | 90% |
| 半价 | 50% |
| 几折几 | 十位 + 个位 |

> 现价 = 原价 × 折扣

### 例 1：求现价

> 原价 200，打 7 折后？
> 200 × 70% = **140**

### 例 2：求原价

> 现价 140，是 7 折后，原价？
> 140 ÷ 70% = **200**

### 例 3：节省

> 原价 200 现价 140，省了？
> 200 - 140 = **60 元**（或 = 200 × (1-70%) = 60）

## 利息（interest）

> ⭐ **利息 = 本金 × 利率 × 时间**

| 概念 | 解释 |
|------|------|
| 本金 | 存入的钱 |
| 利率 | 单位时间产生的利息百分比 |
| 时间 | 单位与利率单位一致（年利率配年）|
| 利息 | 银行付给的"使用费" |
| 本利和 | 本金 + 利息 |

### 例 1：求利息

> 存 1000 元，年利率 3%，存 2 年？
> 1000 × 3% × 2 = **60 元**

### 例 2：求本金

> 利息 60，年利率 3%，存 2 年；本金？
> 60 ÷ (3% × 2) = 60 ÷ 6% = **1000 元**

### 例 3：本利和

> 上题本利 = 1000 + 60 = **1060 元**

> ⚠️ 利率单位很重要：年利率 vs 月利率

## 纳税（tax）

> ⭐ **应纳税额 = 销售额（或收入）× 税率**

| 类别 | 例 |
|------|------|
| 营业税 | 餐饮、销售按 X% 上交 |
| 个税 | 工资按梯度 |
| 增值税 | 商品流通环节 |

例：一家餐厅本月营业额 50000 元，营业税率 5%；应纳税？

```
50000 × 5% = 2500 元
```

## 利润 / 利润率

| 概念 | 公式 |
|------|------|
| 利润 | 售价 - 成本 |
| 利润率 | (售-成) / 成 × 100% |
| 售价（赚 X%）| 成本 × (1 + X%) |
| 售价（亏 X%）| 成本 × (1 - X%) |
| 成本（已知售 + 利润率）| 售 ÷ (1 + 利润率) |

### 例 1：求利润率

> 成本 80，售 100；利润率？
> (100-80)/80 = 20/80 = **25%**

### 例 2：求成本

> 售 250，赚 25%，成本？
> 250 ÷ (1+25%) = 250 ÷ 1.25 = **200**

> ⚠️ 利润率分母**永远是成本**

## 综合复合题

### 例：先涨后降

> 商品先涨 20% 再降 20%，与原价比？

```
设原 100
涨 20% → 120
降 20% → 120 × 0.8 = 96
比原少 100-96 = 4，少 4%
```

> ⭐ 等百分先涨后降 ≠ 不变；**降低**

### 例：折扣 + 利润

> 一件商品标价 200，打 8 折出售仍赚 25%，成本？

```
售价 = 200 × 0.8 = 160
160 = 成 × (1 + 25%)
成 = 160 ÷ 1.25 = 128 元
```

## 常见陷阱

| 错误 | 正确 |
|------|------|
| 八折 = 8% | ❌ 错。是 **80%** |
| 折扣按现价算 | ❌ 错。按**原价**算 |
| 利息 = 本金 × 利率（漏时间）| 必须**乘时间** |
| 月利率 × 年数 | 月数与月利率搭配 |
| 利润率分母用售价 | ❌ 错。分母用**成本** |
| 先涨 20% 再降 20% = 不变 | ❌ 错。**降 4%** |
| 纳税基数搞错 | 营业税基数是**销售额** |

## 与相邻概念关系

| 相邻概念 | 关系 |
|---------|------|
| 百分数 | 经济题全是百分数 |
| 分数应用 | 同结构 |
| 比 / 比例 | 利润率 = 比 |
| 单位 1 | 原价 / 本金 / 成本是单位 1 |
| 实际生活 | 买东西、银行、报税常见 |
