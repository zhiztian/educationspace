## 适用范围

- **讨论对象**：含分数 / 百分数关系的应用题
- **最容易误入的边界**：找错单位 1；分清乘 vs 除

## 精确定义

> ⭐ **核心**：**单位 1**（标准量、被比较量）
> "A 是 B 的 m/n" → **B 是单位 1**

## 多角度逼近

1. **分率角度**：找单位 1 → 列分率
2. **乘除角度**：已知单位 1 求部分用乘；已知部分求单位 1 用除
3. **方程角度**：设单位 1 为 x
4. **图示角度**：画线段图标"1"段位置

## 三步定位法（必背）

```
1. 找单位 1：通常在"是…的"或"占…"或"比…"前面那个量
2. 已知谁？
   - 已知单位 1 求部分 → 用 ×
   - 已知部分求单位 1 → 用 ÷
3. 列式 / 列方程
```

## 类型 1：求一个数的几分之几（×）

> 已知单位 1 → 求"它的 m/n"

例：一本书 80 页，看了 3/5，看了几页？

```
单位 1 = 80 页（全书）
求 80 的 3/5
80 × 3/5 = 48 页
```

## 类型 2：已知部分求单位 1（÷）

> 已知"部分量"和"对应分率" → 求单位 1

例：看了 48 页，是全书 3/5，全书几页？

```
部分 = 48
分率 = 3/5
单位 1 = 48 ÷ 3/5 = 80 页
```

或方程：设全书 x 页

```
3/5 × x = 48 → x = 80
```

## 类型 3：求一个数比另一个多（少）几分之几

> 求"分率"

例：A = 30，B = 24，A 比 B 多几分之几？

```
求 (A-B)/B = (30-24)/24 = 6/24 = 1/4
```

> ⭐ 注意"多 / 少"看作分子，**单位 1 是被比较的那个**

## 类型 4：比一个数多（少）几分之几

> 已知单位 1 + 分率 → 求另一个

例：B = 24，A 比 B 多 1/4，求 A？

```
A = B × (1 + 1/4) = 24 × 5/4 = 30
```

例：A 比 B 少 20%，B = 50，求 A

```
A = B × (1 - 20%) = 50 × 0.8 = 40
```

## 类型 5：已知"一个数比另一数多 m/n 是…"求单位 1

> 必须先找出"对应分率"

例：A 比 B 多 20% 是 12，求 B？

```
A - B = 12（差）
对应分率 = 20%（差对应于 B）
B = 12 ÷ 20% = 60
```

例：一件衣服降价 20% 后是 200 元，原价多少？

```
现价 = 原 × (1 - 20%) = 原 × 0.8
现价 200，对应分率 0.8
原价 = 200 ÷ 0.8 = 250 元
```

## 单位 1 的判断技巧

| 句型 | 单位 1 |
|------|------|
| A 是 B 的 m/n | **B** |
| A 占 B 的 m/n | **B** |
| A 比 B 多 / 少 m/n | **B** |
| 比去年增加 X% | **去年** |
| 现价比原价低 X% | **原价** |
| 男生占全班 m/n | **全班** |
| 提价 X%、降价 X%、赚 X% | 看准是相对哪个 |

## 复合题型（涉及多次单位 1）

> ⭐ **小心 3 个量！每次单位 1 可能不同**

例：水果店运来苹果 200 kg，梨比苹果多 1/4，香蕉比梨少 1/5；香蕉几 kg？

```
苹果 = 200
梨 = 苹果 × (1 + 1/4) = 200 × 5/4 = 250
香蕉 = 梨 × (1 - 1/5) = 250 × 4/5 = 200
```

> 第一步单位 1 = 苹果；第二步单位 1 = 梨

## 百分数特例

| 题型 | 公式 |
|------|------|
| 折扣 | 现价 = 原价 × 折扣（八折=80%） |
| 利息 | 利息 = 本金 × 利率 × 时间 |
| 利润率 | 利润率 = (售-本)/本 × 100% |
| 增长率 | 增 / 原 × 100% |
| 出勤率 | 出勤 / 总数 × 100% |
| 浓度 | 溶质 / 溶液 × 100% |

## 综合例：盐水浓度

> 100 g 盐水含盐 5 g，浓度多少？再加 100 g 水后浓度？

```
原浓度 = 5/100 = 5%
加水后总液 = 200，盐量不变 = 5
新浓度 = 5/200 = 2.5%
```

> ⭐ 加水盐不变；加盐液增加（注意分母）

## 常见陷阱

| 错误 | 正确 |
|------|------|
| 找错单位 1 | 看"…的"前面 |
| "多 1/4" 算成 1/4 | 是 **(1+1/4)** |
| 已知部分求单位 1 用乘 | ❌ 错。**用除** |
| 第二步还沿用第一步单位 1 | 每步可能换单位 1 |
| 降 20% 升 20% 当不变 | ❌ 错。1 → 0.8 → 0.96，少 4% |
| 浓度题加水算成 50% | 加水后**总液变**，不只稀释一半 |

## 与相邻概念关系

| 相邻概念 | 关系 |
|---------|------|
| 分数 / 百分数 | 算式基础 |
| 单位 1 | 核心概念 |
| 比和比例 | 比可看作分率 |
| 方程法 | 求单位 1 用方程更直观 |
| 经济类（折扣 / 利息）| 全是百分数应用 |
