## 适用范围

- **讨论对象**：两类对象、两种属性（如头数 + 脚数）的混合问题
- **最容易误入的边界**：假设法方向搞反；忘验合理性

## 精确定义

> ⭐ 经典原型：**鸡（2 脚）+ 兔（4 脚）共笼，已知头数和脚数，求各几只**

## 多角度逼近

1. **方程法**：设 x → 列一元方程
2. **假设法**：先全部假设为一种，再反推
3. **二元方程组**（中学）：x + y = 头；2x + 4y = 脚
4. **生活角度**：买东西混合 / 单价不同的混合 / 投票题等

## 方法 1：方程法（推荐）

```
设：鸡 x 只 → 兔 (35 - x) 只
方程：2x + 4(35 - x) = 94
   2x + 140 - 4x = 94
   -2x = -46
   x = 23 → 鸡 23 只，兔 12 只
```

## 方法 2：假设法（古法 / 经典）

### 假设全是鸡

```
   假设 35 只全是鸡 → 应有 35 × 2 = 70 脚
   实际 94 脚，比假设多 94 - 70 = 24 脚
   
   每"换 1 鸡为 1 兔"（保持头不变）：
       脚 + 2（兔比鸡多 2 脚）
   
   多 24 脚 → 换了 24 ÷ 2 = 12 只
   即：兔 = 12，鸡 = 35 - 12 = 23
```

### 假设全是兔（同理）

```
   假设全兔 = 35 × 4 = 140 脚
   多了 140 - 94 = 46 脚
   每换"1 兔为 1 鸡"：脚 - 2
   换 46 ÷ 2 = 23 只
   鸡 = 23，兔 = 12
```

## 通用公式（简化记忆）

设头 H、脚 S；鸡 a 脚、兔 b 脚（b > a）

```
   兔 = (S - aH) ÷ (b - a)
   鸡 = H - 兔
```

例：H=35, S=94, a=2, b=4
→ 兔 = (94 - 2×35) / (4-2) = (94-70)/2 = 12
→ 鸡 = 35 - 12 = 23

## 合理性范围检查

> ⭐ **全鸡的脚数 ≤ 实际脚数 ≤ 全兔的脚数**

| 检查 | 例 |
|------|------|
| 35 头全鸡 = 70 脚 | 下限 |
| 35 头全兔 = 140 脚 | 上限 |
| 实际 94 在 [70, 140] | ✅ 合理 |

> 不在范围则题目矛盾或脚数 / 头数有误

## 鸡兔同笼变种

### 变种 1：单价混合

> A 商品 5 元 / 件，B 商品 8 元 / 件，共买 20 件花 130 元，各买几件？

```
设 A 件 x，B 件 (20-x)
方程：5x + 8(20-x) = 130
解：x = 10 件 A，10 件 B
```

### 变种 2：得分加分扣分

> 答 20 题，对得 5 分错扣 3 分，得 60 分，对几题？

```
设对 x 题，错 (20-x)
方程：5x - 3(20-x) = 60
   5x - 60 + 3x = 60
   8x = 120 → x = 15 对
```

### 变种 3：三元素混合（中学常见）

> 3 类对象 → 需 2 个方程，超出小学范围

## 常见陷阱

| 错误 | 正确 |
|------|------|
| 假设全鸡，"少几脚"反着加 | 假设鸡 → 实际多脚 → 兔 = 多/2 |
| 算出兔 = 12.5 只 | ❌ 错。题目矛盾，重检查 |
| 算出兔 > 头数 | ❌ 错。检查脚数是否合理 |
| 不验证 | 代回 2×23 + 4×12 = 46+48 = 94 ✓ |
| 用方程后忘求另一个 | 鸡 + 兔 必须**两个都求** |
