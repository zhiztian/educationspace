## 适用范围

- **讨论对象**：**整数**（含 0、正整数、负整数）
- **不讨论 / 排除**：小数、分数（0.5 既不是奇数也不是偶数）
- **最容易误入的边界**：以为 0 不是偶数；以为奇数都是质数 / 偶数都是合数；漏掉 2 这个特殊偶数

## 精确定义

- **偶数**：能被 2 **整除**的整数（÷2 余 0）。例：…, −4, −2, **0**, 2, 4, …
- **奇数**：**不能**被 2 整除的整数（÷2 余 1）。例：…, −3, −1, 1, 3, 5, …

## 多角度逼近

1. **整除角度**：÷ 2 余 0 → 偶；余 1 → 奇
2. **个位数字角度**：个位是 **0 / 2 / 4 / 6 / 8 → 偶**；**1 / 3 / 5 / 7 / 9 → 奇**
3. **配对角度**：偶数能两两配对没剩；奇数会剩 1 个落单
4. **数轴角度**：奇偶交替出现（…奇偶奇偶…）

## 运算规律（小升初常考）

| 运算 | 结果 | 例 |
|------|------|---|
| 偶 + 偶 | **偶** | 4 + 6 = 10 |
| 奇 + 奇 | **偶** | 3 + 5 = 8 |
| 偶 + 奇 | **奇** | 4 + 3 = 7 |
| 偶 × 偶 | **偶** | 4 × 6 = 24 |
| 偶 × 奇 | **偶** | 4 × 3 = 12 |
| 奇 × 奇 | **奇** | 3 × 5 = 15 |

> 💡 **口诀**：
> **加法**：相同性 → 偶；不同性 → 奇
> **乘法**：只要有偶 → 偶；全奇 → 奇

## 常见陷阱

| 错误说法 | 正确认识 |
|---------|---------|
| "0 不是偶数" | ❌ 错。**0 是偶数**（0 ÷ 2 = 0 没有余数） |
| "奇数都是质数" | ❌ 错。**9, 15, 21** 都是奇合数 |
| "偶数都是合数" | ❌ 错。**2 是偶数但是质数**（唯一的偶质数） |
| "−3 既不是奇数也不是偶数" | ❌ 错。负整数也分奇偶，−3 是奇数 |
| "0.5 是奇数（因为不能被 2 整除）" | ❌ 错。奇偶**只对整数**说，小数不分奇偶 |

## 与相邻概念关系

```
全体整数 = 奇数 ∪ 偶数      （不重不漏，0 在偶数里）
非整数 = 不分奇偶            （0.5 / ½ 不是奇也不是偶）
```

| 相邻概念 | 关系 |
|---------|------|
| 0 | 0 是偶数（最特殊的偶数） |
| 质数 / 合数 | 奇偶 与 质合 是**两套独立分类**；交集：奇质数（3, 5, 7…）/ 奇合数（9, 15…）/ 偶质数（**只有 2**）/ 偶合数（4, 6, 8…） |
| 因数 / 倍数 | 偶数 = 2 的倍数；奇数 ≠ 2 的倍数 |
| 整数 / 小数 | 奇偶**只对整数**说；小数 / 分数不分奇偶 |
