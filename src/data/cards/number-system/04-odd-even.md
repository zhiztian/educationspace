## 精确定义

- **偶数**：能被 2 整除的整数（含 0 和负偶数）。例：…, −4, −2, 0, 2, 4, …
- **奇数**：不能被 2 整除的整数。例：…, −3, −1, 1, 3, 5, …

## 多角度逼近

1. **整除角度**：÷2 余 0 = 偶；余 1 = 奇
2. **个位数字**：个位是 0/2/4/6/8 → 偶；1/3/5/7/9 → 奇
3. **配对角度**：偶数能两两配对；奇数会剩 1 个
4. **数轴角度**：奇偶交替出现

## 运算规律（小升初常考）

| 运算 | 结果 |
|------|------|
| 偶 + 偶 | 偶 |
| 奇 + 奇 | 偶 |
| 偶 + 奇 | 奇 |
| 偶 × 偶 | 偶 |
| 偶 × 奇 | 偶 |
| 奇 × 奇 | 奇 |

> 💡 口诀：**加法看相同——同性为偶，异性为奇；乘法只要有偶就是偶**

## 常见陷阱

| 错误说法 | 正确认识 |
|---------|---------|
| "0 不是偶数" | ❌ 错。0 是偶数 |
| "奇数都是质数" | ❌ 错。9 是奇数但不是质数（9=3×3） |
| "偶数都是合数" | ❌ 错。**2 是偶数但是质数**（唯一的偶质数） |
| "−3 既不是奇数也不是偶数" | ❌ 错。负整数也分奇偶，−3 是奇数 |
