## 适用范围

- **讨论对象**：**非零自然数**之间的关系（即 1, 2, 3, ……）
- **不讨论 / 排除**：**0**（小学约定不讨论 0 的因数 / 倍数）、小数、分数、负数
- **最容易误入的边界**：把"因数 / 倍数"说成单个数的属性（如"3 是因数"）；忽略"必须两个数之间"

## 精确定义

如果 **a × b = c**（a, b, c 都是非零自然数），那么：
- **a 和 b 都是 c 的因数**
- **c 是 a 和 b 的倍数**

例：12 = 3 × 4 → 3 和 4 都是 12 的因数；12 是 3 和 4 的倍数。

> ⚠️ **关键**：因数 / 倍数是**两个数之间的关系**，必须说"A 是 B 的因数 / 倍数"，
> 不能脱离 B 单独说"A 是因数"。

## 多角度逼近

1. **乘法定义**：a × b = c → a, b 是 c 的因数；c 是 a, b 的倍数
2. **除法定义**：c ÷ a = b（无余数）→ a 是 c 的因数
3. **整除角度**：a 能整除 b → a 是 b 的因数 ↔ b 是 a 的倍数
4. **反例角度**：12 ÷ 5 = 2 余 2 → 5 **不是** 12 的因数

## 找一个数的因数（成对找，不漏不重）

例：**找 36 的所有因数**

```
1 × 36 → 1, 36
2 × 18 → 2, 18
3 × 12 → 3, 12
4 ×  9 → 4, 9
6 ×  6 → 6   ← 成对相同只算一次
```

→ 36 的因数有 **1, 2, 3, 4, 6, 9, 12, 18, 36**（共 9 个）

## 找一个数的倍数（无穷多）

例：**6 的倍数** = 6, 12, 18, 24, 30, ……（一直 ×2、×3、… 写不完）

## 关键性质

| 性质 | 说明 |
|------|------|
| 一个数的最小因数 | 是 **1** |
| 一个数的最大因数 | 是它**本身** |
| 一个数的因数个数 | **有限** |
| 一个数的最小倍数 | 是它**本身** |
| 一个数的最大倍数 | **没有**（无穷多） |
| 一个数倍数的个数 | **无限** |

## 常见陷阱

| 错误说法 | 正确认识 |
|---------|---------|
| "12 的因数是 3" | ⚠️ 不严谨。应说"3 是 12 的因数" |
| "5 是因数" | ❌ 错。必须说"5 是 X 的因数" |
| "一个数的最大倍数是它自己" | ❌ 错。**没有最大倍数**；最大**因数**才是它自己 |
| "0 是 5 的倍数" | ⚠️ 小学不讨论（约定在非零自然数范围内） |
| "0.5 是 1 的因数" | ❌ 错。因数 / 倍数**只对非零自然数**说 |

## 与相邻概念关系

```
非零自然数  ──→ 任何两个都可以谈"是否互为因数 / 倍数"
质数       = 只有 2 个因数（1 和自身）
合数       = 因数 ≥ 3 个
1          = 只有 1 个因数（自己）
```

| 相邻概念 | 关系 |
|---------|------|
| 质数 / 合数 | 用**因数个数**定义：质数 = 2 个；合数 ≥ 3 个；1 = 1 个 |
| 公因数 / 公倍数 | 多个数共有的因数 / 倍数 |
| 互质 | 两数公因数只有 1（即 gcd = 1） |
| 奇数 / 偶数 | 偶数 = 2 的倍数；奇数 ≠ 2 的倍数 |
| 0 | 0 不参与因倍讨论（小学约定） |
