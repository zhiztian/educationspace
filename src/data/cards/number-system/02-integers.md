## 精确定义

**整数**：自然数和负整数的统称。

- 正整数：1, 2, 3, ……
- 0
- 负整数：−1, −2, −3, ……

## 多角度逼近

1. **数轴角度**：数轴上等距分布的点（0 和正负整数）
2. **运算角度**：整数加减乘后还是整数（除法不一定）
3. **生活角度**：温度（−5℃）、楼层（−1F）、海拔（−10米）

## 常见陷阱

| 错误说法 | 正确认识 |
|---------|---------|
| "0 是正整数" | ❌ 错。0 既不是正整数也不是负整数 |
| "整数都比小数大" | ❌ 错。−3 比 0.5 小 |
| "0 没有相反数" | ❌ 错。0 的相反数是 0 本身 |

## 例题

**Q**：下列哪些是整数？  3, −7, 0, 0.5, ½, 100, −2.3

**A**：3, −7, 0, 100 是整数；0.5、½、−2.3 不是。
