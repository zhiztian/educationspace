## 适用范围

- **讨论对象**：所有正整数、0、所有负整数
- **不讨论 / 排除**：小数、分数（哪怕分子分母都是整数，如 ½ 也不是整数）
- **最容易误入的边界**：以为整数 = 自然数（漏掉负整数）；以为 0 是正整数

## 精确定义

**整数**：自然数和负整数的统称。

```
整数 = 负整数 ∪ { 0 } ∪ 正整数
       (……, −3, −2, −1)   (1, 2, 3, ……)
```

- **正整数**：1, 2, 3, ……
- **0**：既不是正整数也不是负整数（**单独一类**）
- **负整数**：−1, −2, −3, ……

## 多角度逼近

1. **数轴角度**：数轴上**等距分布的点**，0 是中间，正整数往右、负整数往左
2. **运算角度**：整数 +、−、× 之后还是整数（除法不一定，如 7 ÷ 2 = 3.5 不是整数）
3. **生活角度**：温度（−5 ℃）、楼层（−1 F = 地下一层）、海拔（−10 m）、收支（−50 元 = 支出）
4. **反例角度**：0.5 / ½ / π 都**不是**整数

## 常见陷阱

| 错误说法 | 正确认识 |
|---------|---------|
| "0 是正整数" | ❌ 错。0 既不是正整数也不是负整数 |
| "整数都比小数大" | ❌ 错。−3 比 0.5 小 |
| "0 没有相反数" | ❌ 错。0 的相反数是 0 本身 |
| "整数 = 自然数" | ❌ 错。整数比自然数多了**全部负整数** |
| "½ 是整数（因为分子分母是整数）" | ❌ 错。½ = 0.5，是小数 / 分数，不是整数 |

## 与相邻概念关系

```
自然数 ⊂ 整数 ⊂ 有理数 ⊂ 实数
       (差负整数)  (差分数)    (差无理数)
```

| 相邻概念 | 关系 |
|---------|------|
| 自然数 | 自然数 ⊂ 整数；整数比自然数多负整数 |
| 0 | 0 是整数（也是分界点） |
| 正整数 / 负整数 | 整数 = 负整数 ∪ {0} ∪ 正整数（三类不重不漏） |
| 小数 / 分数 | 整数 ∩ 小数 = ∅；整数 ∩ 真分数 = ∅；但**整数可以写成假分数**（如 3 = 3/1） |
| 相反数 | 任何整数都有相反数；0 的相反数是 0 |
