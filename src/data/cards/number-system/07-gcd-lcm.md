## 适用范围

- **讨论对象**：两个或多个**非零自然数**
- **不讨论 / 排除**：0、小数、分数、负数
- **最容易误入的边界**：把 GCD 和 LCM 搞反；以为"互质 = 两数都是质数"；以为最大公因数可以是 0

## 精确定义

- **公因数**：几个数**共有**的因数
- **最大公因数（GCD，又叫最大公约数）**：公因数中最大的一个
- **公倍数**：几个数**共有**的倍数
- **最小公倍数（LCM）**：公倍数中最小的一个（≠ 0）

> ⭐ **重要公式**：对任意两个非零自然数 a, b
>
> **a × b = gcd(a, b) × lcm(a, b)**

## 多角度逼近

1. **列举法**：分别列出每个数的因数 / 倍数，找交集（适合小数）
2. **短除法**：用公共质因数依次除（最常用，见下）
3. **分解质因数法**：
   - GCD = 公共质因数取**最低次幂**的乘积
   - LCM = 所有质因数取**最高次幂**的乘积
   - 例：12 = 2²×3，18 = 2×3² → gcd = 2¹×3¹ = 6；lcm = 2²×3² = 36
4. **公式法**：已知三个量求第四个 → **a × b = gcd × lcm**

## 求法：短除法（最常用）

例：求 12 和 18 的最大公因数和最小公倍数

```
  2 │ 12  18
  3 │  6   9
    │  2   3   ← 互质，停止

最大公因数 = 2 × 3 = 6
最小公倍数 = 2 × 3 × 2 × 3 = 36
```

> 💡 **口诀**：
> **GCD = 左边乘**（公共质因数全乘起来）
> **LCM = 左边乘 × 底下乘**（再乘上互质后的剩余）

## 特殊情况速记

| 情况 | 最大公因数 | 最小公倍数 |
|------|----------|----------|
| 两数互质（公因数只有 1） | **1** | **两数之积** |
| 一个数是另一个的倍数（如 4 和 12） | **较小数** | **较大数** |
| 两数相等（如 6 和 6） | **该数本身** | **该数本身** |

例：
- 5 和 7（互质）→ gcd = 1，lcm = 35
- 4 和 12（倍数关系）→ gcd = 4，lcm = 12
- 8 和 12（既不互质也无倍数关系）→ gcd = 4，lcm = 24

## 关键性质

| 性质 | 说明 |
|------|------|
| gcd(a, b) | **≤ 较小数**（最大不会超过较小那个） |
| lcm(a, b) | **≥ 较大数**（最小也要等于较大那个） |
| gcd(a, b) | 一定 **≥ 1**（不可能是 0） |
| a × b | **= gcd × lcm**（万能公式） |

## 常见陷阱

| 错误说法 | 正确认识 |
|---------|---------|
| "两个不同数的最大公因数可能是 0" | ❌ 错。最小是 **1**（任何非零自然数都有因数 1） |
| "两个数的最小公倍数可能是 1" | ❌ 错（除非两数都是 1） |
| "最大公因数 ≥ 最小公倍数" | ❌ 错。**gcd ≤ 较小数 ≤ 较大数 ≤ lcm** |
| "互质就是两个数都是质数" | ❌ 错。互质 = 公因数只有 1，与是否质数无关（8 和 9 互质） |
| "GCD 和 LCM 哪个是哪个老忘" | 💡 记：**G**reatest = **小**（≤较小数）；**L**east = **大**（≥较大数）。"最大公因数其实更小，最小公倍数其实更大" |

## 与相邻概念关系

```
两个数 a, b
   ├─ 公因数 ─→ 最大那个 = GCD
   └─ 公倍数 ─→ 最小那个 = LCM
   恒等：a × b = GCD × LCM
```

| 相邻概念 | 关系 |
|---------|------|
| 因数 / 倍数 | 公因数 = 多个数共有的因数；公倍数 = 多个数共有的倍数 |
| 质数 / 合数 | 分解质因数法是求 GCD/LCM 的通用方法 |
| 互质 | gcd(a, b) = 1 ⇔ a, b 互质 |
| 短除法 | 既可用于分解质因数，也可用于求 GCD/LCM |
| 分数 | 通分用 LCM（分母）；约分用 GCD（分子分母） |
