## 精确定义

**自然数**：用来表示物体个数的数：0, 1, 2, 3, 4, 5, ……

## 关键

- ⭐ **0 是自然数**（1993 年后中国小学统一规定，与国际接轨）
- ⭐ **最小的自然数是 0**
- 没有最大的自然数，自然数有无穷多个

## 多角度逼近

1. **数学定义**：从 0 开始，每次 +1 形成的数列
2. **数数角度**：数物体个数得到的数（包括"一个都没有"=0）
3. **写法角度**：用 0–9 十个数字按位值原则写出
4. **反例**：
   - 0.5 不是自然数（小数）
   - −3 不是自然数（负整数）
   - ½ 不是自然数（分数）

## 常见陷阱

| 错误说法 | 正确认识 |
|---------|---------|
| "0 不是自然数" | ❌ 错。0 是自然数 |
| "最小的自然数是 1" | ❌ 错。最小是 0 |
| "自然数都是正数" | ❌ 错。0 不是正数也不是负数 |
| "自然数有最大数" | ❌ 错。无限多个 |

## 与相邻概念关系

```
整数 = 负整数 + 0 + 正整数
自然数 = 0 + 正整数
所以：自然数 ⊂ 整数
```
