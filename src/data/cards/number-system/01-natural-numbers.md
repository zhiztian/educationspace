## 适用范围

- **讨论对象**：0 和所有正整数（0, 1, 2, 3, ……）
- **不讨论 / 排除**：负整数、小数、分数
- **最容易误入的边界**：以为最小是 1（漏掉 0）；以为正数才算自然数

## 精确定义

**自然数**：用来表示物体个数的数 —— **0, 1, 2, 3, 4, ……**。

> ⭐ **0 是自然数**（1993 年后中国小学统一规定，与国际接轨）
>
> ⭐ **最小的自然数是 0**；自然数没有最大数，有无穷多个

## 多角度逼近

1. **数学定义角度**：从 0 开始，每次 +1 形成的数列
2. **数数角度**：数物体个数得到的数 —— 包括"一个都没有" = 0
3. **写法角度**：用 0–9 十个数字按位值原则写出（个位、十位、百位……）
4. **反例角度**（什么不是自然数）：
   - 0.5 ❌（小数）
   - −3 ❌（负整数）
   - ½ ❌（分数）

## 常见陷阱

| 错误说法 | 正确认识 |
|---------|---------|
| "0 不是自然数" | ❌ 错。0 是自然数（且是最小的） |
| "最小的自然数是 1" | ❌ 错。最小是 0 |
| "自然数都是正数" | ❌ 错。0 不是正数也不是负数 |
| "自然数有最大数" | ❌ 错。无限多个 |

## 与相邻概念关系

```
整数 = 负整数 ∪ {0} ∪ 正整数
自然数 = {0} ∪ 正整数
所以：自然数 ⊂ 整数
```

| 相邻概念 | 关系 |
|---------|------|
| 整数 | 自然数 ⊂ 整数（缺了负整数） |
| 0 | 0 是自然数（最小的那个） |
| 正整数 | 正整数 ⊂ 自然数（缺了 0） |
| 负数 | 自然数 ∩ 负数 = ∅（不相交） |
| 小数 / 分数 | 自然数 ∩ 小数 = ∅；自然数 ∩ 真分数 = ∅ |
