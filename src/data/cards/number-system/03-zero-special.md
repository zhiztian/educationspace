## 适用范围

- **讨论对象**：自然数 0 在小学各个数学概念中的归属
- **不讨论 / 排除**：0 在中学才会涉及的话题（如 0 的因数、0 的若干代数性质）
- **最容易误入的边界**：用"非零"概念（质数 / 合数 / 因数）去硬套 0；把 0 当成"既不是奇数也不是偶数"

## 为什么单独一节

**0 是小学数学最特殊的数**，在不同概念中归属不同，最容易混淆。

## 0 的"身份证"全表

| 问题 | 答案 |
|------|------|
| 0 是自然数吗？ | ✅ 是 |
| 0 是整数吗？ | ✅ 是 |
| 0 是正数吗？ | ❌ 不是 |
| 0 是负数吗？ | ❌ 不是 |
| 0 是偶数吗？ | ✅ **是**（0 ÷ 2 = 0 没有余数） |
| 0 是质数吗？ | ❌ 不是 |
| 0 是合数吗？ | ❌ 不是（既不是质数也不是合数） |
| 0 有因数吗？ | ⚠️ 小学**不讨论 0 的因数** |
| 0 是任何非零自然数的倍数吗？ | ✅ 是（0 × n = 0） |
| 0 能做除数吗？ | ❌ **绝对不能**（除以 0 没有意义） |
| 0 能做被除数吗？ | ✅ 能（0 ÷ 5 = 0） |
| 0 的相反数是？ | 0 本身 |
| 0 的绝对值是？ | 0 |

## 必背口诀

> **0 是**：自然数 ✓ 整数 ✓ 偶数 ✓
>
> **0 不是**：正数 ✗ 负数 ✗ 质数 ✗ 合数 ✗

## 常见陷阱

- "0 不是偶数" → ❌ 错（0 ÷ 2 = 0 没有余数，是偶数）
- "0 是正数" → ❌ 错（0 既不正也不负）
- "5 ÷ 0 = 0" → ❌ 错（除以 0 无意义，不是 0）
- "0 ÷ 5 = 5" → ❌ 错（0 ÷ 任何非零数 = 0）

## 与相邻概念关系

| 相邻概念 | 0 的归属 |
|---------|---------|
| 自然数 | ✅ 是（0 是最小的自然数） |
| 整数 | ✅ 是 |
| 偶数 | ✅ 是 |
| 正数 / 负数 | ❌ 都不是（0 是分界点） |
| 质数 / 合数 | ❌ 都不是（不参与质合分类） |
| 除法 | ✅ 可作被除数（0 ÷ 5 = 0）；❌ 不可作除数 |
| 分数 | ✅ 分子可以是 0（如 0/5 = 0）；❌ 分母不能是 0 |
| 因数 / 倍数 | ⚠️ 小学不讨论 0 的因数；0 是任何非零自然数的倍数 |
| 相反数 | 0 的相反数是 0 本身 |
| 绝对值 | 0 的绝对值是 0 |
