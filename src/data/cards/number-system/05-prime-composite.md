## 适用范围

- **讨论对象**：**大于 1** 的自然数（即 2, 3, 4, ……）
- **不讨论 / 排除**：0 和 1
- **最容易误入的边界**：把 1 当成质数；把 0 拉进质合分类

## 精确定义

- **质数（素数）**：**大于 1** 的自然数中，**只有 1 和它本身两个因数**的数
- **合数**：**大于 1** 的自然数中，除了 1 和它本身**还有其他因数**的数（即因数个数 ≥ 3）
- **1**：既不是质数，也不是合数（**单独一类**）
- **0**：既不是质数，也不是合数（不参与质合分类）

## 多角度逼近

1. **因数个数**：
   - 质数：恰好 2 个因数（1 和自身）
   - 合数：3 个或更多因数
   - 1：只有 1 个因数（自己），所以不是质数
2. **乘法原子比喻**：质数像"乘法里的原子"——**不能拆成两个都大于 1 的自然数相乘**。例：7 不能拆；9 = 3 × 3 所以是合数
3. **筛法**：从 2 开始，**保留 2，划掉 2 的其他倍数**；再**保留 3，划掉 3 的其他倍数**……剩下没被划掉的就是质数

## 常见陷阱

| 错误说法 | 正确认识 |
|---------|---------|
| "1 是最小的质数" | ❌ 错。**1 不是质数**。最小质数是 **2** |
| "1 是合数" | ❌ 错。1 既不是质数也不是合数 |
| "所有质数都是奇数" | ❌ 错。**2 是唯一的偶质数** |
| "所有奇数都是质数" | ❌ 错。9, 15, 21 都是奇合数 |
| "互质的两个数都是质数" | ❌ 错。互质≠都是质数。**4 和 9 互质**但都是合数 |
| "0 是质数" | ❌ 错。0 不在质合分类中 |
| "两个质数相加一定是偶数" | ❌ 错。如 2+3=5。**只有当两个质数都不是 2 时才是偶数** |

## 与相邻概念关系

```
全体大于 1 的自然数 = 质数 ∪ 合数
1 = 单独一类
0 = 不参与
```
