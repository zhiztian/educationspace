## 适用范围

- **讨论对象**：用方程方法解应用题
- **最容易误入的边界**：找不准"等量关系"；设错未知数让方程复杂

## 精确定义

> ⭐ **方程法**：把应用题中**未知量**用字母代表，根据**等量关系**列出方程，求解

## 多角度逼近

1. **建模角度**：实际问题 → 数学方程
2. **等量关系角度**：找出"= 号两边相等"的描述
3. **设元角度**：选合适未知量为 x
4. **求解角度**：用解方程技巧（参 eq-04）

## 5 步骤（必背）

```
1. 审题：理解题意，找出已知和未知
2. 设元：用 x 设未知量（写"设…为 x"）
3. 列方程：根据等量关系
4. 解方程
5. 检验 + 写"答"
```

## 找"等量关系"的方法

| 句型 | 等量关系 |
|------|---------|
| "比…多 a" | A = B + a |
| "比…少 a" | A = B - a |
| "是…的 a 倍" | A = aB |
| "比…多 a 倍" | A = (a+1)B |
| "总共 / 一共 = X" | A + B + … = X |
| 单价 × 数量 = 总价 | 商品类 |
| 速度 × 时间 = 路程 | 行程类 |
| 工效 × 时间 = 工作量 | 工程类 |
| 原数 ± 变化 = 现在 | 增减 / 收支类 |

## 例题

### 例 1：单变量直接

> 一本故事书 60 页，小明看了 3 天剩 24 页，平均每天看多少？

```
设：平均每天看 x 页
等量关系：已看页数 + 剩余 = 总页数
方程：3x + 24 = 60
解：3x = 36 → x = 12
答：每天看 12 页
```

### 例 2：和差类

> 妹妹比哥哥小 4 岁，两人年龄和 22 岁，各几岁？

```
设：哥哥 x 岁，妹妹 = x - 4
等量关系：哥哥 + 妹妹 = 22
方程：x + (x - 4) = 22
解：2x - 4 = 22 → 2x = 26 → x = 13
妹妹 = 9
答：哥 13 岁，妹 9 岁
```

### 例 3：倍数关系

> 一筐桃子是另一筐 3 倍，两筐共 60 个，各有多少？

```
设：少的一筐 x 个，多的 = 3x
方程：x + 3x = 60 → 4x = 60 → x = 15
答：少 15 个，多 45 个
```

### 例 4：行程问题

> 甲乙两地相距 360 km，火车 4 小时到达，火车速度多少？

```
设：火车速度 = x km/h
等量关系：速度 × 时间 = 路程
方程：4x = 360 → x = 90
答：90 km/h
```

### 例 5：鸡兔同笼

> 鸡兔同笼共 35 头 94 脚，各几只？

```
设：鸡 x 只 → 兔 (35 - x) 只
等量关系：鸡脚 + 兔脚 = 总脚
方程：2x + 4(35 - x) = 94
   2x + 140 - 4x = 94
   -2x = -46
   x = 23（鸡 23 只，兔 12 只）
```

## 设元小技巧

| 情况 | 设法 |
|------|------|
| 直接求量 | 设那个量为 x |
| 多个相关量 | 设关系最少的为 x（其他用 x 表达）|
| 倍数 | 设较小的为 x，大的 = nx |
| 和差 | 设其中一个，另一个用 (S-x) |

## 检验包含两步

1. **解方程是否正确**：代回方程算
2. **答案是否符合题意**：不能负数 / 不能小数 / 范围合理

例：年龄不能 -3；人数不能 5.5；速度不能太离谱

## 常见陷阱

| 错误 | 正确 |
|------|------|
| 不写"设…为 x" | 必须写设 |
| 找错等量关系 | 多读题，圈关键词 |
| 求出 x 就完事 | 还要写"答：…" |
| 单位漏 | 答中带单位 |
| 解不符合实际未筛 | 鸡 -3 只 → 不合理，需检查 |
| 等量关系搞反 | "甲比乙多 3" = "甲 = 乙 + 3"（不是乙 = 甲 + 3）|

## 与相邻概念关系

| 相邻概念 | 关系 |
|---------|------|
| 解方程 | 列方程后用 |
| 字母表数 | 设元基础 |
| 应用题（算术法 vs 方程法） | 方程更直接，但需会列 |
| 鸡兔同笼 / 工程 / 行程 | 经典方程题型 |
| 比例 | 解比例本质就是解方程 |
