## 适用范围

- **讨论对象**：求方程的解
- **最容易误入的边界**：减号 / 除号方向搞反；解出来不验证

## 精确定义

> ⭐ **解方程**：利用**等式性质**，把方程化成 "x = ..." 的过程

## 多角度逼近

1. **性质角度**：靠等式性质 1 / 2
2. **逆运算角度**：加 ↔ 减；乘 ↔ 除
3. **天平角度**：两边同时操作
4. **公式角度**：和 - 一加数 = 另一加数；积 ÷ 一因数 = 另一因数

## 一步方程（基础）

| 类型 | 操作 | 例 |
|------|------|-----|
| x + a = b | 两边 -a → x = b - a | x+5=12 → x=7 |
| x - a = b | 两边 +a → x = b + a | x-5=12 → x=17 |
| ax = b | 两边 ÷a → x = b/a | 3x=12 → x=4 |
| x ÷ a = b | 两边 ×a → x = ab | x/3=4 → x=12 |
| a - x = b | x = a - b（被减数 - 差 = 减数）| 8-x=3 → x=5 |
| a ÷ x = b | x = a/b（被除数 ÷ 商 = 除数）| 12/x=4 → x=3 |

## 两步方程（含加减 + 乘除）

> ⭐ **倒序剥洋葱**：先消加减，再消乘除（与运算顺序相反）

例：5x - 7 = 18

```
   第 1 步（消减号）：两边 + 7
       5x - 7 + 7 = 18 + 7
       5x = 25
   
   第 2 步（消乘号）：两边 ÷ 5
       5x ÷ 5 = 25 ÷ 5
       x = 5
```

例：(x + 3) × 4 = 32

```
   第 1 步：两边 ÷4
       x + 3 = 8
   第 2 步：两边 -3
       x = 5
```

> 一般原则：先去**最外层**运算

## 含未知数在两边

> ⭐ 把含 x 的项移到一边，常数项移到另一边

例：3x + 5 = x + 17

```
   两边 -x：    2x + 5 = 17
   两边 -5：    2x = 12
   两边 ÷2：    x = 6
```

## 含括号方程

> 一般先**去括号**或**两边同时除以括号外数**

例：3(x - 4) = 15
- 法 1：两边 ÷3 → x - 4 = 5 → x = 9
- 法 2：去括号 → 3x - 12 = 15 → 3x = 27 → x = 9

## 含分数 / 小数方程

例：x/3 + 2 = 5

```
   两边 -2：    x/3 = 3
   两边 ×3：    x = 9
```

例：0.5x = 4

```
   两边 ÷0.5：  x = 8
```

## 验证步骤

> ⭐ 解完后**代回原方程**，看左边是否 = 右边

例：解 5x - 7 = 18 得 x = 5
- 代回：5×5 - 7 = 25 - 7 = 18 ✓
- 解正确

## 解方程的标准格式（书面）

```
   解：5x - 7 = 18
       5x - 7 + 7 = 18 + 7      （等式性质 1）
              5x = 25
              5x ÷ 5 = 25 ÷ 5   （等式性质 2）
              x = 5
   
   检验：把 x = 5 代入原方程
        左边 = 5×5 - 7 = 18
        右边 = 18
        左边 = 右边
        所以 x = 5 是原方程的解
```

## 常见陷阱

| 错误 | 正确 |
|------|------|
| x + 5 = 12 → x = 12 + 5 | ❌ 错。应 **-5** |
| 8 - x = 3 → x = 8 + 3 | ❌ 错。x = **8 - 3** = 5 |
| 3x = 12 → x = 12 - 3 | ❌ 错。应 **÷3** |
| 12 ÷ x = 4 → x = 12 × 4 | ❌ 错。x = **12 ÷ 4** = 3 |
| 解完不验证 | 必须代回**原方程** |
| 验证时代入"化简后的方程"| 必须代入**原方程** |
| 移项不变号 | 解方程靠"两边同操作"；移项要改变运算 |
