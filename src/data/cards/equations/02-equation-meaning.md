## 适用范围

- **讨论对象**：含未知数的等式
- **最容易误入的边界**：把不等式 / 单纯算式当方程

## 精确定义

> ⭐ **方程**：含有**未知数**的**等式**

```
   方程 = 等式 + 未知数（缺一不可）
   
   3 + x = 8   ✅ 方程（含未知数 x，是等式）
   3 + 5 = 8   ❌ 不是方程（无未知数）
   x + 3       ❌ 不是方程（不是等式）
   x + 3 > 5   ❌ 不是方程（是不等式）
```

## 多角度逼近

1. **构成角度**：等式 + 未知数（必备）
2. **求解角度**：找使等式成立的未知数值
3. **建模角度**：把实际问题翻译成方程
4. **生活角度**：糖块谜题、年龄问题、价格问题

## 方程的判定（两条件同时）

| 条件 | 例 |
|------|------|
| ① 是等式（含 =） | x + 3 = 8 ✅ / x + 3 > 5 ❌ |
| ② 含未知数（字母） | 3 + x = 8 ✅ / 3 + 5 = 8 ❌ |

> 必须**同时满足**才是方程

## 方程 vs 算式 vs 等式 vs 不等式

| 名称 | 形式 | 例 |
|------|------|-----|
| 算式 | 一串运算 | 3 + 5 |
| 等式 | 含等号的式子 | 3 + 5 = 8 |
| 不等式 | 含 > / < / ≥ / ≤ 的式子 | x + 3 > 5 |
| 方程 | 含未知数的等式 | x + 3 = 8 |

## "方程的解" vs "解方程"

| 概念 | 含义 |
|------|------|
| **方程的解** | 那个使方程成立的**值**（结果，名词） |
| **解方程** | 求方程的解的**过程**（动作，动词） |

例：方程 x + 5 = 12
- 解方程：x + 5 = 12 → x = 12 - 5 → x = 7
- 方程的解：**x = 7**

## 验证：把解代回方程

例：检验 x = 7 是不是 x + 5 = 12 的解
→ 把 x = 7 代入左边：7 + 5 = 12 = 右边 ✅
→ x = 7 是解

## 经典练习：判断哪些是方程

```
① 3 + 5 = 8         ❌ 无未知数
② 3 + x = 8         ✅ 方程
③ x + 3 > 5         ❌ 不等式
④ 7 - x             ❌ 不是等式
⑤ 4y - 2 = 10       ✅ 方程
⑥ x = 5             ✅ 方程（含未知数 + 等式）
⑦ a + b = 10        ✅ 方程（含未知数 a, b）
⑧ 2 × 3 + 1 = 7     ❌ 无未知数
```

## 列方程解题（基本步骤）

```
1. 分析题目，找出"等量关系"
2. 设未知数（用 x、y）
3. 根据等量关系列方程
4. 解方程
5. 检验 + 写答
```

例：小明买苹果，每个 3 元，买了 x 个，共 12 元
等量关系：单价 × 数量 = 总价
→ 3x = 12 → x = 4

## 常见陷阱

| 错误 | 正确 |
|------|------|
| 3 + 5 = 8 是方程 | ❌ 错。**无未知数**不是方程 |
| x + 3 是方程 | ❌ 错。**不是等式** |
| x > 5 是方程 | ❌ 错。**是不等式**（不是等式） |
| x = 5 不是方程 | ❌ 错。它**是**方程（满足两条件） |
| "方程的解 = 解方程" | 一个是结果，一个是过程 |
| 设 x 但不写"设…为 x" | 列方程前要明确设 |

## 与相邻概念关系

| 相邻概念 | 关系 |
|---------|------|
| 等式 | 方程是特殊等式 |
| 字母表示数 | 字母在方程中是**未知数** |
| 解方程 | 求方程的解的过程 |
| 比例（解比例）| 解比例本质是解方程 |
| 应用题 | 翻译成方程是核心 |
