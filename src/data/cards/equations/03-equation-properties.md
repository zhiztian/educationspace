## 适用范围

- **讨论对象**：所有等式（方程）
- **最容易误入的边界**：只对一边操作；除以 0；同乘除时只乘一边

## 精确定义

> ⭐ **等式性质 1**（加减）：等式两边**同时加 / 减同一个数**，等式仍成立
> ⭐ **等式性质 2**（乘除）：等式两边**同时乘 / 除以同一个不为 0 的数**，等式仍成立

## 多角度逼近

1. **公平角度**：天平两边动作必须**完全一样**
2. **代数角度**：是解方程的根本依据
3. **不变量角度**：保持"="不变
4. **生活角度**：左右口袋同时放进 / 拿出相同钱

## 性质 1（加减）

```
   若 a = b，则
       a + c = b + c     （两边同加 c）
       a - c = b - c     （两边同减 c）
```

例：x + 5 = 12
两边同 -5：x + 5 - 5 = 12 - 5 → **x = 7**

## 性质 2（乘除）

```
   若 a = b，则
       a × c = b × c        （两边同乘 c）
       a ÷ c = b ÷ c       （两边同除 c，c ≠ 0）
```

例：3x = 18
两边同 ÷3：3x ÷ 3 = 18 ÷ 3 → **x = 6**

> ⚠️ **除时 c ≠ 0**

## 天平模型（直观理解）

```
       天平：左 = 右
       
       同时加 5g：左+5g = 右+5g  ✓ 仍平衡
       同时取 3g：左-3g = 右-3g  ✓ 仍平衡
       两边同 ×2：左×2 = 右×2    ✓ 仍平衡（拿等量物品）
       
       只在一边动 → ❌ 失衡（等式不成立）
```

## 解方程的本质：用等式性质化简

> ⭐ **解方程 = 利用等式性质，把方程"化"成 x = ...**

### 例 1：x + 7 = 15

两边同 -7：x = 15 - 7 = **8**

### 例 2：4x = 24

两边同 ÷4：x = 24 ÷ 4 = **6**

### 例 3：2x + 3 = 11（两步）

第 1 步（性质 1）：两边 -3
→ 2x = 8

第 2 步（性质 2）：两边 ÷2
→ x = **4**

### 例 4：（x - 5）× 3 = 12

第 1 步：两边 ÷3 → x - 5 = 4
第 2 步：两边 +5 → x = **9**

## 检验

> ⭐ 解出后**代回原方程**验证

例：解 4x = 24 得 x = 6
代回：4 × 6 = 24 ✓ → 解正确

## 常见陷阱

| 错误 | 正确 |
|------|------|
| 只对一边加减 | ❌ 错。**两边必须同时**做相同操作 |
| 等式两边同除以 0 | ❌ 错。0 不能作除数 |
| x + 5 = 12 → x = 12 + 5 | ❌ 错。该 - 5 而不是 + 5 |
| 3x = 18 → x = 18 + 3 | ❌ 错。该 ÷ 3 |
| 加减 / 乘除性质混 | 看清符号；含加减用性质 1，含乘除用性质 2 |
| 解出来不验证 | 必须代回原方程 |
