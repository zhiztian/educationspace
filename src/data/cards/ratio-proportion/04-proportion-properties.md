## 适用范围

- **讨论对象**：所有比例（已知或含未知数）
- **最容易误入的边界**：把外项积和内项积位置搞反；解出后忘验证

## 精确定义

> ⭐ **比例的基本性质**：在比例里，**两个外项的积 = 两个内项的积**

```
   a : b  =  c : d
   ↑     ↑
  外项  内项

   a × d  =  b × c
   外×外   =  内×内
```

> 等价形式：a/b = c/d ⇔ ad = bc

## 多角度逼近

1. **乘法守恒角度**：外×外 = 内×内 是比例最核心的等价条件
2. **判断角度**：判断两个比能否组比例 → 算外项积、内项积比一比
3. **解比例角度**：含 x 时用基本性质转成普通方程
4. **几何 / 实际角度**：相似图形 → 对应边比例 → 求未知边

## 用基本性质判断比例

`8 : 6 = 12 : 9` ?

- 外项积 = 8 × 9 = 72
- 内项积 = 6 × 12 = 72
- ✅ 相等 → 可组比例

## 解比例（用基本性质转方程）

### 例 1：内项含 x

`x : 6 = 4 : 3`
→ x × 3 = 6 × 4
→ 3x = 24
→ x = 8

### 例 2：外项含 x

`5 : x = 15 : 9`
→ 5 × 9 = 15x
→ 45 = 15x
→ x = 3

### 例 3：分数式

`1.5 / x = 0.6 / 2`
→ 1.5 × 2 = 0.6 × x
→ 3 = 0.6x
→ x = 5

### 例 4：已知部分关系

已知 x : y = 3 : 5，y = 20，求 x：
→ x : 20 = 3 : 5
→ 5x = 60
→ x = 12

## 解比例步骤总结

```
1. 用基本性质：外项积 = 内项积 → 写成普通方程
2. 解方程 → 求 x
3. 代回原比例验证
```

## 常见陷阱

| 错误 | 正确 |
|------|------|
| 外项 / 内项位置认错 | **两端 = 外项；中间 = 内项** |
| 算成 a × c = b × d | ❌ 错。是 **a × d = b × c**（外两端 vs 中两端） |
| `x : 6 = 4 : 3 → x = 4` | ❌ 错。要用 3x = 24 → x = 8 |
| 解出来不验证 | 代回原比例，比值是否相等 |
| 含小数 / 分数时不化简 | 解出 x 后要化简（如最简分数） |
