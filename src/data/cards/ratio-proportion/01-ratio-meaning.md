## 适用范围

- **讨论对象**：表示**两数之间的相除关系**（同类量或不同类量）
- **不讨论 / 排除**：体育比赛比分（不是相除关系）；后项为 0
- **最容易误入的边界**：把比赛比分当成数学的比；比的后项为 0

## 精确定义

**比**：两个数**相除**又叫这两个数的**比**。

```
   5 : 3       =  5 ÷ 3  =  5/3
   ↑   ↑
  前项 后项
       └─ 比号
```

> ⭐ **比的本质 = 除法的另一种写法**

## 多角度逼近

1. **除法角度**：a : b = a ÷ b
2. **分数角度**：a : b = a/b（b ≠ 0）
3. **倍数角度**：a : b 表示 a 是 b 的几倍 / 几分之几
4. **生活角度**：男女比例 / 配料比 / 速度（路程 : 时间）/ 单价（总价 : 数量）

## 比值

> **比值 = 前项 ÷ 后项 = a/b** —— 一个具体的数

| 比 | 比值 |
|----|------|
| 6 : 4 | 6 ÷ 4 = 3/2 = 1.5 |
| 1 : 4 | 1/4 = 0.25 |
| 3 : 1 | 3 |

> ⚠️ **比** 与 **比值** 不同：
> - **比** 是 a : b 形式（两数关系）
> - **比值** 是 a ÷ b 的结果（一个数）

## 同类量比 vs 不同类量比

| 类型 | 例 | 意义 |
|------|----|------|
| **同类量比** | 男生 : 女生 = 24 : 16 | 数量关系（同单位） |
| **不同类量比** | 路程 : 时间 = 120km : 2h | 比值有新意义（**速度** 60km/h） |
| 不同类量比的例 | 总价 : 数量 = **单价** | 工作量 : 时间 = **效率** |

## 比 / 除法 / 分数 关系表

| 概念 | 写法 | 各部分名称 |
|------|------|-----------|
| 除法 | a ÷ b | 被除数 / 除数 / 商 |
| 分数 | a/b | 分子 / 分母 / 分数值 |
| 比 | a : b | 前项 / 后项 / 比值 |

> **三者本质相同**，只是写法和侧重不同：
> - 除法 → **运算**
> - 分数 → **数**
> - 比 → **关系**

## 常见陷阱

| 错误 | 正确 |
|------|------|
| 比赛比分 5:3 是数学的比 | ❌ 错。比分是两数独立得分 |
| 比的后项 = 0（如 5:0） | ❌ 错。**后项不能为 0**（除数不能为 0） |
| 把比 6:4 和比值 1.5 等同 | 比是关系（两个数）；比值是一个数 |
| "比" = "差" | ❌ 错。比 = 相除；差 = 相减 |
| 倒数和反比混淆 | a:b 反过来是 b:a；和倒数概念**不同** |

## 与相邻概念关系

| 相邻概念 | 关系 |
|---------|------|
| 除法 / 分数 | 三者本质相通；比的性质 ↔ 商不变 / 分数基本性质 |
| 比例 | 表示**两个比相等**：a:b = c:d |
| 单位 1 | 在比中**后项**或**前后项之和**常做单位"1"  |
| 速度 / 单价 | 不同类量比，比值有具体含义 |
| 百分数 | a% 也可写成 a : 100 |
