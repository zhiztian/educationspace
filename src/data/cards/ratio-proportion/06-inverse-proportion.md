## 适用范围

- **讨论对象**：两个**相关联**的量
- **最容易误入的边界**：把"x 增 y 减"等同于反比例（不一定）；忽略"乘积定"这一条件

## 精确定义

> ⭐ **两个量成反比例**：两种**相关联**的量，一种变化另一种也变化，它们的**乘积一定（≠ 0）**。

```
   x × y = k （k 是定值，k ≠ 0）
   ↔
   y = k / x
```

| 关键词 | 说明 |
|-------|------|
| 相关联 | 一变另一也变 |
| **乘积一定** | 必须 xy 永远等于同一个常数 k |
| 反向 | x 增 → y 减；x 减 → y 增 |

## 多角度逼近

1. **乘积定**：xy = k（最严格的判断标准）
2. **变化方向**：x 增 y 减；x 减 y 增（**反向**）
3. **图像**：双曲线（一支在第一象限，不过原点）
4. **生活角度**：路程定的速度时间；总价定的单价数量；工作量定的人数天数

## 判断三步法

```
1. 两个量是否相关联？否 → 不成
2. 一增一减是否反向？反向 → 进入第 3 步
3. 它们的乘积是否始终相等？相等 → 成反比例
```

## 经典例子

| 关系 | 乘积 | 是否反比例 |
|------|-----|----------|
| 路程定，速度 ↔ 时间 | 速度 × 时间 = 路程（定） | ✅ |
| 总价定，单价 ↔ 数量 | 单价 × 数量 = 总价（定） | ✅ |
| 工作量定，效率 ↔ 时间 | 效率 × 时间 = 工作量（定） | ✅ |
| 长方形面积定，长 ↔ 宽 | 长 × 宽 = 面积（定） | ✅ |
| 总人数定，每组人数 ↔ 组数 | 每组×组数 = 总人数（定） | ✅ |
| 相邻：速度定，路程 ↔ 时间 | 路程/时间 = 速度（定） | ❌ 这是**正比例** |

## 图像特征

```
   y
   ↑
   │ \
   │  \
   │   \           ← 双曲线（一支）
   │    \
   │      \
   │         \____
   └──────────────→ x
   0   不过原点
```

> ⭐ 反比例图像：**双曲线**，**不过原点**

## 正比例 vs 反比例 对比

| 特征 | 正比例 | 反比例 |
|------|-------|-------|
| 关系式 | y/x = k | xy = k |
| 变化方向 | 同向（同增同减） | 反向（一增一减） |
| 图像 | 经过原点的直线 | 双曲线 |
| 关键词 | "比值一定" / "商一定" | "乘积一定" / "积一定" |
| 例 | 速度定的路程时间 | 路程定的速度时间 |

## 常见陷阱

| 错误 | 正确 |
|------|------|
| "x 增 y 减就是反比例" | ❌ 不一定。还要**乘积定** |
| `x + y = 10` 当反比例 | ❌ 错。反比例是**乘积**定，不是和定 |
| `y = 10 - x` 当反比例 | ❌ 错。这是减法关系，不是反比例 |
| 速度定的路程时间 → 反比例 | ❌ 错。**比值定 → 正比例** |
| k = 0 算反比例 | ❌ 错。k 必须 ≠ 0 |

## 与相邻概念关系

| 相邻概念 | 关系 |
|---------|------|
| 正比例 | 反比例的"对偶"：正定比值；反定乘积 |
| 比例 | 正反比例都涉及量与量的"等"关系 |
| 应用题 | 工程问题、行程"反追"问题用反比例求解 |
| 函数（中学） | 反比例 y = k/x 是基本初等函数之一 |
| 单价 / 工效 | 总量定时，单价 ↔ 数量、工效 ↔ 时间都是反比例 |
