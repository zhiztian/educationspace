## 适用范围

- **讨论对象**：两个**比值相等**的比组成的等式
- **不讨论 / 排除**：单个比（a:b 不是比例，是比）
- **最容易误入的边界**：把"比"和"比例"混用；忘了"比值相等"才能组比例

## 精确定义

**比例**：表示**两个比相等**的式子。

```
   a : b  =  c : d        或      a/b = c/d
   └─比─┘    └─比─┘                ↑
      └─两个比的比值相等─┘
```

例：`6 : 4 = 9 : 6`（都等于 3/2）

## 多角度逼近

1. **比值相等角度**：判断 a:b 与 c:d 能否组比例 → 看 a/b 是否等于 c/d
2. **几何角度**：相似图形对应边的比相等（构成比例）
3. **生活角度**：缩放图（地图、平面图、模型）；同一种饮料的不同包装单价
4. **方程角度**：含未知数的比例方程（如 x:4 = 3:2）

## 比例各部分名称

```
   8  :  6   =   12  :  9
   ↑     ↑       ↑      ↑
  外项  内项    内项   外项
```

> 两端的项叫 **外项**，中间的项叫 **内项**

例：`a : b = c : d` → 外项 a, d；内项 b, c

## 判断能否组比例的方法

### 方法 1：求比值（推荐）

`6:4 vs 9:6`
- 6 ÷ 4 = 1.5
- 9 ÷ 6 = 1.5
- 相等 → ✅ 可组比例

### 方法 2：化简比

化简后两个比相同 → 可组比例

`12:8` → 化简 = 3:2；`6:4` → 化简 = 3:2 → 相同 → ✅ 可组比例

### 方法 3：交叉相乘（外项积 vs 内项积，详见 rp-04）

外项积 = 内项积 → ✅ 可组比例

## 比 vs 比例（必须区分）

| 概念 | 形式 | 是 |
|------|------|----|
| **比** | a : b | 一个比，两个数的关系 |
| **比例** | a:b = c:d | 一个等式，两个比相等 |

## 比例的写法

两种等价写法：

```
   8 : 6 = 12 : 9       ← 横式
   或
   8     12
   ─  =  ──             ← 分数式
   6      9
```

## 常见陷阱

| 错误 | 正确 |
|------|------|
| "8:6 是比例" | ❌ 错。8:6 是**比**；比例是 a:b = c:d **等式** |
| 比值不等也组比例 | ❌ 错。**必须比值相等** |
| 只看一项相等就以为是比例 | 必须两个**比的整体**相等 |
| 内项 / 外项搞反 | 两端 = 外项；中间 = 内项 |
| 比例的"=" 当成估计 | 必须严格相等才是比例 |

## 与相邻概念关系

| 相邻概念 | 关系 |
|---------|------|
| 比 | 比例的"成分" |
| 比例的基本性质 | 外项积 = 内项积（见 rp-04） |
| 正比例 / 反比例 | 比例关系的特殊形式 |
| 解比例 | 用基本性质求未知项 |
| 相似 | 几何相似图形对应边成比例 |
