## 适用范围

- **讨论对象**：所有比（含整数 / 小数 / 分数 / 含单位的比）
- **最容易误入的边界**：单位不统一就化简；化简没到最简

## 精确定义

> ⭐ **比的基本性质**：比的前项和后项**同时乘 / 除以同一个不为 0 的数**，比值不变。

```
   a       a × n        a       a ÷ n
   ─  =  ─────────  =  ─  =  ─────────       (n ≠ 0)
   b       b × n        b       b ÷ n
```

## 多角度逼近

1. **基本性质角度**：和分数基本性质、商不变性质本质相同
2. **化简思想**：把比化为最简（前后项互质）
3. **乘 1 角度**：×n / ×n = ×1 → 数变了但比值没变
4. **生活角度**：1 元 : 5 角 → 单位统一为角 = 10 : 5 = 2 : 1

## 最简比

> ⭐ **最简比 ⇔ 前项和后项是互质的整数**

例：2:3、5:7、7:9 都是最简比；4:6、6:9、10:15 不是

## 化简比的方法

### 1. 整数比 → 同除以最大公因数

`12 : 18` → ÷ 6 → `2 : 3`

### 2. 小数比 → 先扩大成整数比

`0.4 : 0.6` → × 10 → `4 : 6` → ÷ 2 → `2 : 3`

### 3. 分数比 → 通分后取分子；或同乘公分母

| 方法 | `1/4 : 2/3` |
|------|-------------|
| 通分法 | 3/12 : 8/12 → 取分子 → 3 : 8 |
| 同乘公分母法 | × 12 → 3 : 8 |

### 4. 含单位的比 → 先统一单位

`0.5 米 : 25 厘米`
→ 0.5 米 = 50 厘米
→ 50 : 25 = 2 : 1

## 化简 vs 求比值

| 任务 | 操作 | 结果形式 |
|------|------|---------|
| 化简比 | 同除化最简 | **比的形式**（如 2 : 3） |
| 求比值 | 前项 ÷ 后项 | **一个数**（如 2/3） |

## 常见陷阱

| 错误 | 正确 |
|------|------|
| 单位不同直接化简（5 米 : 25 厘米 = 5 : 25） | ❌ 错。**先统一单位** |
| 化简到 4 : 6 就停了 | 必须**化到最简** → 2 : 3 |
| 把化简比写成小数（2 : 3 → 0.667） | 那是**比值**；化简结果应是 **整数比** 形式 |
| 同乘 / 除 0 | ❌ 错。**乘除的数必须非 0** |
| 加 / 减常数化简（6 : 9 → 5 : 8） | ❌ 错。比的性质讲**乘除**不是加减 |

## 与相邻概念关系

| 相邻概念 | 关系 |
|---------|------|
| 分数基本性质 | 同源；化简比 ↔ 约分 |
| 商不变性质 | 同源；除法版 |
| 比例 | 化简比常用来判断"两个比是否能组成比例" |
| 单位换算 | 含单位的比化简前必须统一单位 |
| 互质 | 最简比的判定依据 |
