## 适用范围

- **讨论对象**：两个**相关联**的量
- **最容易误入的边界**：把"两个量都变大"等同于"成正比例"（不一定）；忽略"比值定"这一关键条件

## 精确定义

> ⭐ **两个量成正比例**：两种**相关联**的量，一种变化另一种也跟着变化，它们的**比值（商）一定（≠ 0）**。

```
   y / x = k （k 是定值，k ≠ 0）
   ↔
   y = kx
```

| 关键词 | 说明 |
|-------|------|
| 相关联 | 一变另一也变 |
| **比值一定** | 必须 y/x 永远等于同一个常数 k |
| k ≠ 0 | k = 0 不是正比例 |

## 多角度逼近

1. **比值定**：y/x = k（最严格的判断标准）
2. **变化方向**：x 增 y 增；x 减 y 减（同向）
3. **图像**：经过原点 (0, 0) 的**直线**
4. **生活角度**：定速度的路程 / 时间；定单价的总价 / 数量

## 判断两个量是否成正比例（三步法）

```
1. 两个量是否相关联？  否 → 不成
2. 一变另一是否同向变？同向 → 进入第 3 步
3. 它们的比值是否始终相等？相等 → 成正比例
```

## 经典例子

| 关系 | 比值 | 是否正比例 |
|------|-----|----------|
| 速度定，路程 ↔ 时间 | 路程/时间 = 速度（定） | ✅ |
| 单价定，总价 ↔ 数量 | 总价/数量 = 单价（定） | ✅ |
| 边长 ↔ 周长（正方形） | 周长/边长 = 4（定） | ✅ |
| 半径 ↔ 圆周长 | 周长/半径 = 2π（定） | ✅ |
| 半径 ↔ 圆面积 | 面积/半径 = πr（不定） | ❌ |
| 时间一定，路程 ↔ 速度 | 路程/速度 = 时间（定） | ✅ |
| 长方形长一定，宽 ↔ 面积 | 面积/宽 = 长（定） | ✅ |

## 图像特征

```
   y
   ↑
   │           /
   │         /
   │       /  ← 经过原点的直线
   │     /
   │   /
   │ /
   └──────────→ x
   0
```

> ⭐ 正比例图像：**经过原点的一条直线**，斜率 = k

## 常见陷阱

| 错误 | 正确 |
|------|------|
| "x 增 y 增就是正比例" | ❌ 不一定。还要**比值定** |
| 圆的面积与半径成正比例 | ❌ 错。比值 πr 不是定值 |
| 加减关系（如 x + y = 10）当正比例 | 加减关系**不是**正比例 |
| k = 0 算正比例 | ❌ 错。**k 必须 ≠ 0** |
| 把"一变另一也变"误以为正比例 | 反比例也"一变另一变"；要看比值是否定 |

## 与相邻概念关系

| 相邻概念 | 关系 |
|---------|------|
| 反比例 | 正比例：比值定；反比例：乘积定 |
| 比例（rp-03） | 正比例本质就是 y:x = k:1 |
| 解比例 | 已知正比例求未知量 |
| 函数（中学） | 正比例是 y = kx 的最简函数 |
| 应用题 | 行程 / 单价 / 工程类常用正比例求解 |
