## 适用范围

- **讨论对象**：所有平面图形
- **最容易误入的边界**：底和高不对应；忘了 ÷ 2；梯形误认为平行四边形

## 精确定义

> ⭐ **面积**：物体表面或封闭图形的**大小**
> 单位：cm² / dm² / m² / 公顷 / km²

```
  1 m² = 100 dm² = 10000 cm²
  1 公顷 = 10000 m²
  1 km² = 100 公顷 = 1,000,000 m²
```

## 多角度逼近

1. **铺方格角度**：面积 = 单位方格的个数
2. **公式角度**：常见图形有简化公式
3. **变换角度**：复杂图形 → 转化为熟悉图形
4. **生活角度**：地板 / 墙面 / 田地 / 屏幕

## 常见图形面积公式（必背）

| 图形 | 公式 | 备注 |
|------|------|------|
| 正方形 | S = a² | 边长 × 边长 |
| 长方形 | S = a × b | 长 × 宽 |
| 平行四边形 | S = a × h | 底 × **对应**的高 |
| 三角形 | S = a × h ÷ 2 | 底 × 高 ÷ 2 |
| 梯形 | S = (a + b) × h ÷ 2 | (上底+下底) × 高 ÷ 2 |
| 圆 | S = πr² | π × 半径² |
| 半圆 | S = πr² ÷ 2 | 圆面积一半 |

## 公式推导链（理解 > 死记）

```
            ┌─────────────────┐
            │ 长方形 S = ab   │ ← 面积起点
            └─────────────────┘
                    │
        切割平移    │
                    ▼
         ┌────────────────┐
         │ 平行四边形      │ ← 切下三角形拼成长方形
         │ S = 底 × 高     │
         └────────────────┘
                    │
       两个相同拼合  │
                    ▼
         ┌────────────────┐    ┌────────────────┐
         │ 三角形          │    │ 梯形            │
         │ S = 底 × 高 ÷2  │    │ S=(上+下)×高÷2  │
         └────────────────┘    └────────────────┘
```

## 底和高必须对应

> ⭐ **底和高一定要垂直**

错误：用平行四边形的斜边当高
正确：必须是**底边上的垂直距离**

```
   平行四边形：取任一边为底 → 对应的高是该底上的垂线段
   三角形：3 个底 → 对应 3 条高（一个三角形有 3 组底高）
```

## 组合图形面积

### 方法 1：分割法

把组合图形分成几个熟悉图形，**面积相加**

```
   ┌─────┐
   │  A  │
   │     │_________
   │     │   B    │      S = S(A) + S(B)
   └─────┴────────┘
```

### 方法 2：添补法

补上一块凑成大图形，再**减掉**补的部分

```
   ┌────────────┐
   │            │
   │   ┌────────┘     S = S(整) - S(缺角)
   │   │
   └───┘
```

### 方法 3：等积变换

利用平行 / 旋转把不规则图形变成等面积的规则图形

## 单位换算

| 大单位 → 小单位 | 倍数 |
|---------------|------|
| 1 m² → cm² | × 10000 |
| 1 公顷 → m² | × 10000 |
| 1 km² → 公顷 | × 100 |

> ⚠️ **平方单位换算是 100 / 10000 倍**（不是 10）

## 周长 vs 面积易混题型

| 问 | 答 |
|---|---|
| 周长相同时，正方形和长方形哪个面积大？ | 正方形（长宽越接近面积越大） |
| 面积相同时，正方形和长方形哪个周长小？ | 正方形（长宽相等周长最小） |
| 圆和正方形周长相同，谁面积大？ | **圆面积更大**（同周长下圆面积最大） |

## 常见陷阱

| 错误 | 正确 |
|------|------|
| 平行四边形 S = 底 × 邻边 | ❌ 错。是 **底 × 对应的高** |
| 三角形 S = 底 × 高 | ❌ 错。**还要 ÷ 2** |
| 梯形 S = (上+下) × 高 | ❌ 错。**还要 ÷ 2** |
| 1 m² = 100 cm² | ❌ 错。1 m² = **10000** cm² |
| 周长一样面积一定一样 | ❌ 错（参见 gp-07） |
| 圆面积 = 2πr | ❌ 错。2πr 是**周长** |

## 与相邻概念关系

| 相邻概念 | 关系 |
|---------|------|
| 周长 | 不同维度，单位不同 |
| 体积 / 表面积 | 立体图形版本，每面用面积公式 |
| 单位换算 | 平方单位 100 / 10000 倍 |
| 比例 | 相似图形面积比 = 边长比的平方 |
| 应用题 | 田地 / 装修 / 油漆 / 草坪 |
