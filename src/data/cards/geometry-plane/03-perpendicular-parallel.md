## 适用范围

- **讨论对象**：**同一平面内**两条直线的位置关系
- **不讨论 / 排除**：异面直线（中学内容）
- **最容易误入的边界**：忘了"同一平面内"前提；垂直只看相交不看 90°

## 精确定义

> ⭐ **垂直**：两条直线相交成**直角**（90°），称这两条直线互相垂直，记作 a ⊥ b
> ⭐ **平行**：在**同一平面内**不相交的两条直线，称为互相平行，记作 a ∥ b

```
   垂直                       平行
   │                         ─────────
   │                         
 ──┼──   ⊥                   ─────────
   │
```

## 多角度逼近

1. **角度角度**：垂直 = 相交且角 = 90°
2. **距离角度**：平行 = 同方向永不相遇 = 距离永远相等
3. **画法角度**：用三角板的直角画垂线；用直尺平移画平行线
4. **生活角度**：墙角是垂直；铁路两轨是平行；楼梯扶手与地面平行

## 同一平面内两条直线位置关系

```
            两条直线
               │
       ┌───────┴───────┐
       │               │
      相交            不相交
       │               │
   ┌───┴───┐         平行
   │       │
  斜交   垂直（90°）
```

## 重要性质

| 性质 | 内容 |
|------|------|
| 过点画垂线 | 过直线外一点 / 直线上一点 → **有且只有 1 条**垂线 |
| 过点画平行线 | 过直线外一点 → **有且只有 1 条**平行线 |
| 平行传递 | 同时平行于第三条 → 两直线**平行** |
| 垂直传递 | 同时垂直于第三条 → 两直线**平行**（同一平面内） |
| 平行间距 | 平行线间距离**处处相等** |

## 点到直线的距离

> ⭐ **最短距离**：从点向直线作**垂线段**，这条线段的长度即"点到直线的距离"

```
   • A
   |\
   | \
   |  \         ← 斜的都比垂线长
   ↓   \
   ──────────  直线 l
   ↑
   垂足
   
   AC（垂线段）= 点 A 到 l 的距离
```

> 直线外一点到直线上各点连线中，**垂线段最短**

## 画垂线 / 平行线

### 画垂线（用三角板）

```
1. 三角板的一条直角边贴住已知直线
2. 沿另一条直角边画线
3. 标垂直符号 ⊥
```

### 画平行线（用直尺 + 三角板）

```
1. 直尺贴住已知直线
2. 三角板贴住直尺，沿三角板边画一条线
3. 平移三角板（直尺不动），再画一条 → 平行
```

## 常见陷阱

| 错误 | 正确 |
|------|------|
| 忘"同一平面内" | 不在同一平面 → **既不平行也不相交**（异面） |
| "相交就是垂直" | ❌ 错。必须是**直角**（90°）才垂直 |
| "平行 = 不会碰" | 还得在**同一平面**内才叫平行 |
| 距离用斜线段量 | ❌ 错。距离 = **垂线段**长度 |
| 平行符号写成 = | 平行符号是 **∥**（两根竖线） |

## 与相邻概念关系

| 相邻概念 | 关系 |
|---------|------|
| 角 | 垂直要求两线夹角为 90° |
| 长方形 / 正方形 | 对边平行；邻边垂直 |
| 平行四边形 | 两组对边分别平行 |
| 梯形 | 一组对边平行，一组不平行 |
| 三角形高 | 从顶点向对边（或延长线）作**垂线段** |
