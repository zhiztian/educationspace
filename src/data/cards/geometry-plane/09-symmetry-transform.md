## 适用范围

- **讨论对象**：图形在平面内的位置变化
- **不变量**：形状、大小（这三种变换都不改变形状大小）
- **最容易误入的边界**：把"中心对称"和"轴对称"混；以为平行四边形是轴对称

## 精确定义

| 变换 | 定义 | 不变 | 变 |
|------|------|------|----|
| **平移** | 沿某方向移动一段距离 | 形状、大小、方向 | 位置 |
| **旋转** | 绕某点（旋转中心）转动 | 形状、大小 | 位置、方向 |
| **轴对称** | 沿一条直线对折两侧重合 | 形状、大小 | 左右翻转 |

## 多角度逼近

1. **运动角度**：平移是平动；旋转是转动；对称是翻折
2. **不变量**：三种变换都**保形保大小**（即"全等变换"）
3. **三要素**：平移 = 方向+距离；旋转 = 中心+方向+角度；对称 = 对称轴
4. **生活角度**：电梯（平移）、风扇（旋转）、蝴蝶（对称）

## 轴对称图形

> ⭐ **沿一条直线对折，两侧能完全重合**的图形叫**轴对称图形**
> 这条直线叫**对称轴**

```
        │
        │
    ◢───┤───◣
   ╱    │    ╲       折痕 = 对称轴
   ╲    │    ╱       两侧完全重合
    ◥───┤───◤
        │
```

### 常见图形对称轴数量（必背）

| 图形 | 对称轴数 |
|------|---------|
| 等腰三角形 | 1 |
| 等边三角形 | 3 |
| 长方形 | 2（横竖两条） |
| 正方形 | 4 |
| 菱形 | 2（两对角线） |
| 一般平行四边形 | **0**（不是轴对称） |
| 等腰梯形 | 1 |
| 圆 | **无数条**（任一过圆心的直线） |
| 正 n 边形 | n 条 |

## 平移

> ⭐ **沿一定方向、移动一定距离**

```
    □ ────→ □       水平向右平移 5 格
    
    □
    ↓
    □          竖直向下平移 3 格
```

**画平移图**：
1. 找出图形上几个关键点
2. 各关键点按相同方向、相同距离平移
3. 连接对应点

> 平移**不改变方向**（A 朝上，平移后仍朝上）

## 旋转

> ⭐ 三要素：**旋转中心 + 旋转方向 + 旋转角度**

| 方向 | 含义 |
|------|------|
| 顺时针 | 与时针走向相同 |
| 逆时针 | 与时针走向相反 |

```
   绕 O 顺时针旋转 90°
              ●
              │
        ●─────● ────→ ●─────●
                      │
                      ●
```

**画旋转图**（绕一点旋转）：
1. 关键点到中心的距离不变
2. 每个关键点都旋转**相同角度**
3. 连接对应点

## 三种变换对比

| 项目 | 平移 | 旋转 | 轴对称 |
|------|------|------|-------|
| 移动方式 | 平动 | 转动 | 翻折 |
| 改变方向 | ❌ | ✅ | ✅（左右翻） |
| 形状大小 | 不变 | 不变 | 不变 |
| 三要素 | 方向+距离 | 中心+方向+角度 | 对称轴 |
| 生活例子 | 电梯 | 风扇 | 蝴蝶 |

## 常见陷阱

| 错误 | 正确 |
|------|------|
| "平行四边形是轴对称" | ❌ 错。**一般平行四边形不是**（折不重合） |
| 圆只有 1 条对称轴 | ❌ 错。**无数条**（任一过圆心的直线） |
| 平移会让图形翻转 | ❌ 错。平移**不改变方向** |
| 旋转 90° 不指方向 | 必须说**顺时针/逆时针** |
| 长方形对称轴是对角线 | ❌ 错。是**横竖中线**（不是对角线） |
| 正方形对称轴 2 条 | ❌ 错。**4 条**（2 横竖 + 2 对角线） |

## 与相邻概念关系

| 相邻概念 | 关系 |
|---------|------|
| 全等 | 三种变换都得**全等**图形 |
| 相似 | 缩放变换 → 相似（形状同大小不同） |
| 周长 / 面积 | 变换前后**周长面积都不变** |
| 中心对称（中学） | 旋转 180° = 中心对称 |
| 美术 / 设计 | 图案设计常用三种变换 |
