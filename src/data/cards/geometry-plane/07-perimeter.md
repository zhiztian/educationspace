## 适用范围

- **讨论对象**：所有**封闭**平面图形
- **不讨论 / 排除**：开放折线（不封闭无周长）
- **最容易误入的边界**：周长与面积单位混淆；组合图形漏边

## 精确定义

> ⭐ **周长**：封闭图形**一周的长度** = 所有边长之和
> 单位：长度单位（cm / m / dm / km 等）

```
   方形 / 三角形 / 多边形：所有边相加
   圆形：用周长公式 C = πd
```

## 多角度逼近

1. **求和角度**：所有边长之和
2. **量绳角度**：用绳子围一圈再量绳长
3. **公式角度**：常见图形有简化公式
4. **生活角度**：相框周长、跑道周长、栅栏长度

## 常见图形周长公式

| 图形 | 公式 |
|------|------|
| 正方形 | C = 边长 × 4 = **4a** |
| 长方形 | C = (长 + 宽) × 2 = **2(a+b)** |
| 三角形 | C = a + b + c |
| 平行四边形 | C = (邻边和) × 2 = 2(a+b) |
| 菱形 | C = 边长 × 4 |
| 圆 | C = πd = 2πr |
| 半圆 | C = πr + d（弧长 + 直径） |

## 组合图形周长

> ⭐ **窍门**：把"凹陷"的边平移，合并成大长方形 / 正方形的边

例：L 形 → 平移凹边后等于大长方形周长（不是加多边）

```
   ┌──────┐
   │      │
   │   ┌──┘
   │   │           凹陷部分两条短边平移合并
   │   │           ⇒ 周长 = 大长方形周长
   └───┘
```

## 周长 vs 面积（核心区分）

| 项目 | 周长 | 面积 |
|------|------|------|
| 是什么 | 一周长度 | 一面大小 |
| 单位 | cm, m | cm², m² |
| 公式 | 加（或加 + 乘） | 乘 |
| 运算结果 | 长度 | 面积量 |

> ⭐ **周长一样不一定面积一样；面积一样不一定周长一样**

例：周长 = 20 的长方形 → 长×宽 可以是 9×1 (S=9) 或 5×5 (S=25)
→ 周长不变，面积变化

## "周长不变面积最大"问题

> 长 + 宽 = 定值时，**长 = 宽**（即正方形）面积最大

例：周长 = 20 cm（长+宽=10）的最大长方形是 5×5 = 25 cm²

> 反过来：**面积一定时，正方形周长最小**（节省材料）

## 常见陷阱

| 错误 | 正确 |
|------|------|
| 长方形 C = 长 × 宽 | ❌ 错。**长 + 宽**（不是乘）再 ×2 |
| 周长单位写 cm² | ❌ 错。周长用 **长度单位** cm 不带平方 |
| 圆周长 C = πr² | ❌ 错。πr² 是**面积**；周长 = 2πr |
| 半圆周长漏直径 | 半圆 = 半弧 + 直径，**不能只算 πr** |
| 周长不变面积也不变 | ❌ 错。可变（详见上面表） |
| 组合图形死算每段 | 巧用平移合并；少加错少漏 |

## 与相邻概念关系

| 相邻概念 | 关系 |
|---------|------|
| 面积 | 不同维度（长度 vs 平方）；公式不同 |
| 长度单位 | 周长用长度单位计算 |
| 各种四边形 | 公式因图形不同 |
| 圆 | 周长公式涉及 π |
| 应用题 | 围栅栏 / 相框 / 跑道场景 |
