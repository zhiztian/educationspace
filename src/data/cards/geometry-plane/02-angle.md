## 适用范围

- **讨论对象**：两条有公共端点的射线之间的张口
- **最容易误入的边界**：把"边长"等同于"角的大小"

## 精确定义

> ⭐ **角**：由**两条有公共端点的射线**组成的图形
> 公共端点 = **顶点**；两条射线 = **边**

```
        / ← 边
       /
      /  ∠
     /    } 张口越大，角越大
    /─────  ← 边
   ↑
  顶点
```

## 多角度逼近

1. **形态角度**：两条射线 + 公共端点
2. **度量角度**：用度（°）；1 周角 = 360°
3. **大小本质**：张口度，**与边长无关**
4. **生活角度**：剪刀、钟表指针、椅子打开角

## 角的分类

| 名称 | 范围 | 图示 |
|------|------|------|
| 锐角 | 0° < x < 90° | 小于直角 |
| 直角 | = 90° | ⊥ |
| 钝角 | 90° < x < 180° | 大于直角小于平角 |
| 平角 | = 180° | 一条直线 |
| 周角 | = 360° | 转一整圈 |

> 1 周角 = 2 平角 = 4 直角

## 量角器使用

```
1. 顶点 → 量角器中心点（小孔）
2. 一条边 → 0°刻度线
3. 另一条边 → 读对应刻度
4. 内圈 vs 外圈：看 0°在哪圈，就读哪圈
```

## 角的画法

例：画 65° 角

```
1. 画一条射线 OA
2. 量角器中心对 O，0°对 OA
3. 在 65° 刻度处点 B
4. 连 OB → 角 AOB = 65°
```

## 钟表角换算

```
钟面共 360°，12 个数 → 每两数之间 30°
1 小时（分针走 1 圈）= 360°
1 分钟（分针走 1 格）= 6°
时针 1 小时 = 30°；时针 1 分钟 = 0.5°
```

## 常见陷阱

| 错误 | 正确 |
|------|------|
| "边越长角越大" | ❌ 错。**与边长无关** |
| 量角器读错圈（内/外） | 看 0°所在圈 → 读那一圈 |
| "钝角 + 锐角 = 平角" | ❌ 不一定。85°+95°=180° 是平角，但 60°+95°=155° 不是 |
| 把"直线"当"平角" | 平角是**两条射线方向相反**的角；直线没顶点 |
| 量出 100°，写成 80° | 内/外圈混了。再确认 0°的方向 |

## 与相邻概念关系

| 相邻概念 | 关系 |
|---------|------|
| 直线 / 射线 | 角的边是射线 |
| 垂直 | 两条直线相交成 90°角 |
| 三角形 | 三个内角和 = 180° |
| 旋转 | 旋转角度可用周角分割 |
| 钟表问题 | 时针 / 分针角速度差 |
