## 适用范围

- **讨论对象**：平面上到一定点距离相等的所有点构成的封闭曲线图形
- **最容易误入的边界**：把直径 r 用错；把面积公式记成 πd²

## 精确定义

> ⭐ **圆**：平面上**到一定点（圆心）距离相等的所有点**构成的封闭曲线
> **圆心** O：圆的中心
> **半径** r：圆心到圆上任一点的距离
> **直径** d：通过圆心、两端在圆上的线段（最长的弦）

```
              ╭─────╮
            ╱         ╲
          │   r↗      │       O = 圆心
          │  O ─── ●  │       r = OA（半径）
          │    \      │       d = AB（直径，过 O）
            ╲   \   ╱
              ╰─────╯
```

> ⭐ **同一圆内：所有半径相等；所有直径相等；d = 2r**

## 多角度逼近

1. **集合角度**：到圆心距离 = r 的所有点
2. **运动角度**：固定一端、另一端绕动一圈
3. **比值角度**：周长 / 直径 = π（恒定）
4. **生活角度**：硬币、车轮、井盖（井盖做圆形 → 不会掉下去）

## π（圆周率）

> ⭐ **π = 圆的周长 ÷ 直径** = 一个常数（无理数）
> 常用 **π ≈ 3.14**（小学）；中学 ≈ 3.14159…

| 常用 π 倍数（必背） |
|---|
| π ≈ 3.14 |
| 2π ≈ 6.28 |
| 3π ≈ 9.42 |
| 4π ≈ 12.56 |
| 5π ≈ 15.7 |
| 6π ≈ 18.84 |
| 9π ≈ 28.26 |
| 16π ≈ 50.24 |
| 25π ≈ 78.5 |

## 圆的周长

> ⭐ **C = πd = 2πr**

例：r = 5 cm → C = 2 × 3.14 × 5 = 31.4 cm

## 圆的面积

> ⭐ **S = πr²**

```
推导：把圆分成无数等分扇形 → 拼成近似长方形
长方形：长 = 半周长 = πr；宽 = 半径 r
面积 = πr × r = πr²
```

例：r = 4 cm → S = 3.14 × 16 = 50.24 cm²

## 半径变化对周长 / 面积的影响

| r → kr（半径扩大 k 倍） | C → kC（周长扩大 k 倍） | S → k²S（面积扩大 k² 倍） |

| 半径变化 | 周长变化 | 面积变化 |
|---------|---------|---------|
| × 2 | × 2 | **× 4** |
| × 3 | × 3 | **× 9** |
| × 5 | × 5 | **× 25** |

## 已知周长求半径 / 面积

```
1. r = C ÷ (2π)
2. S = πr²
```

例：C = 18.84 cm
→ r = 18.84 ÷ 6.28 = 3 cm
→ S = 3.14 × 9 = 28.26 cm²

## 已知面积求半径 / 周长

```
1. r² = S ÷ π → r = √(S/π)
2. C = 2πr
```

例：S = 78.5 cm²
→ r² = 78.5 ÷ 3.14 = 25 → r = 5 cm
→ C = 2 × 3.14 × 5 = 31.4 cm

## 常见陷阱

| 错误 | 正确 |
|------|------|
| S = πd² | ❌ 错。S = π**r²**（不是 d²）|
| S = 2πr | ❌ 错。2πr 是**周长**不是面积 |
| 半径扩大 2 倍，面积扩大 2 倍 | ❌ 错。面积扩大 **4 倍**（平方关系） |
| C = πr | ❌ 错。C = **2π**r（少了 2） |
| 把 π 当 3 算 | 课内通常 π = 3.14；π = 3 是粗略估算 |
| 直径用 = 周长 ÷ 2 | ❌ 错。**直径 = 周长 ÷ π**，不是 ÷ 2 |

## 与相邻概念关系

| 相邻概念 | 关系 |
|---------|------|
| 周长 / 面积 | 圆是周长 / 面积公式专题之一 |
| 圆柱 / 圆锥 | 底面是圆；表面积、体积都用 πr² |
| 扇形 | 圆的一部分（圆心角占比） |
| 对称 | 圆有**无数条**对称轴（任一过圆心的直线） |
| 比例 | 半径 : 直径 = 1 : 2（恒定） |
