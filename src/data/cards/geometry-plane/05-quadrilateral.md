## 适用范围

- **讨论对象**：四条线段首尾相连组成的封闭图形
- **最容易误入的边界**：包含关系搞反（认为长方形不是平行四边形）

## 精确定义

| 名称 | 定义 |
|------|------|
| 四边形 | 由 4 条线段首尾相连围成的封闭图形 |
| 平行四边形 | 两组对边**分别平行**的四边形 |
| 长方形 | 4 个角都是**直角**的平行四边形 |
| 正方形 | 4 边相等且 4 角都是直角的四边形 |
| 梯形 | **只有一组**对边平行的四边形 |

## 包含关系图（必背）

```
            四边形
           /      \
          /        \
   平行四边形      梯形
       │
       ▼
     长方形
       │
       ▼
     正方形
```

> ⭐ **正方形 ⊂ 长方形 ⊂ 平行四边形 ⊂ 四边形**
> ⭐ **梯形 ⊂ 四边形** 但梯形 **不属于** 平行四边形

## 各四边形性质对比

| 性质 | 平行四边形 | 长方形 | 正方形 | 梯形 |
|------|----------|-------|-------|------|
| 对边平行 | 两组 | 两组 | 两组 | 一组 |
| 对边相等 | 两组 | 两组 | 两组（4边都等） | 不一定 |
| 对角相等 | ✅ | ✅（都90°） | ✅（都90°） | 不一定 |
| 4 角都 90° | ❌ | ✅ | ✅ | ❌ |
| 4 边相等 | ❌ | ❌ | ✅ | ❌ |
| 对角线相等 | ❌ | ✅ | ✅ | 等腰梯形 |
| 对角线互相平分 | ✅ | ✅ | ✅ | ❌ |
| 对角线互相垂直 | ❌ | ❌ | ✅ | ❌ |
| 稳定性 | ❌ | ❌ | ❌ | ❌ |

## 平行四边形

```
   A___________B
   /          /          AB ∥ CD, AD ∥ BC
  /          /           AB = CD, AD = BC
 /__________/            ∠A = ∠C, ∠B = ∠D
D            C
```

> 不稳定 → 容易变形（推拉门、扩缩晾衣架、伸缩护栏）

## 梯形

```
   ____上底____
  /            \
 /              \         上底 ∥ 下底
 \                \       两腰可以等也可以不等
  \________________\
       下底
```

| 类型 | 特征 |
|------|------|
| 一般梯形 | 两腰不等 |
| 等腰梯形 | **两腰相等**；底角相等；对角线相等 |
| 直角梯形 | 一条腰 ⊥ 上下底（**有两个直角**） |

## 内角和

| 图形 | 内角和 |
|------|-------|
| 三角形 | 180° |
| 四边形 | **360°** |
| 五边形 | 540° |
| n 边形 | (n-2) × 180° |

> 推理：四边形可沿一条对角线分成两个三角形

## 常见陷阱

| 错误 | 正确 |
|------|------|
| "长方形不是平行四边形" | ❌ 错。长方形**是**特殊平行四边形 |
| "正方形不是长方形" | ❌ 错。正方形**是**特殊长方形 |
| "梯形是特殊平行四边形" | ❌ 错。梯形只有 1 组对边平行 |
| 平行四边形稳定 | ❌ 错。**不稳定**（与三角形对比） |
| "等腰梯形腰=底" | ❌ 错。等腰梯形是**两腰相等**，腰和底通常不等 |

## 与相邻概念关系

| 相邻概念 | 关系 |
|---------|------|
| 平行 / 垂直 | 定义中用到的核心 |
| 三角形 | 平行四边形 = 两个全等三角形 |
| 周长 / 面积 | 各四边形面积公式不同 |
| 立体图形 | 长方体的面是长方形；正方体的面是正方形 |
| 对称 | 长方形 / 正方形 / 等腰梯形都是轴对称图形 |
