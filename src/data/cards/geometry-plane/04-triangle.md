## 适用范围

- **讨论对象**：三条线段首尾相连组成的封闭图形
- **最容易误入的边界**：忽视"两边之和 > 第三边"；以为内角和不是 180°

## 精确定义

> ⭐ **三角形**：由**三条线段首尾相连**围成的封闭图形

```
        A
        /\
       /  \           边：AB / BC / AC
      /    \          顶点：A / B / C
     /      \         角：∠A / ∠B / ∠C
    /________\
   B          C
```

## 多角度逼近

1. **角度角度**：内角和 = 180°
2. **边角度**：任意两边之和 > 第三边
3. **分类角度**：按角 / 按边
4. **稳定性**：三角形是**最稳定**的几何图形（自行车、铁塔常用）

## 三角形分类

### 按角分

| 名称 | 特征 |
|------|------|
| 锐角三角形 | 三个角都 < 90° |
| 直角三角形 | 有一个角 = 90°（其他两个互余） |
| 钝角三角形 | 有一个角 > 90° |

> 一个三角形最多有 **1 个**直角或钝角

### 按边分

| 名称 | 特征 |
|------|------|
| 不等边三角形 | 三边都不等 |
| 等腰三角形 | 至少两边相等（**两腰** + 1 底；两底角相等） |
| 等边三角形 | 三边都相等（也是等腰；三角都 60°） |

> 等边 ⊂ 等腰

## 重要性质

### 1. 内角和 = 180°（最重要）

```
   ∠A + ∠B + ∠C = 180°
```

### 2. 三边关系

> ⭐ **任意两边之和 > 第三边**
> 等价：**任意两边之差 < 第三边**

判断 3 边能否构成三角形：只需检查**最小两边之和是否大于最大边**

例：3, 4, 8 → 3+4 = 7 < 8 → ❌
例：5, 6, 8 → 5+6 = 11 > 8 ✅

### 3. 高 / 底

> 从一个顶点向**对边**（或对边的延长线）作**垂线段**叫该边上的高
> 一个三角形有 **3 条高**（每边对应一条）

```
       A
       /|\
      / | \           AD ⊥ BC
     /  |  \          AD = BC 边上的高
    /   |   \         BC = 底
   /____|____\
  B     D     C
```

## 三角形稳定性

> ⭐ 三角形具有**稳定性**：三边一定，形状大小完全确定（不变）

应用：自行车架、电塔、晾衣架、屋顶斜撑都用三角形

## 常见陷阱

| 错误 | 正确 |
|------|------|
| "5 cm + 6 cm + 12 cm 可构成三角形" | ❌ 错。5+6 < 12 |
| "三角形可以有两个直角" | ❌ 错。两个直角已 180°，第三角 = 0 |
| 等腰三角形腰当底 | 腰 = 相等的两条边；底 = 第三条 |
| 等边三角形不是等腰 | 等边⊂等腰；**是**等腰的特例 |
| 高画到底边外面就不算 | 钝角三角形的两条高确实在三角形外，**用延长线**作 |

## 与相邻概念关系

| 相邻概念 | 关系 |
|---------|------|
| 角 | 三个内角，和 180° |
| 平行四边形 | 沿对角线一分为二 = 两个全等三角形 |
| 多边形 | n 边形可分成 (n-2) 个三角形 |
| 面积 | S = 底 × 高 ÷ 2 |
| 直角三角形 | 中学勾股定理基础 |
