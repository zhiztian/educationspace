## 适用范围

- **讨论对象**：图形最基本的几何元素
- **不讨论 / 排除**：曲线、折线
- **最容易误入的边界**：把直线 / 射线说成"长度无限"但又试图量长

## 精确定义

> ⭐ **线段**：两个端点之间的部分，**有限长**
> ⭐ **射线**：一个端点 + 一端无限延伸
> ⭐ **直线**：没有端点 + 两端无限延伸

```
   线段 ●━━━━━●            ← 两端有点
   射线 ●━━━━━━──→         ← 一端有点
   直线 ←━━━━━━━━━→         ← 两端无点
```

| 名称 | 端点数 | 是否可测长度 | 表示 |
|------|-------|------------|------|
| 线段 | 2 | ✅ 可以 | 线段 AB（或 AB） |
| 射线 | 1 | ❌ 不能 | 射线 OA（O 是端点） |
| 直线 | 0 | ❌ 不能 | 直线 AB（任两点） |

## 多角度逼近

1. **端点角度**：0 / 1 / 2 个端点 → 直线 / 射线 / 线段
2. **延伸角度**：两端无限 / 一端无限 / 都有限
3. **测量角度**：只有线段可以量长度
4. **生活角度**：手电筒光线 ≈ 射线；铁路两轨 ≈ 直线；尺子的一段 ≈ 线段

## 经过点画线的规律

| 几何对象 | 条数 |
|---------|------|
| 经过 1 点画直线 | **无数条** |
| 经过 2 点画直线 | **有且只有 1 条** |
| 经过 1 点画线段 | 无数条（端点都不同） |
| 经过 2 点画线段 | **有且只有 1 条** |

## 表示符号

```
   线段 AB（有时写 |AB| 表示长度）
   射线 OA（O 必须是端点）
   直线 AB 或 直线 l
```

## 常见陷阱

| 错误 | 正确 |
|------|------|
| "射线有 2 个端点" | ❌ 错。**只有 1 个**端点 |
| "直线长 5 cm" | ❌ 错。直线没长度（无限） |
| "射线 AB 和 射线 BA 是同一条" | ❌ 错。**端点不同 → 不是同一条**（方向反） |
| "经过 2 点能画无数条直线" | ❌ 错。**只能画 1 条** |
| 把"曲线"算入直线 | ❌ 错。直线必须**直** |

## 与相邻概念关系

| 相邻概念 | 关系 |
|---------|------|
| 角 | 由两条**射线**+ 公共端点（顶点）组成 |
| 平行 / 垂直 | 描述**两条直线**的相对关系 |
| 多边形 | 由若干**线段**首尾相连 |
| 长度测量 | 测的是**线段**长度，不是直线 |
