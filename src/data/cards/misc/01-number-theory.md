## 适用范围

- **讨论对象**：整数的整除性 / 因数倍数 / 质合数
- **最容易误入的边界**：1 是质数（错）；GCD vs LCM 搞反

## 精确定义

> ⭐ **因数 / 倍数**：a × b = c（整数），a 和 b 是 c 的因数，c 是它们的倍数
> ⭐ **质数**：> 1 且只有 1 和本身两个因数
> ⭐ **合数**：> 1 且除 1 和本身外还有其他因数

## 多角度逼近

1. **整除角度**：a ÷ b 无余 ↔ b 是 a 的因数
2. **乘积角度**：c = ab 给出因数
3. **分解角度**：质因数分解 c = 2^a × 3^b × ...
4. **集合角度**：公因数 / 公倍数 = 集合交并

## 因数的特点

| 特点 | 说明 |
|------|------|
| 最小 | 1（每个数都有因数 1）|
| 最大 | 它本身 |
| 数量 | 有限 |
| 找法 | 一对一对找：1×n, 2×(n/2)...至 √n |

例：找 36 的因数
- 1×36, 2×18, 3×12, 4×9, 6×6
- 因数：1, 2, 3, 4, 6, 9, 12, 18, 36（共 9 个）

## 倍数的特点

| 特点 | 说明 |
|------|------|
| 最小 | 它本身 |
| 最大 | 无（无限）|
| 找法 | ×1, ×2, ×3... |

例：6 的倍数：6, 12, 18, 24, 30, ...

## 整除性判断（必背）

| 倍数 | 判断方法 |
|------|------|
| 2 | 末位是偶数（0,2,4,6,8）|
| 3 | 各位数字之**和**能被 3 整除 |
| 4 | 末两位组成的数能被 4 整除 |
| 5 | 末位是 0 或 5 |
| 6 | 同时是 2 和 3 的倍数 |
| 9 | 各位数字之和能被 9 整除 |
| 10 | 末位是 0 |

例：判 1245 是否被 3 整除
- 1+2+4+5 = 12 → 是 3 倍数 ✓

## 质数 / 合数

| 类型 | 定义 |
|------|------|
| 质数 | 因数只有 **1 和本身** 两个 |
| 合数 | 因数 **多于 2 个** |
| 1 | **既不是**质数也不是合数 |
| 0 | 一般不讨论 |
| 偶质数 | **只有 2** |

## 质因数分解

> 任何合数都可以分解为**质数的乘积**（短除法）

例：60 = ?

```
60
├ 2 → 30
   ├ 2 → 15
      ├ 3 → 5
          └ 5

60 = 2 × 2 × 3 × 5 = 2² × 3 × 5
```

## 公因数 / 最大公因数（GCD）

> 两个数**共同的因数** = 公因数；最大的叫 **GCD**

例：12 和 18

- 12 因数：1, 2, 3, 4, 6, 12
- 18 因数：1, 2, 3, 6, 9, 18
- 公因数：1, 2, 3, 6
- **GCD = 6**

### 短除法求 GCD

```
   2 | 12  18
   3 |  6   9
   ----+---------
       2   3   ← 互质，停

GCD = 2 × 3 = 6
```

## 公倍数 / 最小公倍数（LCM）

> 两数**共同的倍数** = 公倍数；最小的叫 **LCM**

例：4 和 6

- 4 倍数：4, 8, 12, 16, 20, 24, ...
- 6 倍数：6, 12, 18, 24, ...
- 公倍数：12, 24, ...
- **LCM = 12**

### 短除法求 LCM

```
   2 | 12  18
   3 |  6   9
   ----+---------
       2   3

LCM = 2 × 3 × 2 × 3 = 36
```

## GCD × LCM 关系

> ⭐ **GCD(a,b) × LCM(a,b) = a × b**

例：12 × 18 = 216 = 6 × 36 ✓

## 互质数

> ⭐ **GCD = 1** 的两数叫互质

例：(8, 9)、(7, 11)、(15, 28) 都是互质

> ⚠️ 互质不要求是质数

## 奇偶性

| 类 | 特点 |
|---|------|
| 奇 | 末位 1, 3, 5, 7, 9 |
| 偶 | 末位 0, 2, 4, 6, 8（含 0）|
| 0 | **是偶数** |

### 运算

| 运算 | 结果 |
|------|------|
| 奇 + 奇 | 偶 |
| 奇 + 偶 | 奇 |
| 偶 + 偶 | 偶 |
| 奇 × 奇 | 奇 |
| 奇 × 偶 | 偶 |
| 偶 × 偶 | 偶 |

## 常见陷阱

| 错误 | 正确 |
|------|------|
| 1 是质数 | ❌ 错。**既不质也不合** |
| 2 不是质数（觉得是偶数）| ❌ 错。**2 是唯一偶质数** |
| 因数 = 倍数 | 是相反关系 |
| GCD 用所有除数和商相乘 | 短除法 GCD 只乘**除数** |
| LCM 只乘除数 | LCM = 除数 × 最后**所有商** |
| 偶数不含 0 | 0 **是**偶数 |
| 互质数必为质数 | ❌ 错。仅要求 GCD = 1 |

| 相邻概念 | 关系 |

| 整除 | 数论基础 |
