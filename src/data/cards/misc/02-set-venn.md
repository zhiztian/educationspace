## 适用范围

- **讨论对象**：分类计数 / 重叠问题
- **最容易误入的边界**：直接相加忘减重叠；三集合容斥漏加项

## 精确定义

> ⭐ **集合**：把一些**确定的对象**放在一起，叫一个集合
> ⭐ **韦恩图**：用图圈直观表示集合关系

## 多角度逼近

1. **图示角度**：画圆 + 重叠
2. **公式角度**：容斥原理
3. **数表角度**：列分类表
4. **生活角度**：选课 / 喜好 / 调查

## 集合的简单概念

| 关键词 | 意义 |
|------|------|
| 元素 | 集合里的对象 |
| 子集 | 一个集合在另一集合里 |
| 交集 ∩ | 两集合**公共**元素 |
| 并集 ∪ | 两集合**所有**元素 |
| 差集 | A 中不在 B 的元素 |
| 补集 | 全集中不在该集合的元素 |

## 两集合韦恩图

```
     ┌──────┐ ┌──────┐
     │  A   │ │  B   │
     │  只  │∩│  只  │
     │  A   │ │  B   │
     └──────┘ └──────┘
        左只     右只
        + 中间重叠（A∩B）
```

> ⭐ **容斥公式**：|A∪B| = |A| + |B| - |A∩B|

## 经典例题

### 例 1：求总人数

> 班里 35 人喜欢音乐，28 人喜欢体育，两个都喜欢 15 人；至少一项几人？

```
|A∪B| = 35 + 28 - 15 = 48 人
```

### 例 2：求都不喜欢

> 50 人调查：会游泳 30，会骑车 25，都会 15。**都不会**几人？

```
至少一项 = 30 + 25 - 15 = 40
都不会 = 50 - 40 = 10
```

### 例 3：求"只…"的人数

> 上题中：只会游泳几人？只会骑车几人？

```
只游泳 = 30 - 15 = 15
只骑车 = 25 - 15 = 10
都会 = 15
都不会 = 10
合计 = 15+10+15+10 = 50 ✓
```

## 三集合韦恩图

```
        A
        ●
       / \
      /   \
   B ● ─── ● C

7 个区域：
- 只 A（A only）
- 只 B
- 只 C
- A∩B（不含 C）
- A∩C（不含 B）
- B∩C（不含 A）
- A∩B∩C（中心）
```

> ⭐ **三集合容斥**：
> |A∪B∪C| = |A|+|B|+|C| - |A∩B| - |A∩C| - |B∩C| + |A∩B∩C|

例：100 人调查
- 喜欢苹果 50
- 喜欢香蕉 40
- 喜欢梨 30
- A∩B = 20，A∩C = 15，B∩C = 10
- A∩B∩C = 5

至少喜欢一种 = 50+40+30 - 20-15-10 + 5 = **80**
都不喜欢 = 100-80 = **20**

## 列表法（可代替韦恩图）

> ⭐ 整理"分类表"很清晰

例：30 人，喜欢苹果 20，喜欢梨 15，两个都喜欢 10

| | 喜欢梨 | 不喜欢梨 | 合 |
|---|---|---|---|
| 喜欢苹果 | 10 | 10 | 20 |
| 不喜欢苹果 | 5 | 5 | 10 |
| 合 | 15 | 15 | 30 |

## 韦恩图与方程结合

> 设"两都喜欢" = x，列方程

例：50 人，AB 各喜欢 30 人，至少一项 45 人，求两都喜欢？

```
30 + 30 - x = 45
x = 15
```

## 常见陷阱

| 错误 | 正确 |
|------|------|
| 直接相加 | 必须**减重叠** |
| 减两次重叠 | 只减一次（两集合）|
| 三集合不"+ 中心" | 必须 **+ A∩B∩C** |
| 把"只 A"算入 A | A = 只 A + A∩B（含交集）|
| 都不喜欢忘求 | 都不喜欢 = 总 - 至少一项 |
| 重叠比一项还大 | 重叠 ≤ min(各项)|

## 与相邻概念关系

| 相邻概念 | 关系 |
|---------|------|
| 调查统计 | 实际场景 |
| 分类计数 | 集合是基础 |
| 数论 | 公倍数 / 公因数 = 集合交 |
| 中学集合 | 高中正式学 |
| 概率 | P(A∪B) = P(A)+P(B)-P(A∩B)|
