## 适用范围

- **讨论对象**：分类计数与分步计数
- **最容易误入的边界**：加 vs 乘搞反；有序无序混

## 精确定义

> ⭐ 计数 = 数清"有多少种方案"
> 两大原则：**加法原理**（分类）+ **乘法原理**（分步）

## 多角度逼近

1. **分类思想**：方法分几大类
2. **分步思想**：每步分别选
3. **树形图**：把所有可能画成树
4. **排列组合**：高级公式

## 加法原理（分类）

> ⭐ 完成一件事有 n 类方法，**任一类**都能独立完成 → **总数 = 各类相加**

例：从 A 到 B 的交通方式：
- 火车 3 路
- 汽车 2 路
- 飞机 1 路

总方法 = 3 + 2 + 1 = **6 种**

## 乘法原理（分步）

> ⭐ 完成一件事必须**每步都做**，分 n 步 → **总数 = 各步相乘**

例：4 件衣服 3 条裤子搭配
- 第 1 步：选衣 4 种
- 第 2 步：选裤 3 种
- 总 = 4 × 3 = **12 种**

## 加 vs 乘 的判别

| 关键词 | 用 |
|------|------|
| "或" / "类" / "种类型" | 加 |
| "再" / "和" / "依次" / "搭配" | 乘 |

例题：硬币 + 邮票
- "买硬币 3 种或邮票 2 种"，类型 = **加** = 5
- "买 1 枚硬币和 1 枚邮票"，搭配 = **乘** = 6

## 树形图（直观）

> ⭐ 把所有可能列成"树"

例：抛 2 次硬币

```
       第 1 次
       /    \
      正     反
     /  \   /  \
    正  反 正  反
    第 2 次

共 4 种：(正,正)(正,反)(反,正)(反,反)
```

## 排列（有顺序）

> ⭐ 从 n 个不同元素中**有序**选 k 个的方法数

> 公式：A(n,k) = n × (n-1) × ... × (n-k+1)

| 题型 | 公式 |
|------|------|
| n 个全排 | n! |
| n 选 k 排 | n × (n-1) × ... × (n-k+1) |

例：5 个人排队
- 5! = 5×4×3×2×1 = **120 种**

例：5 选 3 排
- 5 × 4 × 3 = **60 种**

## 组合（无顺序）

> ⭐ 从 n 个不同元素中**无序**选 k 个

> 公式：C(n,k) = A(n,k) / k!

| 题型 | 公式 |
|------|------|
| n 选 k 组 | C(n,k) = n!/(k!(n-k)!) |

例：5 选 2 组
- C(5,2) = (5×4)/(2×1) = **10 种**

> ⭐ 区别：去比赛"队长 + 队员"（有顺序）vs"代表队"（无顺序）

## 数字组合题

例：用 1, 2, 3, 4 组成几个**三位数**（不重复）？

```
百位：4 种 → 十位：3 种 → 个位：2 种
共 4 × 3 × 2 = 24 个
```

例：组成几个**奇数**？
- 个位必为 1 或 3 → 2 种
- 十百位从剩 3 个选 2 个排 → 3 × 2 = 6
- 共 2 × 6 = **12 个**

## 路径计数（典型）

> ⭐ 方格图从 A 到 B 走最短路径数

```
   A . . . . B   2 行 4 列
   . . . . .

   每点 = 上面 + 左面（路径加和）
   
   1 1 1 1 1
   1 2 3 4 5

   答：5 种
```

## 例题汇总

### 例 1：握手问题

> 5 人两两握手，共几次？

```
C(5,2) = 5×4/2 = 10 次
```

### 例 2：分组

> 6 人分两组每组 3 人

```
C(6,3) = 20，但两组无序 → 除以 2 = 10
```

### 例 3：站队

> 3 男 2 女站一排，女生不相邻几种？

```
先排男 = 3! = 6 种
男之间 + 两端共 4 个空，女选 2 个排：A(4,2)= 12 种
共 6 × 12 = 72 种
```

## 常见陷阱

| 错误 | 正确 |
|------|------|
| 分类用乘 / 分步用加 | **分类加，分步乘** |
| 排列当组合 | 看顺序是否影响 |
| 数字组合首位 0 | 首位**不能 0** |
| 重复计算"对称"组合 | 组合**除以重复因子** |
| 漏特殊位置 | 先放"特殊位"再算其余 |
| n! 算成 n×n | n! = n×(n-1)×...×1 |
