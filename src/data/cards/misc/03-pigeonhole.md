## 适用范围

- **讨论对象**：分类后的"至少"问题
- **最容易误入的边界**："最少"vs"最多"搞反；最坏情况未想清

## 精确定义

> ⭐ **抽屉原理（鸽巢原理）**：
> n 个物体放入 k 个抽屉（n > k）→ **至少有一个**抽屉里 **≥ 2** 个

## 多角度逼近

1. **最坏情况**：先尽量"摊开"，再加 1
2. **公式角度**：⌈N/K⌉ 个/抽屉
3. **反证角度**：假设每个 ≤ m，矛盾
4. **生活角度**：袜子、球、月份、年级、卡片

## 简单形式（必会）

> n+1 个物 → n 个抽屉 → 必有一抽屉 **≥ 2**

例：13 人放进 12 个月 → 必有同月生日

## 一般形式（公式）

> N 个物 → K 个抽屉 → 至少一抽屉 **≥ ⌈N/K⌉**

| N | K | ⌈N/K⌉ |
|---|---|------|
| 10 | 3 | 4 |
| 25 | 4 | 7 |
| 100 | 7 | 15 |

## 经典题型

### 1. 同色问题（最坏 + 1）

> 红、黄、蓝球各 5 个，摸出几个保证 2 个同色？

```
最坏：每色摸 1 个 → 共 3 个，全不同
再摸 1 个 → 必同色
答：3 + 1 = 4
```

### 2. 数量相同保证

> 摸几个保证 3 个同色？

```
最坏：每色 2 个 → 共 6 个
再摸 1 个 → 某色到 3
答：6 + 1 = 7

公式：(目标-1) × 抽屉数 + 1
   = 2 × 3 + 1 = 7
```

### 3. 袜子配对

> 黑袜子 + 白袜子 各 10 只，摸几只保证一双同色？

```
最坏：1 黑 1 白
再摸 1 → 必同色
答：3 只
```

### 4. 生日问题

> 至少几人保证 2 人同月？

```
抽屉 = 12 月
12 + 1 = 13 人
```

> 至少几人保证 3 人同月？
> 2×12 + 1 = **25 人**

## 解题模板

```
1. 找抽屉（分类标准）：颜色 / 月份 / 余数 / 区域 ...
2. 算最坏情况下"恰好不达成"的个数
3. 在最坏 + 1 即为答案
```

## 复杂例题

### 例 1：余数抽屉

> 8 个不同正整数，必有两数差是 7 的倍数

```
余数 0,1,2,3,4,5,6 共 7 个抽屉
8 数 > 7 → 必有 2 数同余
两数差 = 7 的倍数 ✓
```

### 例 2：年龄抽屉

> 50 人 18 ~ 60 岁；至少几人同岁？

```
年龄段 = 60-18+1 = 43 个
50 个物 → 43 抽屉
⌈50/43⌉ = 2
至少 2 人同岁
```

### 例 3：方格抽屉

> 10 × 10 方格 51 个点，必有 ≥ 2 点在同一格

```
抽屉 = 100 格
51 ≤ 100 → ❌ 不能直接用

更精细：要看面积分割
```

## 反证法描述（高级）

> 若结论不成立 → 假设每抽屉 < ⌈N/K⌉ 个 → 总数 < N → 矛盾

例：
- 13 人 12 月，假设每月 ≤ 1 人
- 总人 ≤ 12 < 13 → 矛盾

## 抽屉的"找法"

| 题型 | 抽屉 |
|------|------|
| 颜色 | 按颜色 |
| 生日 | 按月 / 按日 |
| 整数余数 | 按 mod n 余数 |
| 平面点 | 按区域分割 |
| 边长 / 距离 | 按区间 |

## 常见陷阱

| 错误 | 正确 |
|------|------|
| 摸 2 个就保证同色 | 必须算**最坏 + 1** |
| 抽屉找错（不分类正确）| 抽屉数 = 分类数 |
| 公式 ⌈N/K⌉ 算成 ⌊N/K⌋ | **向上取整** |
| 把"最少"和"最多"混 | 最少保证 = 最坏情况 + 1 |
| 不存在"至少 0"的题意 | 抽屉数 ≥ 1 |
