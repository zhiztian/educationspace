## 适用范围

- **讨论对象**：数据从哪里来、怎么记
- **最容易误入的边界**：抽样代表性差；只统计部分却以为是全部

## 精确定义

> ⭐ **统计**：通过收集、整理、分析数据来发现规律
> 关键步骤：**收集 → 整理 → 表示（图表）→ 分析**

## 多角度逼近

1. **收集角度**：调查 / 观察 / 实验 / 资料查阅
2. **整理角度**："正"字 / 对号 / 列表
3. **表达角度**：统计表 / 各种图（条形 / 折线 / 扇形）
4. **生活角度**：班级喜爱、家庭开销、天气记录

## 收集数据的方法

| 方法 | 适合场景 | 例 |
|------|---------|----|
| 观察 | 自然现象 | 一天中天气状况 |
| 调查（问卷/访谈） | 喜好 / 意见 | 班级最爱学科 |
| 测量 | 物理量 | 全班身高 / 体重 |
| 实验 | 科学验证 | 不同肥料对植物生长的影响 |
| 查阅资料 | 历史 / 大数据 | 各国人口、GDP |

## 整理数据的方法

### 1. "正"字法（最常用）

> ⭐ 每画一笔代表 1 个；一个完整"正"字 = **5**

```
   一    二    三    四    正
   1     2     3     4     5
```

例：12 个 → "正 正 二"（5+5+2）

### 2. 对号 / 圆点法

```
   √√√√√  √√√  → 8 个
```

### 3. 统计表

| 项目 | 数量 |
|------|------|
| 语文 | 12 |
| 数学 | 15 |
| 英语 | 8 |
| 体育 | 5 |
| **合计** | **40** |

## 统计表必备要素

> ⭐ **标题 + 表头 + 数据 + 合计**

```
        班级最爱学科统计表（2026.5）
   +------+------+
   | 学科 | 人数 |   ← 表头
   +------+------+
   | 语文 |  12  |   ← 数据
   | ...  |  ... |
   +------+------+
   | 合计 |  40  |   ← 合计
```

## 抽样 vs 全调查

| 方法 | 适用 | 优 | 劣 |
|------|------|----|---|
| 全调查 | 总体小 | 准确 | 费时 |
| 抽样 | 总体大 | 高效 | 抽样要**有代表性** |

> ⭐ 抽样**代表性**很重要：
> - 调查全校女生体重 → 不能只抽 1 个班
> - 调查电视收视率 → 不能只问家长

## 数据准确性的影响因素

- 抽样太少 / 不均衡 → 偏差
- 调查问题歧义（如"你常运动吗？"标准模糊）
- 受访者不诚实（敏感问题尤其）
- 记录 / 录入失误

## 常见陷阱

| 错误 | 正确 |
|------|------|
| "正"字一笔代表 5 | ❌ 错。一笔代表 1，**完整一个"正"字** = 5 |
| 抽 5 个就代表全班 | 太少；至少有比例代表性 |
| 漏写"合计" | 完整统计表必须有合计 |
| 标题省略 | 必须有 |
| 调查方式偏（只问优等生）| 抽样要随机 / 均匀 |
