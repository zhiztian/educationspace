## 适用范围

- **讨论对象**：随**时间**变化的数量
- **最容易误入的边界**：用折线图表示"项目对比"（应用条形图）

## 精确定义

> ⭐ **折线统计图**：用**点**表示数量、用**线段**连接相邻点
> 主要用于反映数量**随时间的变化**

## 多角度逼近

1. **趋势角度**：上升 / 下降 / 起伏 / 平稳
2. **比较角度**：复式折线对比多组
3. **时间角度**：横轴一定是时间或顺序量
4. **生活角度**：气温、体重、股价、成绩变化

## 折线图要素

```
   纵轴（数量）↑
        │
     30 │           ●
        │         ╱   ╲
     20 │       ●       ●
        │     ╱           ╲
     10 │   ●               ●
        │ ╱                   ╲
      0 └─┬───┬───┬───┬───┬───┬─→
         一  二  三  四  五  六  日  (横轴：时间)
   
   标题：本周每日气温变化（°C）
```

| 要素 | 说明 |
|------|------|
| 标题 | 表明统计内容 |
| 横轴 | **时间**（顺序量，等间距）|
| 纵轴 | 数量轴 + 刻度 + 单位 |
| 点 | 每个时间点的数据值 |
| 线段 | 相邻点连接，反映变化 |
| 数据标签 | 点旁边标具体值（可选） |

## 折线"陡峭程度" = 变化速度

```
   陡 ↑↑      → 变化快（剧增 / 剧减）
   缓 ↗→      → 变化慢
   平 ──      → 不变（或几乎不变）
```

## 折线分析常考点

| 问题 | 怎么看 |
|------|------|
| 哪天 / 哪期最高 / 最低 | 找最高 / 最低点 |
| 总体趋势 | 看大方向（升 / 降 / 起伏）|
| 哪段升降最快 | 找最陡的线段 |
| 与平均数比较 | 算平均后画水平虚线 |
| 预测未来值 | 按趋势外推（仅参考） |

## 复式折线图

> ⭐ **多组数据同图对比**

例：A、B 两人一周体温变化

```
   ↑                   
40 │  ─── A
   │  ─・─ B
39 │       ●─●            
   │     ╱     ╲   ●
38 │   ●         ●╱  ╲
   │ ─・           ●─・
37 │ ●     ●─・─・    ╲
   └──┴──┴──┴──┴──┴──┴──→
      一  二  三  四  五  六  日
```

> 用不同**颜色 / 线型**（实线 / 虚线 / 点线）区分；必须有**图例**

## 折线图 vs 条形图（用途对比）

| 项目 | 条形图 | 折线图 |
|------|-------|-------|
| 适合看 | 项目多少比较 | 趋势变化 |
| 横轴 | 项目类别 | 时间（顺序量）|
| 元素 | 直条 | 点 + 线 |
| 看陡峭程度 | ❌ 不直观 | ✅ 关键功能 |

## 常见陷阱

| 错误 | 正确 |
|------|------|
| 横轴用项目（语文/数学）画折线 | ❌ 错。**用条形图**；折线必须横轴是时间 |
| 折线图不连接点 | ❌ 错。必须用**线段相连** |
| 复式图无图例 | 必须有 |
| 横轴时间间隔不均匀 | 必须等间距 |
| 折线超出图框不调整刻度 | 重新选纵轴单位长度 |

## 与相邻概念关系

| 相邻概念 | 关系 |
|---------|------|
| 条形图 | 适合静态对比，不适合趋势 |
| 扇形图 | 适合占比，不适合时间序列 |
| 平均数 | 折线图中可加平均线 |
| 函数（中学） | 折线 ≈ 离散数据的函数图 |
