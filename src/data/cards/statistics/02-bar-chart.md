## 适用范围

- **讨论对象**：用直条长度表示数量
- **最容易误入的边界**：单位长度选错；直条粗细不一；漏数据标签

## 精确定义

> ⭐ **条形统计图**：用**直条的长短**表示数量多少
> 每根直条**高度 ∝ 数量**

## 多角度逼近

1. **直观角度**：眼睛看高低 → 直接看出谁多谁少
2. **比较角度**：项目间数量对比一目了然
3. **复式角度**：两组以上的对比
4. **生活角度**：销量对比、考试分数、人口比较

## 条形图的要素

```
   纵轴 ↑（数量，单位 mm/人/件）
        │
     50 ┤────────
     40 ┤   ┌──┐
     30 ┤   │  │   ┌──┐
     20 ┤───│  │───│  │
     10 ┤   │  │   │  │   ┌──┐
      0 └───┴──┴───┴──┴───┴──┴────→
            语文     数学     英语
            (横轴：项目)

   标题：班级最喜爱学科统计图（2026.5）
   单位：人数
```

| 要素 | 说明 |
|------|------|
| 标题 | 表明统计内容 + 时间 |
| 横轴 | 项目类别（语文 / 数学 …）|
| 纵轴 | 数量轴 + 刻度 + 单位 |
| 直条 | 等粗细，**等间距** |
| 数据标签 | 直条顶部标具体数（可选） |

## 单位长度的选择

> ⭐ 看数据**最大值**和**最小值**：
> - 数据 0~50 → 每格 5 或 10
> - 数据 100~200 → 每格 10 或 20
> - 数据 500~1000 → 每格 50 或 100

例：数据是 12, 15, 8, 35
→ 最大 35 → 每格选 5（共 7 格够用）

## 复式条形图

> ⭐ **同一项目用两根（或多根）颜色不同的直条对比**

```
       ↑
       │  ▓ 男生   ░ 女生
       │
    20 │  ▓░  ▓░
    15 │  ▓░  ▓░
    10 │  ▓░  ▓░  ▓░
     5 │  ▓░  ▓░  ▓░
       └──┴───┴───┴──→
          语文 数学 英语
```

> 必须有**图例**说明颜色含义

## 看图分析

常考问题：
1. 哪一项最多 / 最少？（找最高/最低条）
2. 总数是多少？（直条数据相加）
3. A 比 B 多多少？（差）
4. A 是 B 的几倍？（除法）
5. 平均每项多少？（÷ 项目数）
6. 增减趋势？（折线图更适合）

## 常见陷阱

| 错误 | 正确 |
|------|------|
| 直条粗细不一 | 必须**等粗细**，**等间距** |
| 单位长度选不合理 | 数据要能填满图、且不超出 |
| 漏单位 / 标题 | 完整图都必须有 |
| 复式图无图例 | 必须有**图例** |
| 直条从中间开始 | 一般从 0 开始（截断要标省略号）|

## 与其他统计图对比

| 图形 | 适合表示 | 优势 |
|------|---------|------|
| **条形** | 数量**多少**比较 | 直观比较多少 |
| **折线** | 数量**变化趋势** | 看变化方向 |
| **扇形** | 各部分**占比** | 看百分比 |

## 与相邻概念关系

| 相邻概念 | 关系 |
|---------|------|
| 数据收集 | 条形图前的步骤 |
| 折线 / 扇形图 | 不同侧重 |
| 平均数 | 看图分析常算平均 |
| Excel / 软件 | 实际工具中条形图最常用 |
