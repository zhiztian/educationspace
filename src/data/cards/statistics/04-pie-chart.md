## 适用范围

- **讨论对象**：各部分**占总体的百分比**
- **最容易误入的边界**：用扇形图表示"具体数值"或"趋势"

## 精确定义

> ⭐ **扇形统计图**：用**整圆代表总体**（100%），每个**扇形**代表一部分的占比
> 扇形大小 ∝ 该部分占比

```
        ▓▓▓▓▓▓
      ▓▓        ▓▓
    ▓▓   30%    ▓▓
   ▓▓     A      ▓▓
   ▓▓             ▓▓
   ▓▓ 50% ┃ 20%  ▓▓
    ▓▓ B  ┃ C  ▓▓
      ▓▓        ▓▓
        ▓▓▓▓▓▓
   
   各部分加起来 100%
```

## 多角度逼近

1. **占比角度**：直观看出谁多谁少（比例）
2. **角度角度**：圆心角 = 360° × 百分比
3. **总和角度**：所有扇形之和必为整圆（100%）
4. **生活角度**：班级喜爱、家庭开销分布、人口构成

## 扇形图要素

| 要素 | 说明 |
|------|------|
| 标题 | 表明统计内容 |
| 整圆 | 代表 **100%** 的总体 |
| 扇形 | 各部分大小 ∝ 占比 |
| 百分比标注 | 每个扇形标具体百分比 |
| 名称（图例 / 直标） | 说明每个扇形代表什么 |
| 颜色 | 用不同颜色区分 |

## 圆心角 vs 百分比换算

> ⭐ **圆心角 = 360° × 百分比**
> 反之：**百分比 = 圆心角 ÷ 360°**

| 百分比 | 圆心角 |
|-------|-------|
| 100% | 360° |
| 50% | 180° |
| 25% | 90° |
| 20% | 72° |
| 10% | 36° |
| 5% | 18° |
| 1% | 3.6° |

## 扇形图分析

### 基本：算具体数量

> ⭐ 扇形图本身只显示百分比，要算**具体数**：
> **某部分数量 = 总数 × 该部分百分比**

例：80 人的班级，男生占 60%
→ 男生人数 = 80 × 60% = **48 人**

### 比例换算：占比间比较

A 占 30%，B 占 15% → A 是 B 的 **2 倍**

### 反推总体

C 占 25%，已知 C 数量是 20 → 总数 = 20 ÷ 25% = **80**

## 三种统计图选用

| 想看 | 选 | 原因 |
|------|-----|------|
| 各项**多少**比较 | 条形图 | 直条长短 |
| **变化趋势** | 折线图 | 线段走势 |
| **占比 / 构成** | 扇形图 | 整体 = 100% |

## 复合用法

> 一份调查通常配多张图：
> - 总体构成 → 扇形图
> - 各组数量比较 → 条形图
> - 多年变化趋势 → 折线图

## 常见陷阱

| 错误 | 正确 |
|------|------|
| 扇形图各部分 ≠ 100% | ❌ 错。必须**正好 100%** |
| 用扇形图看具体数量 | 看的是**占比**；要乘总数才有数量 |
| 扇形图看趋势 | ❌ 错。扇形图无时间维度 |
| 圆心角和百分比比例算错 | 圆心角 = **360° × 百分比** |
| 漏标百分比 | 每个扇形必须标 |
| 颜色 / 图例缺失 | 必须能区分各扇形 |

## 与相邻概念关系

| 相邻概念 | 关系 |
|---------|------|
| 百分数 | 扇形图本质是百分数的可视化 |
| 圆 / 圆心角 | 扇形几何属性 |
| 比例 | 扇形大小比 = 数量比 |
| 条形 / 折线图 | 不同侧重，各有适用 |
| 应用：人口 / 经济 | 实际报告中常见 |
