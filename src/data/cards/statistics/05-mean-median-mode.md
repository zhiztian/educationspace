## 适用范围

- **讨论对象**：一组数据的"集中趋势"（代表性数值）
- **最容易误入的边界**：被极端值拉偏；以为"平均数"总是最好

## 精确定义

| 名称 | 计算方法 | 反映 |
|------|---------|------|
| **平均数** | 总和 ÷ 个数 | 数据"中心" |
| **中位数** | 排序后中间值 | 数据"中点" |
| **众数** | 出现最多的数 | 数据"高频" |

## 多角度逼近

1. **总和角度**：平均数 = 总和 / 个数
2. **位置角度**：中位数看排序后的位置
3. **频率角度**：众数看出现次数
4. **代表性角度**：根据数据特点选合适的统计量

## 平均数

> ⭐ **平均数 = 总和 ÷ 个数**

例：12, 15, 18 → (12+15+18) ÷ 3 = **15**

### 加权平均（高年级）

```
   2 个 80 分 + 3 个 90 分
   平均 = (2×80 + 3×90) / (2+3) = 430/5 = 86
```

> 平均数受**极端值**影响大

## 中位数

> ⭐ **中位数**：数据排序后位于中间的数

### 步骤

1. 数据从小到大排
2. 数有几个
   - 奇数个：取中间那个
   - 偶数个：取中间两个的**平均**

例 1：3, 5, 7, 9, 11（5 个，奇数）→ 中位 = **7**
例 2：3, 5, 7, 9（4 个，偶数）→ 中位 = (5+7)/2 = **6**

> 中位数**不受极端值影响**（更稳健）

## 众数

> ⭐ **众数**：出现次数最多的数

例 1：1, 2, 2, 3, 4 → 众数 = **2**
例 2：1, 1, 2, 2, 3 → 众数 = **1 和 2**（两个）
例 3：1, 2, 3, 4 → **无众数**（都只出现 1 次）

> 众数可能没有 / 一个 / 多个

## 三个统计量的对比

| 项目 | 平均数 | 中位数 | 众数 |
|------|-------|-------|------|
| 是否易计算 | 易 | 中 | 易 |
| 受极端值 | **大**影响 | 不影响 | 不影响 |
| 适合 | 数据较均匀 | 有极端值 | 看典型 / 流行 |
| 必有？ | 总有 | 总有 | 不一定 |

## 何时选哪个？

| 情况 | 选 | 原因 |
|------|-----|------|
| 求"平均工资" | 中位数（薪资差大易拉偏）| 高薪老板会拉高平均 |
| 求"班级平均成绩" | 平均数（无极端） | 数据集中 |
| 求"最受欢迎的鞋码" | 众数 | 看流行 |
| 数据有少量异常 | 中位数 | 稳健 |

## 经典坑：被极端值拉偏

数据：1, 2, 2, 3, 100
- 平均 = (1+2+2+3+100)/5 = **21.6** ❌ 不能代表这组数据
- 中位 = **2**（排序后第 3 个） ✅ 较代表
- 众数 = **2** ✅ 较代表

> 异常值（100）严重拉高平均数；中位数 / 众数更稳定

## 常见陷阱

| 错误 | 正确 |
|------|------|
| 中位数算前要排序 | 必须**先排序** |
| 偶数个数据中位数取中间一个 | ❌ 错。**取中间两个的平均** |
| 众数必须有 | 不一定，可以**无众数** |
| 平均数总能代表 | 异常值会拉偏，要看分布 |
| 把 0 排除算平均 | 不能省略（除非题目说明）|
| 平均 = 中位 = 众数 | 仅在数据均衡分布时；一般**不一定相等** |

| 相邻概念 | 关系 |
|---------|------|
| 数据收集 | 三量是分析的常用结果 |
| 折线 / 条形图 | 图上可加平均线 |
| 比较问题 | 比较两班用平均数（同人数前提） |

| 应用题 | 工资 / 成绩 / 销量分析 |
