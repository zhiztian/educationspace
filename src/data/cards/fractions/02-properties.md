## 适用范围

- **讨论对象**：所有分数（真分数 / 假分数 / 带分数）
- **不讨论 / 排除**：分子或分母变化为 0 的情况
- **最容易误入的边界**：把"同乘 / 同除"错记成"同加 / 同减"

## 精确定义

> ⭐ **分数的基本性质**：分数的分子和分母**同时乘 / 除以同一个不为 0 的数**，分数的大小不变。

```
   a       a × n        a       a ÷ n
   ─  =  ─────────  =  ─  =  ─────────
   b       b × n        b       b ÷ n

         (n ≠ 0)
```

## 多角度逼近

1. **几何角度**：把"取出的份数 / 总份数"同时变细 —— 大小不变
   ```
   1/2 = ▮▮▯▯  →  细分：2/4 = ▮▮▯▯ → 4/8 = ▮▮▮▮▯▯▯▯
   ```
2. **除法角度**：分数性质 = 商不变性质（a÷b = (a×n)÷(b×n)）
3. **乘 1 角度**：×n / ×n = ×1 → 没动
4. **生活角度**：6 块饼 / 12 个人 = 1 块饼 / 2 个人 = 同样的人均量

## 应用一：约分（向小化）

把分子分母同时**除以**它们的公因数（最大公因数最快） → 化成**最简分数**

例：`8/12 ÷ 4/4 = 2/3` ✓

## 应用二：通分（异分母 → 同分母）

把几个分数同时**乘**适当的数 → 分母相同 → 分母通常取**最小公倍数**

例：`2/3 = 8/12；3/4 = 9/12`（分母通分到 12）

## 应用三：化为指定分母 / 分子

| 任务 | 方法 |
|------|------|
| 1/2 化成分母 6 的分数 | 分母 ×3，分子也 ×3 → 3/6 |
| 1/2 化成分子 5 的分数 | 分子 ×5，分母也 ×5 → 5/10 |
| 3/5 化成分母 25 | 25 ÷ 5 = 5 → 分子也 ×5 → 15/25 |

## 常见陷阱

| 错误 | 正确 |
|------|------|
| "分子加 1，分母加 1，分数不变" | ❌ 大错。例 1/2 → 2/3 ≠ 1/2。**只能同乘 / 同除** |
| "同时乘以 0 也算"（套同乘） | ❌ 错。**同乘 / 同除的数必须非 0** |
| 通分时用了非公倍数的数 | 不出错但麻烦；优选**最小公倍数** |
| 约分时少除了一次（如 16/24 → 8/12 没继续约） | 约到**最简**为止 —— 分子分母互质 |
| 分子分母调换顺序（"分数倒过来"）说"性质" | 那是**倒数**，不是基本性质 |

## 与相邻概念关系

| 相邻概念 | 关系 |
|---------|------|
| 商不变性质 | 等价表述（除法版） |
| 约分 | 性质的"向小"应用 |
| 通分 | 性质的"向大 / 同分母"应用 |
| 比的性质 | 比的前后项同乘 / 同除非零数比值不变（同源思想） |
| 倒数 | 是"分子分母换位"，与基本性质**无关** |
