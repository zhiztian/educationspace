## 适用范围

- **讨论对象**：把"单位 1"平均分成若干份后表示部分或全部的数
- **不讨论 / 排除**：分母为 0 的"分数"（无意义）；不平均的"分"
- **最容易误入的边界**：忘记"平均分"前提；把"几分之几"和"几米"搞混

## 精确定义

**分数**：把单位"1"**平均分**成若干份，表示这样的一份或几份的数。

```
        分子（取了几份）
分数 = ─────────────
        分母（平均分成几份）
```

> ⭐ **必备前提**：必须**平均分**。"随便分"不能用分数表示。

## 多角度逼近

1. **平均分角度**：分母 = 总份数；分子 = 取了几份
2. **除法角度**：a / b = a ÷ b（b ≠ 0）—— 分数本质是除法的另一种写法
3. **比率 / 比角度**：3/4 表示"3 与 4 的比" → a : b = a/b
4. **数轴角度**：在 0 和 1 之间均匀插入分点

## 单位"1"

> ⭐ **单位"1"**：不仅可以是 1 个物体，还可以是**一堆 / 一组 / 一个计量单位**

| 单位"1" | 例 |
|---------|----|
| 1 个物体 | 一块饼平均分成 4 份，1 份是 1/4 |
| 1 个计量单位 | 1 米平均分成 5 份，1 份是 1/5 米 |
| 一群 / 一组 | 班里 40 人，男生 24 人 → 男生占 24/40 = 3/5 |
| 一段时间 | 一天 24 小时，睡 8 小时 → 睡眠占 1/3 |

## 分数的两种用法（重要）

| 用法 | 例 | 意义 |
|------|---|------|
| **比率 / 倍率**（不带单位） | 一根绳子被剪去 2/3 | 占单位"1"的 2/3 |
| **数量**（带单位） | 一根绳子长 2/3 米 | 具体的 2/3 米 |

> ⚠️ 同一个 "2/3" 用法不同 —— 题目不带单位时是比率，带单位时是数量

## 各部分名称

```
       3   ← 分子（取了几份）
       ─   ← 分数线（"平均分"的标志）
       4   ← 分母（平均分成几份）

读作：四分之三（先读分母，再读分子）
```

## 分数与除法的关系

> ⭐ `a ÷ b = a/b`（b ≠ 0）

例：3 ÷ 4 = 3/4 = 0.75

## 常见陷阱

| 错误 | 正确 |
|------|------|
| "随便切成 4 份，吃 1 份是 1/4" | ❌ 错。**必须平均分** |
| "2/3 米 = 2/3"（混用单位） | 带单位是数量，不带单位是比率 —— 不能混 |
| "分母可以是 0" | ❌ 错。分母 = 0 无意义（除以 0 没意义） |
| "先读分子再读分母" | ❌ 错。**先读分母 → 几分之 → 再读分子** |
| 把分数线当成减号 | 分数线 = 平均分（≠ 减号） |

## 与相邻概念关系

| 相邻概念 | 关系 |
|---------|------|
| 整数 | 整数可写成 a/1 形式（3 = 3/1）→ 整数是特殊的分数 |
| 除法 | 分数 = 除法的另一种写法 |
| 小数 | 分数与有限 / 无限循环小数可互化（见 dp-07） |
| 比 | a:b = a/b |
| 单位"1" | 是分数的"基准" |
| 百分数 | 百分数是分母 100 的特殊分数 |
