## 适用范围

- **讨论对象**：所有非零分数（按分子分母大小关系分类）
- **不讨论 / 排除**：负数 / 0 的分数情况（小学不深入）
- **最容易误入的边界**：忘了"分子 = 分母"算假分数；把"5/5 = 1"也看成带分数

## 精确定义

| 类型 | 条件 | 范围 |
|------|------|------|
| **真分数** | 分子 < 分母 | 0 < 分数 < 1 |
| **假分数** | 分子 ≥ 分母 | ≥ 1 |
| **带分数** | 整数 + 真分数 | ≥ 1（不含整数） |

> ⚠️ **分子 = 分母**（如 4/4）也是假分数（等于 1）

## 多角度逼近

1. **大小角度**：真 < 1 ≤ 假；带分数是假分数的"整数 + 真分数"形式
2. **几何角度**：
   ```
   真：3/4   = ▮▮▮▯   < 1
   假：5/4   = ▮▮▮▮ + ▮▯▯▯   ≥ 1
   带：1又1/4 = 1 + 1/4
   ```
3. **除法角度**：`分子 ÷ 分母` 不够分一份 → 真；够 → 假

## 假分数 ↔ 带分数 互化

### 假分数 → 带分数

`分子 ÷ 分母 = 商 ……余数` → `商 又 余数/分母`

例：`7/3 = 7 ÷ 3 = 2 …… 1 → 2又1/3`

> 边界：`6/3 = 2`（无余数 → 化为整数，不是带分数）

### 带分数 → 假分数

`(整数 × 分母 + 分子) / 分母`

例：`3又2/5 = (3×5+2)/5 = 17/5`

## 关键性质

| 性质 | 说明 |
|------|------|
| 真分数 | < 1 |
| 假分数 | ≥ 1 |
| 假分数 = 1 | 分子 = 分母（如 4/4） |
| 假分数 > 1 且能整除 | 化为整数（如 6/3 = 2） |
| 假分数 > 1 不能整除 | 化为带分数（如 7/3 = 2又1/3） |
| 带分数 | 整数 + 真分数（部分） |
| 整数 ≥ 1 不是带分数 | 5 ≠ 5/5 也 ≠ 带分数 |

## 常见陷阱

| 错误 | 正确 |
|------|------|
| "分子 = 分母不算假分数" | ❌ 错。**= 也是假分数**，等于 1 |
| `7/3 = 2.3...` 直接小数化 | 在分数题里要化**带分数 2又1/3** |
| `3又2/5 = 3 × 2/5 = 6/5` | ❌ 大错。带分数是 **加法**，不是乘法 |
| `5 = 5又0/x` 当带分数 | 整数不能写成带分数（带分数必须有真分数部分 ≠ 0） |
| 假分数化带分数后不约分 | 余数 / 分母 部分若可约要约（如 8/6 = 1又2/6 = 1又1/3） |

## 与相邻概念关系

| 相邻概念 | 关系 |
|---------|------|
| 整数 | 假分数中分子是分母的整数倍时 = 整数 |
| 约分 | 化简后再判断真 / 假 / 带 |
| 加减运算 | 异分母分数计算后常出现假分数，需化带分数 |
| 大小比较 | 真分数 < 1 ≤ 假分数（粗略判断） |
| 小数 | 真分数 ↔ < 1 的小数；假分数 ↔ ≥ 1 的小数 |
