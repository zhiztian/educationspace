## 适用范围

- **讨论对象**：分数 × / ÷ 分数 / 整数 / 带分数
- **不讨论 / 排除**：除数为 0 的（不允许）
- **最容易误入的边界**：除法忘了倒数；带分数乘除直接拆开；0 当成有倒数

## 分数乘法

> ⭐ **分子乘分子，分母乘分母**

```
   a       c       a × c
   ─   ×   ─   =   ─────
   b       d       b × d
```

例：`2/3 × 4/5 = 8/15`

### 整数乘分数

`整数 × a/b = (整数 × a) / b`

例：`6 × 2/3 = 12/3 = 4`

### 带分数乘法

**先化为假分数再乘**：

`1又1/2 × 2/3 = 3/2 × 2/3 = 6/6 = 1`

### 计算技巧：**先约分再乘**

`9/16 × 8/27` 不要先乘：

```
  9     8       1 × 1     1
 ── × ──  =  ───────  = ─
 16    27      2 × 3     6
   └──────约───┘
   9 ↔ 27 约 9：1 ↔ 3
   8 ↔ 16 约 8：1 ↔ 2
```

## 倒数（除法的关键概念）

> ⭐ **乘积是 1 的两个数互为倒数**

| 数 | 倒数 |
|----|------|
| 5 | 1/5 |
| 1/5 | 5 |
| 2/3 | 3/2 |
| 1 | 1 |
| 0 | **没有倒数** |
| 0.5 (= 1/2) | 2 |

> ⚠️ **0 没有倒数**：任何数 × 0 = 0，永远 ≠ 1

## 分数除法

> ⭐ **除以一个不为 0 的数 = 乘这个数的倒数**

```
   a       c       a       d       a × d
   ─   ÷   ─   =   ─   ×   ─   =   ─────
   b       d       b       c       b × c

         (c ≠ 0)
```

例：
- `2/3 ÷ 4/5 = 2/3 × 5/4 = 10/12 = 5/6`
- `12 ÷ 3/4 = 12 × 4/3 = 16`
- `3/4 ÷ 2 = 3/4 × 1/2 = 3/8`

### 带分数除法

**先化为假分数，再用倒数法**：

`2又1/4 ÷ 1又1/2 = 9/4 ÷ 3/2 = 9/4 × 2/3 = 18/12 = 3/2 = 1又1/2`

## 多角度逼近

1. **乘法角度**：a × b/c = a 的 b/c —— "a 的几分之几"
2. **除法角度**：÷ 几分之几 = × 倒数（"颠倒来乘"）
3. **几何角度**：长方形面积 = 长 × 宽（含分数）
4. **倒数对称**：a × b = 1 ⇔ a 与 b 互为倒数

## 常见陷阱

| 错误 | 正确 |
|------|------|
| 分数加 / 减用乘法规则（分子加分母加） | 加减用通分；乘法才是分子乘分子 |
| 除法忘了取倒数（直接分子除分子）| ÷ a/b = × b/a |
| `5 ÷ 3/4 = 5 × 3/4`（取倒数取错对象） | 取**除数**的倒数：5 × 4/3 |
| `0` 也算个倒数（如 1/0） | ❌ 0 没有倒数 |
| 带分数直接 `2又1/2 × 3 = 6又1/2` | 错。先化假分数 5/2 × 3 = 15/2 = 7又1/2 |
| 不先约分硬乘出大数再约 | 跨分子分母约分省力得多 |

## 与相邻概念关系

| 相邻概念 | 关系 |
|---------|------|
| 倒数 | 除法的核心工具 |
| 整数乘除 | 分数乘除的基础规则一致 |
| 带分数 | 计算前必须化假分数 |
| 约分 | 乘法时先约后乘最简便 |
| 应用题 | "求一个数的几分之几" 用分数乘法；"已知部分求整体" 用分数除法 |
