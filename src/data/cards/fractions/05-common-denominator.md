## 适用范围

- **讨论对象**：两个或多个**异分母**分数
- **不讨论 / 排除**：分母已经相同的（无需通分）
- **最容易误入的边界**：公分母不取最小公倍数（取了乘积导致数太大）

## 精确定义

**通分**：把几个**异分母**分数分别化成与原来相等、且**分母相同**的分数。

> ⭐ 公分母的最佳选择：**几个分母的最小公倍数（LCM）**

## 多角度逼近

1. **基本性质角度**：分子分母同乘适当数 → 分母相同
2. **LCM 角度**：找几个分母的最小公倍数作公分母
3. **比较 / 加减角度**：异分母不能直接比 / 加，需要先通分
4. **几何角度**：把每份切得"一样细" → 才能比

## 通分步骤

```
1. 求几个分母的最小公倍数 = 公分母
2. 每个分数 → 分母 × (公分母 ÷ 原分母)
              分子 × (公分母 ÷ 原分母)
3. 写出分母相同的等价分数
```

例：`2/3 和 5/6 通分`

```
分母 3 与 6 的 lcm = 6
2/3 → 分母 ×2，分子也 ×2 → 4/6
5/6 → 不变
```

例：`5/8 和 7/12 通分`

```
lcm(8,12) = 24
5/8  → ×3 → 15/24
7/12 → ×2 → 14/24
```

## 求几个分母的 LCM 的捷径

| 情形 | 公分母 |
|------|-------|
| 一个分母是另一个的倍数 | **较大那个** |
| 两个分母互质 | **两数之积** |
| 一般情形 | 短除法 / 分解质因数（见 ns-07） |

## 三个或更多分数

例：`1/4、1/6、1/9`

```
  2 │ 4   6   9
  3 │ 2   3   9
    │ 2   1   3   ← 互质，停止

lcm = 2 × 3 × 2 × 1 × 3 = 36
1/4 → 9/36
1/6 → 6/36
1/9 → 4/36
```

## 通分的两大用途

### 用途 1：比较异分母分数大小

`5/8 vs 7/12` → 通分 15/24 vs 14/24 → 5/8 > 7/12

### 用途 2：异分母分数加减

`2/3 + 5/6 = 4/6 + 5/6 = 9/6 = 3/2 = 1又1/2`（详见 fr-07）

## 常见陷阱

| 错误 | 正确 |
|------|------|
| 公分母用两数之积（如 8 × 12 = 96） | 不算错但麻烦。**优选最小公倍数 24** |
| 只乘分母没乘分子 | ❌ 改变了分数大小。**必须同时乘** |
| `2/3 + 5/6 = 4/6 + 5/6` 写成 = 9/12 | 通分后**分母不变**，不要相加 |
| 通分 1/4 和 1/6 用 lcm = 12 / 但写成 3/12 和 1/12（漏算） | 6 → 12 是 ×2，所以 1/6 = 2/12 不是 1/12 |
| 三个分数只通了两个 | 必须三个分母都化到同一个 |

## 与相邻概念关系

| 相邻概念 | 关系 |
|---------|------|
| 基本性质 | 通分的依据 |
| 最小公倍数 | 公分母的最佳选择 |
| 约分 | 通分是"向大"，约分是"向小"，方向相反 |
| 加减运算 | 异分母加减必须先通分 |
| 大小比较 | 通分是异分母比较的标准方法 |
