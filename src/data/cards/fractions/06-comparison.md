## 适用范围

- **讨论对象**：两个或多个分数（可同分母 / 同分子 / 都不同）
- **不讨论 / 排除**：含不同符号的（小学不深入）
- **最容易误入的边界**：以为"分母大分数就大"（恰恰相反）

## 三大基本规则

| 情形 | 比较方法 | 结论 |
|------|---------|------|
| **同分母** | 比分子 | **分子大的大** |
| **同分子** | 比分母 | **分母小的大** |
| **不同分母不同分子** | 通分 → 同分母再比 | 通分后比分子 |

> ⭐ **同分子时分母越小越大** —— 最违直觉，必须背

## 多角度逼近

1. **平均分角度**：分得份数越少，每份越大 → 分母越小，分数越大（同分子时）
2. **几何角度**：两个一样大的饼，切 2 块和切 3 块，每块大小不同
3. **小数 / 除法角度**：1/2 = 0.5；1/3 ≈ 0.333 → 0.5 > 0.333
4. **数轴角度**：在 0 到 1 之间画分点，越大越靠右

## 通用方法：通分比

`5/8 和 7/12` → lcm(8,12) = 24 → 15/24 vs 14/24 → **5/8 > 7/12**

## 高级方法（不通分快速比）

### 方法 1：化为小数比

`5/9 ≈ 0.556；7/12 ≈ 0.583` → 7/12 大

### 方法 2：和 1 比（"差到 1"）

适合接近 1 的真分数

`7/8 vs 9/10`：
- 1 − 7/8 = 1/8
- 1 − 9/10 = 1/10
- 1/10 < 1/8 → 离 1 近 → 9/10 大

### 方法 3：和"基准分数"比（如 1/2）

`3/7 vs 5/9` 都和 1/2 比：
- 3/7 < 1/2（因 3.5/7 = 1/2，3 < 3.5）
- 5/9 > 1/2（因 4.5/9 = 1/2，5 > 4.5）
- → 5/9 > 3/7

### 方法 4：交叉相乘（高年级）

`a/b vs c/d` → 比 `a×d` 与 `b×c` —— 大的那个对应的分数大（要求 b、d > 0）

例：`5/8 vs 7/12` → 5×12=60 vs 8×7=56 → 60 > 56 → **5/8 > 7/12**

## 真分数 vs 假分数

> 真分数 < 1 ≤ 假分数

任何真分数都比任何假分数小。

## 常见陷阱

| 错误 | 正确 |
|------|------|
| "分母大分数就大" | ❌ 错（同分子时**分母小才大**） |
| 异分母直接比分子 | 必须先**通分**或换其他方法 |
| 把 1/2 和 1/3 当成 2 和 3 比 | 分母数字大小**不等于**分数大小 |
| 通分时用了不是公倍数的数 | 通分后分母必须**真的相等** |
| 交叉相乘后混淆方向 | 交叉积大的对应原分数大（牢记 a×d ↔ a/b） |

## 与相邻概念关系

| 相邻概念 | 关系 |
|---------|------|
| 通分 | 通用比较方法的核心 |
| 基本性质 | 通分时不改变大小 |
| 小数 | 化小数也能比 |
| 1（单位"1"） | 和 1 比（差到 1 / 大到 1）是高级技巧 |
| 真假分数 | 真 < 1 ≤ 假，可一眼判断 |
