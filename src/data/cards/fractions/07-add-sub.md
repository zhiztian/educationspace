## 适用范围

- **讨论对象**：分数与分数 / 分数与整数 / 带分数 的加减
- **最容易误入的边界**：异分母直接加分子；带分数减时不会借位

## 三类规则

### 1. 同分母分数

> ⭐ **分母不变，分子相加减**

`2/7 + 3/7 = 5/7`
`6/11 − 4/11 = 2/11`

### 2. 异分母分数

> ⭐ **先通分，再按同分母规则**

`2/3 + 5/6 = 4/6 + 5/6 = 9/6 = 3/2 = 1又1/2`

### 3. 带分数

> ⭐ **整数加整数，分数加分数；不够减时整数借 1**

```
2又1/3 + 1又1/2
= (2+1) + (1/3 + 1/2)
= 3 + (2/6 + 3/6)
= 3 + 5/6
= 3又5/6
```

带分数减法（够减）：

```
3又5/6 − 1又1/2
= (3−1) + (5/6 − 3/6)
= 2 + 2/6
= 2又1/3
```

带分数减法（不够减，借位）：

```
3又1/4 − 1又3/4   ← 1/4 < 3/4，分数部分不够
= 2又5/4 − 1又3/4 ← 整数借 1 → 1 = 4/4 → 1/4 + 4/4 = 5/4
= 1又2/4
= 1又1/2
```

整数减带分数：

```
3 − 1又2/5
= 2又5/5 − 1又2/5  ← 把 3 写成 2 + 5/5
= 1又3/5
```

## 多角度逼近

1. **平均分角度**：份数同了，加减就是加减"取走的份数"
2. **几何角度**：把饼切相同份数，加 / 减一目了然
3. **数轴角度**：在数轴上跳"几分之几"
4. **化小数验算**：算完化小数验一下

## 计算后的整理（必做）

| 情况 | 处理 |
|------|------|
| 结果可约 | **约分**到最简（如 9/6 → 3/2） |
| 结果是假分数 | **化带分数**（如 3/2 → 1又1/2）—— 中国小学惯例 |
| 结果是 4/4 / 6/6 | **化为整数 1** |
| 计算中出现 0/n | = 0（保留 0 即可） |

## 常见陷阱

| 错误 | 正确 |
|------|------|
| `2/3 + 5/6 = 7/9`（分子加 + 分母加） | ❌ 大错。**分母通分，只加分子** |
| 异分母不通分直接加 | 必须先通分 |
| 带分数加完不化简（4/6） | 化为最简（2/3） |
| `3 − 1又2/5 = 2又2/5`（整数直接减） | ❌ 错。整数借 1 → `2又5/5 − 1又2/5 = 1又3/5` |
| `3又1/4 − 1又3/4 = 2又(1/4 − 3/4)` | 1/4 − 3/4 不能直接做（小学）→ 借位 |
| 假分数结果不化带分数 | 中国小学要求化带分数 |

## 与相邻概念关系

| 相邻概念 | 关系 |
|---------|------|
| 通分 | 异分母加减的前提 |
| 约分 | 加减结果要约到最简 |
| 假 / 带分数 | 结果常需互化 |
| 加减运算律 | 分数加法也满足交换 / 结合律 |
| 小数加减 | 同源思想：先"统一单位"再加减 |
