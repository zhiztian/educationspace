## 适用范围

- **讨论对象**：分子分母**不互质**的分数
- **不讨论 / 排除**：已经互质的分数（无需约分）
- **最容易误入的边界**：约一次没约到底；只除了分子或分母

## 精确定义

- **约分**：把一个分数化成与它**相等**、**分子分母都较小**的分数的过程
- **最简分数**：分子和分母**互质**（公因数只有 1）的分数

## 多角度逼近

1. **基本性质角度**：分子分母同时除以公因数（基本性质的"向小"应用）
2. **GCD 角度**：一次性除以最大公因数 → 直接到最简
3. **逐次约分角度**：每次找一个公因数除（适合公因数小的情况）
4. **质因数分解角度**：写出质因数，约掉相同的

## 两种约分方法

### 方法 1：用最大公因数（推荐高年级）

```
24/36 ─ gcd(24,36)=12 ─→ (24÷12)/(36÷12) = 2/3
```

### 方法 2：逐次约分

```
24/36 ─÷2─→ 12/18 ─÷2─→ 6/9 ─÷3─→ 2/3 ✓
```

> 任意公因数都行，最后化到最简即可

## 判断最简

> ⭐ **最简 ⇔ 分子分母互质**（gcd = 1）

| 情形 | 是否最简 |
|------|---------|
| 分子 = 1 | ✅ 必为最简 |
| 分子 / 分母 都是质数且不等 | ✅ 最简 |
| 分子分母**都是偶数** | ❌ 不是（至少能除 2） |
| 都以 5 / 0 结尾 | ❌ 不是（能除 5） |

## 整除特征（快速找公因数）

| 末位 | 能被 |
|------|------|
| 偶数 | 2 |
| 0 或 5 | 5 |
| 各位数字之和能被 3 整除 | 3 |
| 各位数字之和能被 9 整除 | 9 |

例：`126/216` → 各位 1+2+6=9 / 2+1+6=9 → 都能除 9 → 14/24 → 都偶 → 7/12 ✓

## 常见陷阱

| 错误 | 正确 |
|------|------|
| `7/14 ÷ 7 = 1/14` | ❌ 错。分母也要除 → 1/2 |
| 约一次就停（24/36 → 12/18） | 必须**约到最简** |
| "分母大就一定要约" | 17/100 已是最简（17 是质数，与 100 互质） |
| `8/16 = 1/8`（只除分子） | 错。同时除 → 1/2 |
| 把约分写成"等号链"算成减法 | 约分用 = 不用箭头 |

## 与相邻概念关系

| 相邻概念 | 关系 |
|---------|------|
| 基本性质 | 约分是性质的"向小"应用 |
| 最大公因数 | 约分一步到位的工具 |
| 互质 | 最简分数 ⇔ 分子分母互质 |
| 通分 | 通分 = 性质的"向大"应用，方向相反 |
| 化简结果 | 答案要求最简（除非题目特别说明） |
