## 适用范围

- **讨论对象**：表示**比 1 小或可拆成整数 + 小于 1 部分**的数
- **不讨论 / 排除**：分母不是 10/100/1000 的分数与小数互化（小学先讨论"十进制"分母）
- **最容易误入的边界**：把"小数位数"和"分母 0 的个数"对应不上；混 0.3 和 3/10

## 精确定义

**小数**：分母是 10、100、1000、…… 的**分数的另一种写法**。

```
0.3   = 3/10
0.07  = 7/100
0.123 = 123/1000
```

> ⭐ 规律：**几位小数 ↔ 分母是几个 0 的 10 的幂**
> - 一位小数 → 分母 10
> - 两位小数 → 分母 100
> - 三位小数 → 分母 1000

## 多角度逼近

1. **分数角度**：小数 = 十进制分数的简写
2. **数位角度**：每往右一位，单位变小 10 倍
3. **生活角度**：人民币（元 / 角 / 分）、长度（米 / 分米 / 厘米）、质量（千克 / 克）
4. **几何角度**：把单位长度平均分成 10 / 100 / 1000 份

## 数位顺序表（必备）

```
百   十   个 │ 十   百   千   万
位   位   位 │ 分   分   分   分
              位   位   位   位
                ─────小数部分→ 越来越小
```

例：`123.456`

| 数位 | 百位 | 十位 | 个位 | . | 十分位 | 百分位 | 千分位 |
|------|------|------|------|---|-------|-------|-------|
| 数字 | 1 | 2 | 3 | . | 4 | 5 | 6 |
| 计数单位 | 100 | 10 | 1 | | 1/10 | 1/100 | 1/1000 |

## 小数的两部分

```
   整数部分 . 小数部分
```

- **整数部分**：小数点**左**边（可以是 0，如 0.5）
- **小数部分**：小数点**右**边（小于 1）

## 读写要点

| 写法 | 读法 |
|------|------|
| 0.7 | 零点七 |
| 0.07 | 零点零七 |
| 25.302 | 二十五点三零二 |

> 整数部分按整数读；**小数部分一位一位地读**（不像整数那样按数位说"几十几"）

## 与分数互化（分母 10 / 100 / 1000）

| 分数 | 小数 |
|------|------|
| 3/10 | 0.3 |
| 7/100 | 0.07 |
| 13/100 | 0.13 |
| 9/1000 | 0.009 |
| 235/1000 | 0.235 |

> ⭐ 规则：**分母多少个 0 → 小数就有几位**

## 常见陷阱

| 错误 | 正确 |
|------|------|
| 0.07 = 7/10 | ❌ 错。两位小数 = 分母 100 → 7/100 |
| 25.302 读成"二十五点三百零二" | ❌ 错。小数部分一位位读：**三零二** |
| 0.5 = 1/5 | ❌ 错。0.5 = 5/10 = 1/2 |
| 0.1 ≠ 0.10 | ❌ 错。**相等**（小数末尾 0 不影响大小） |
| 把整数 0 当成小数（0 = 0.0 ?） | 0 既是整数也是小数；写成 0 即可 |

## 与相邻概念关系

| 相邻概念 | 关系 |
|---------|------|
| 分数 | 小数 = 分母 10 / 100 / … 的分数（互化见 dp-07） |
| 整数 | 整数是特殊的小数（0 位小数） |
| 数位顺序 | 整数与小数共用一张数位顺序表 |
| 计量单位 | 元 / 米 / 千克 → 与小数密切相关 |
| 百分数 | 百分数 = 小数 × 100% |
