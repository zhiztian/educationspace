## 适用范围

- **讨论对象**：两个或多个小数（含整数部分相同 / 不同）
- **最容易误入的边界**：用"位数多就大"判断（错误！）

## 精确比较步骤

```
1. 先比较整数部分
   ├─ 整数部分大的小数大
   └─ 整数部分相同 → 进入第 2 步

2. 比较十分位
   ├─ 十分位大的小数大
   └─ 十分位相同 → 进入第 3 步

3. 比较百分位 → 千分位 → ……
   一直比到不相等的那一位为止
```

> ⭐ **不要用位数多少判断大小**！0.7 > 0.65（虽然 0.65 位数多）

## 多角度逼近

1. **数位对齐角度**：把所有小数对齐小数点，从最高位开始一位一位比
2. **补 0 角度**：位数不同时末尾添 0 补齐再比
3. **分数角度**：化为同分母分数比（如 0.7 = 70/100；0.65 = 65/100）
4. **数轴角度**：在数轴上越往右越大

## 实例分析

### 例 1：整数部分不同

`5.99 vs 6.0` → 整数部分 5 < 6 → **6.0 > 5.99**

### 例 2：整数部分相同，位数不同

`0.7 vs 0.65` →

```
   0 . 7 0     ← 补齐
   0 . 6 5
       ↓
   十分位 7 > 6 → 0.7 > 0.65
```

### 例 3：多个小数排序

`0.0008、0.001、0.0009` 排序：

| 原数 | 补齐到四位 |
|------|---------|
| 0.0008 | 0.0008 |
| 0.001 | 0.0010 |
| 0.0009 | 0.0009 |

→ `0.0008 < 0.0009 < 0.001`

## 常见陷阱

| 错误 | 正确 |
|------|------|
| "小数位数多的就大"（0.65 > 0.7） | ❌ 大错。**先比整数 → 再比十分位 → ……** |
| 5.7 与 5.70 视为不等 | 末尾 0 不影响大小 → **相等** |
| 整数部分不同时还在比小数部分 | 整数部分**胜负已定**就不用看小数 |
| 比较时不对齐小数点 | 必须**对齐小数点**再一位位看 |
| 0.0009 < 0.001 没算对 | 补齐到 0.0010 → 0.0009 < 0.0010 ✓ |

## 与相邻概念关系

| 相邻概念 | 关系 |
|---------|------|
| 数位顺序 | 比较的依据 |
| 性质（末尾 0） | 不影响大小，可补齐位数 |
| 分数比较 | 思想类似 —— 统一基准再比 |
| 排序 | 先两两比较再整体排 |
| 估算 | 估算时也按这套方法判断 |
