## 适用范围

- **讨论对象**：所有有限小数
- **最容易误入的边界**：以为小数中间 / 整数部分前面的 0 也可以去掉

## 精确定义

> ⭐ **小数的基本性质**：小数的**末尾**添上 0 或去掉 0，小数大小**不变**。

例：`0.5 = 0.50 = 0.500`

> ⚠️ **关键限定**：只有"**小数末尾**"的 0 可以加 / 去；其他位置的 0 不能动。

## 多角度逼近

1. **分数角度**：0.3 = 3/10；0.30 = 30/100 → 约分 = 3/10 → 等
2. **数位角度**：末尾 0 表示"那一位上没有"，可省
3. **生活角度**：1.5 元 = 1.50 元（写成 1 元 5 角 = 1 元 50 分）
4. **化简角度**：把不必要的 0 去掉让数更简洁

## 哪些 0 能去 / 不能去

| 0 的位置 | 能去吗 | 例 |
|---------|-------|----|
| 小数末尾 | ✅ 能 | 0.300 → 0.3 |
| 小数中间 | ❌ 不能 | 0.305 不能去 → 0.35（变大了） |
| 整数部分中间 | ❌ 不能 | 102.5 不能去 → 12.5 |
| 整数部分末尾（小数点前） | ❌ 不能 | 30.5 ≠ 3.5 |
| 整数 0 写成 0.0 | ✅ 等价 | 0 = 0.0 = 0.00 |

## 应用一：化简小数

把末尾 0 去掉 → 化简

| 原数 | 化简 |
|------|------|
| 0.30 | 0.3 |
| 0.500 | 0.5 |
| 5.020 | 5.02 |
| 100.0 | 100 |

## 应用二：改写小数（升 / 降位数）

把 0.5 改写成两位小数 → 末尾添 0 → 0.50

## 小数点移动 ↔ 大小变化

> ⭐ 这是另一条独立规律 —— 不是"基本性质"

| 移动方向 | 移动位数 | 大小变化 |
|---------|---------|---------|
| 向**右**移 1 位 | × 10 |
| 向**右**移 2 位 | × 100 |
| 向**右**移 3 位 | × 1000 |
| 向**左**移 1 位 | ÷ 10 |
| 向**左**移 2 位 | ÷ 100 |
| 向**左**移 3 位 | ÷ 1000 |

例：
- 4.5 → 45 （右 1 位，× 10）
- 4.5 → 0.045 （左 2 位，÷ 100）
- 0.3 → 30 （右 2 位，× 100）

## 常见陷阱

| 错误 | 正确 |
|------|------|
| 0.03 = 0.3（认为小数中间 0 也能去） | ❌ 错。**只有末尾 0** 能去 |
| 30.5 = 3.5（去整数部分的 0） | ❌ 错 |
| "末尾 0 既能加又能去" 误认为"加 0 后小数变大" | 加在末尾不变（0.5 = 0.50） |
| 把小数点移动当成"性质"应用 | 移动改变大小（× / ÷ 10 / 100 / …） |
| 0.5 → 0.50 当成"扩大 10 倍" | ❌ 错。0.5 = 0.50，没变 |

## 与相邻概念关系

| 相邻概念 | 关系 |
|---------|------|
| 分数基本性质 | 都是"形式变 / 大小不变"的核心规律 |
| 化简 | 性质的常见应用 |
| 单位换算 | 4.5 米 → 450 厘米（小数点右移 2 位 = ×100） |
| 大小比较 | 末尾 0 不影响比较（0.5 = 0.50） |
| 估算 | 化简后判断大小更直观 |
