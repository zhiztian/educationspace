## 适用范围

- **讨论对象**：小数 × / ÷ 整数 / 小数
- **最容易误入的边界**：乘法忘点小数点 / 点错位置；除法忘"被除数同步右移"

## 小数乘法

> ⭐ **三步法**：
> 1. **按整数乘法算积**（忽略小数点）
> 2. 看两个因数共有几位小数（位数相加）
> 3. 在积上**从右往左**数同样位数，点上小数点

例：`0.3 × 0.5`

```
   3 × 5 = 15
   两因数共 2 位小数 → 从右往左数 2 位
   → 0.15
```

例：`1.25 × 0.4`

```
   125 × 4 = 500
   共 3 位小数 → 0.500 → 化简 0.5
```

### 整数 × 小数

`6 × 0.8 = 4.8`（整数 0 位 + 小数 1 位 = 1 位小数）

### 末尾 0 与积的位数

| 情况 | 处理 |
|------|------|
| 积末尾有 0 | 先点小数点再化简（如 0.500 → 0.5） |
| 整数乘积位数不够 | 在前面**补 0** 占位（如 3 × 0.02 = 0.06） |

## 小数除法

### 类型 1：除数是整数

> 直接按整数除法做，**商的小数点和被除数的小数点对齐**

例：`12.6 ÷ 4`

```
       3 . 1 5
    ─────────
  4 │ 1 2 . 6 0
      1 2
      ─────
         . 6 0    ← 0.6 不够 4 除 → 商 0.0..；继续添 0
           4
         ─────
           2 0
           2 0
           ─────
              0
```

→ `12.6 ÷ 4 = 3.15`

### 类型 2：除数是小数

> ⭐ **关键**：用**商不变性质**把除数变成整数
>
> 除数小数点向右移几位，被除数小数点也向右移几位（不够就补 0）；然后按"除数是整数"的方法做

例：`1.35 ÷ 0.27`

```
   除数 0.27 → 27（小数点右移 2 位）
   被除数 1.35 → 135（同步右移 2 位）
   → 135 ÷ 27 = 5
```

例：`5.6 ÷ 0.8`

```
   0.8 → 8（右移 1 位）
   5.6 → 56（右移 1 位）
   → 56 ÷ 8 = 7
```

例：`9 ÷ 0.4` → 90 ÷ 4 = 22.5

## 多角度逼近

1. **整数化思想**：先去小数点变整数，最后再补回去
2. **商不变性质**：除法中被除数与除数同时 × 同一个数
3. **几何角度**：长 × 宽 = 面积（含小数）
4. **生活角度**：单价 × 数量 = 总价；总价 ÷ 单价 = 数量

## 常见陷阱

| 错误 | 正确 |
|------|------|
| `0.3 × 0.5 = 1.5` | ❌ 错。3 × 5 = 15；点 2 位 → **0.15** |
| 乘法忘点小数点 | 看两因数共几位小数，从右往左数 |
| 除数是小数时只移除数不移被除数 | ❌ 错。**必须同步右移** |
| `1.35 ÷ 0.27 = 0.5` | ❌ 错。同步右移 2 位 → 135 ÷ 27 = **5** |
| 商小数点不和被除数对齐 | 除数是整数时**必须对齐** |
| 末尾 0 不化简 | 5.00 → 5；3.50 → 3.5 |
