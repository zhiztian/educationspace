## 适用范围

- **讨论对象**：含小数的加减运算（含整数与小数混合）
- **最容易误入的边界**：末位对齐（错）→ 应小数点对齐；位数不同时不补 0

## 核心规则

> ⭐ **小数点对齐 = 相同数位对齐**

不要把"末位对齐"和"小数点对齐"搞混 —— 在小数里这两条**完全不同**！

```
整数加减：末位对齐
小数加减：小数点对齐
```

## 多角度逼近

1. **数位思想**：相同数位才能加减（个位加个位、十分位加十分位）
2. **分数角度**：加减前要"统一单位 / 通分母"
3. **生活角度**：5 元 + 3.5 元 = 5.0 元 + 3.5 元 = 8.5 元
4. **几何角度**：长度相加要单位一致（米 + 米；分米 + 分米）

## 竖式步骤

### 例 1：5.6 + 3.27

```
     5 . 6 0          ← 5.6 末尾添 0 → 5.60
   + 3 . 2 7
   ─────────
     8 . 8 7
```

### 例 2：8.5 − 3.27

```
     8 . 5 0          ← 补 0
   − 3 . 2 7
   ─────────
     5 . 2 3
```

### 例 3：12 − 4.7

```
     1 2 . 0          ← 12 写成 12.0
   −    4 . 7
   ─────────
        7 . 3
```

## 检查 / 化简

| 情况 | 处理 |
|------|------|
| 结果末尾有 0 | 通常**化简**（如 7.30 → 7.3） |
| 结果是整数（如 1.0） | 写成 1 |
| 进位 / 退位 | 与整数加减一样处理 |

## 验算

| 类型 | 验算公式 |
|------|---------|
| 加法 | 用减法（和 − 一个加数 = 另一个加数） |
| 减法 | 用加法（差 + 减数 = 被减数） |

## 常见陷阱

| 错误 | 正确 |
|------|------|
| **末位对齐**（5.6 与 3.27 末尾对齐） | ❌ 大错！必须**小数点对齐** |
| 12 − 4.7 算成 12 − 4 = 8 | ❌ 错。要补 0 → 12.0 − 4.7 = 7.3 |
| 0.8 + 0.2 写成 0.10 | ❌ 错。是 1.0 = 1（不是 0.10） |
| 漏掉小数点（结果忘点） | 答案必须带小数点 |
| 小数末尾 0 没化简 | 5.30 → 5.3（建议化简） |

## 估算（验答）

`8.5 − 3.27` → 估算 8 − 3 = 5 → 精算 5.23 ≈ 5 ✓

## 与相邻概念关系

| 相邻概念 | 关系 |
|---------|------|
| 整数加减 | 数位对齐思想一致 |
| 分数加减 | 都要先"统一基准"才能加减 |
| 小数性质 | 末尾添 / 去 0 用于对齐与化简 |
| 元 / 角 / 分 | 1 元 5 角 + 3 角 = 1.5 + 0.3 = 1.8 元 |
| 估算 | 加减估算到整数判断结果合理性 |
