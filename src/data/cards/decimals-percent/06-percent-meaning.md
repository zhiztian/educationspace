## 适用范围

- **讨论对象**：表示**两数之比 / 倍数关系**的数（统计、增长率、合格率、命中率等）
- **不讨论 / 排除**：带单位的具体数量（百分数**不能带单位**）
- **最容易误入的边界**：把"占百分之几"和"是百分之几"等同；忘了百分数没单位

## 精确定义

**百分数**：表示一个数**是另一个数的百分之几**的数。

```
   a%  =  a / 100   表示 a 是 100 的几分之几（即比率）
```

> ⭐ **百分数的本质：两数之比**（不带单位）

## 多角度逼近

1. **分数角度**：百分数 = **分母为 100 的特殊分数**
2. **小数角度**：a% = a ÷ 100 = 0.0a（小数点左移 2 位）
3. **比率角度**：表示"是 / 占 / 比" —— 描述关系而非具体量
4. **生活角度**：合格率 / 出勤率 / 折扣 / 利率 / 命中率 —— 全是百分数

## 百分数 vs 分数（关键区别）

| 特征 | 分数 | 百分数 |
|------|------|--------|
| 是否带单位 | ✅ 可带（2/3 米） | ❌ 不带 |
| 表示数量 | ✅ 可以 | ❌ 只表示比率 |
| 表示比率 | ✅ 可以 | ✅ 可以 |
| 分母 | 任意 | **必为 100** |
| 是否 ≥ 1 | 真 / 假分数 | 可 ≥ 100% |

## 常见百分数对应

| 百分数 | 分数 | 小数 |
|-------|------|------|
| 25% | 1/4 | 0.25 |
| 50% | 1/2 | 0.5 |
| 75% | 3/4 | 0.75 |
| 20% | 1/5 | 0.2 |
| 10% | 1/10 | 0.1 |
| 12.5% | 1/8 | 0.125 |
| 100% | 1 | 1 |
| 200% | 2 | 2 |

## 单位"1"在百分数中的关键作用

> ⭐ **百分数总是"是 / 占 / 比 X 的百分之几"**，X 就是单位"1"

例：
- "今年比去年增长 20%" → **去年**是单位"1"
- "甲是乙的 80%" → **乙**是单位"1"
- "男生占全班 40%" → **全班**是单位"1"

## 大于 100% 的百分数

| 表达 | 含义 |
|------|------|
| 120% | 是单位"1"的 1.2 倍（增长 20%） |
| 200% | 是单位"1"的 2 倍（增长 100%） |
| 增长率 30% | 增加部分是原来的 30% |

## 常见陷阱

| 错误 | 正确 |
|------|------|
| "一根绳子长 25%" | ❌ 错。**百分数不带单位** |
| "% 后面可以写单位" | ❌ 错。% 本身就是"分母 100" |
| 把"甲比乙多 20%"和"乙比甲少 20%"等同 | ❌ 错。两者**单位"1"不同**，不一样 |
| "增长 200%"和"增长到 200%"等同 | 不一样。增长 200% 是变成 3 倍；增长到 200% 是变成 2 倍 |
| 25% 写成 25/100 后不约分 | 一般要约简为 1/4 |
| 0.25 = 25%（漏 % 号） | 漏 % 号会变成数值 25/100 ↔ 25 |

## 与相邻概念关系

| 相邻概念 | 关系 |
|---------|------|
| 分数 | 百分数 = 分母 100 的特殊分数 |
| 小数 | 百分数 ↔ 小数 互化 |
| 比 | 百分数也可写为 a:100 |
| 单位"1" | 百分数表达必须明确单位"1" |
| 折扣 / 利率 | 折扣 = 现价 / 原价 × 100% |
