## 适用范围

- **讨论对象**：分数 / 小数 / 百分数 三种数互相转化
- **最容易误入的边界**：忘乘 100% / 忘除 100；化简没到最简

## 互化总图

```
            ÷ 100  / 去 %
        ┌────────────────┐
        ↓                │
     小数 ─→ × 100% / 加 % → 百分数
        │
        ├ ÷ 1 → 分子取小数；分母取 10^n
        ↓
     分数 ←──── 互化（先化小数）─── 百分数
```

## 三组规则

### 1. 小数 ↔ 百分数

| 方向 | 方法 |
|------|------|
| 小数 → 百分数 | × 100%（小数点**右移 2 位**，加 %） |
| 百分数 → 小数 | ÷ 100（去掉 %，小数点**左移 2 位**） |

例：
- 0.35 → 35%
- 0.07 → 7%
- 1.2 → 120%
- 35% → 0.35
- 7% → 0.07

### 2. 分数 ↔ 小数

| 方向 | 方法 |
|------|------|
| 分数 → 小数 | 分子 ÷ 分母（除不尽按要求保留几位） |
| 小数 → 分数 | 写成 分子/10^n（n = 小数位数）→ 约分 |

例：
- 3/4 = 3 ÷ 4 = 0.75
- 1/3 = 1 ÷ 3 = 0.333... ≈ 0.333（保留三位）
- 0.125 = 125/1000 = 1/8
- 0.6 = 6/10 = 3/5

### 3. 分数 ↔ 百分数

> 通用方法：**先化小数，再化百分数**（或反过来）

| 方向 | 方法 |
|------|------|
| 分数 → 百分数 | 分子 ÷ 分母 → × 100% |
| 百分数 → 分数 | 去 % → / 100 → 约分 |

例：
- 3/4 = 0.75 = 75%
- 1/8 = 0.125 = 12.5%
- 1/3 ≈ 0.333 = 33.3%（保留 1 位）
- 25% = 25/100 = 1/4
- 12.5% = 125/1000 = 1/8

## 互化的实际应用

### 比较大小（统一形式）

`0.6, 65%, 5/8` → 全化为百分数 → `60%, 65%, 62.5%` → `0.6 < 5/8 < 65%`

### 简化计算

如 1/4 × 84 → 比 25% × 84 容易（也可 84 ÷ 4 = 21）

### 答题规范

题目要求"用百分数表示" → 必须化为百分数（不能用分数答）

## 常见陷阱

| 错误 | 正确 |
|------|------|
| 0.35 化为百分数写成 0.35% | ❌ 错。要 × 100% → **35%** |
| 7% 化为小数写成 7.0 | ❌ 错。要 ÷ 100 → **0.07** |
| 1/3 = 33%（漏 .3...）  | 1/3 ≈ 33.3%（按要求保留） |
| 0.125 化分数后不化简 | 125/1000 → **1/8** |
| 12.5% 化分数 → 12.5/100（保留小数） | 应化整数：125/1000 → **1/8** |

## 与相邻概念关系

| 相邻概念 | 关系 |
|---------|------|
| 单位"1" | 百分数总是相对单位"1"，互化不改变这点 |
| 大小比较 | 三种形式互化后比较是常用方法 |
| 应用题 | 折扣 / 利率题中三种形式自由切换 |
| 化简 | 互化结果**默认要约简到最简** |
| 估算 | 1/3 ≈ 33%、2/3 ≈ 67% 是常用估算锚点 |
