## 适用范围

- **讨论对象**：体积（三维）、容积（容器内部容量）
- **最容易误入的边界**：进率算 100 而非 1000；体积容积混用

## 精确定义

> ⭐ **体积**：物体所占空间大小（外测）
> ⭐ **容积**：容器能容纳物体的体积（内测）

## 多角度逼近

1. **单位角度**：m³ / dm³ / cm³ / mm³ + 容积特用 L / mL
2. **进率角度**：相邻 ×1000（最大！）
3. **场景角度**：根据大小选合适单位
4. **生活角度**：饮料 mL，浴缸 L，房间 m³

## 体积单位（必背）

| 单位 | 缩写 | 等价 | 生活感觉 |
|------|------|------|---------|
| 立方米 | m³ | 1000 dm³ | 一个 1 m 边长的箱子 |
| 立方分米 | dm³ | 1000 cm³ | = 1 升 = 一瓶大可乐 |
| 立方厘米 | cm³ | 1000 mm³ | = 1 毫升 = 一个骰子 |
| 立方毫米 | mm³ | — | 极小 |

## 容积特用单位

| 单位 | 等价 |
|------|------|
| 升（L） | = 1 dm³ = 1000 mL |
| 毫升（mL） | = 1 cm³ |

> ⭐ **1 升 = 1 dm³ = 1000 毫升 = 1000 cm³**（必背）

## 进率口诀

```
m³  →  dm³  →  cm³  →  mm³
   1000   1000   1000

L → mL：1000
1 dm³ = 1 L
```

## 为什么进率是 1000

> 体积 = 长 × 宽 × 高（三个长度相乘）
> 长度进率 10 → 体积进率 = 10³ = **1000**

## 单位换算

### 大 → 小：乘 1000

```
   3 m³ = 3 × 1000 = 3000 dm³
   5 dm³ = 5 × 1000 = 5000 cm³
   2 L = 2 × 1000 = 2000 mL
```

### 小 → 大：除以 1000

```
   5000 cm³ = 5 dm³ = 5 L
   1500 mL = 1.5 L
```

## 单位选择

| 物体 | 合适单位 |
|------|---------|
| 一瓶矿泉水 | mL（500 mL） |
| 一袋牛奶 | mL（250 mL） |
| 一桶油 | L（5 L） |
| 一个浴缸 | L（200 L） |
| 一个泳池 | m³ |
| 一颗糖 | cm³ |

## 体积 vs 容积

| 项目 | 体积 | 容积 |
|------|------|------|
| 测什么 | 物体占空间 | 容器内能装多少 |
| 用谁 | 实心物体 | 容器（杯 / 盒 / 桶） |
| 单位 | cm³ / m³ | L / mL（也可 cm³ / m³） |
| 关系 | 同一容器：**容积 < 体积**（含壁厚） |

> 容器**外壁尺寸**算体积；**内壁尺寸**算容积

## 进率对比表（终极对照）

| 维度 | 单位例 | 进率 |
|------|-------|------|
| 长度 | m / cm | 10 |
| 面积 | m² / cm² | **100** |
| 体积 | m³ / cm³ | **1000** |

## 常见陷阱

| 错误 | 正确 |
|------|------|
| 1 m³ = 100 dm³ | ❌ 错。**1000 dm³** |
| 1 dm³ = 100 cm³ | ❌ 错。**1000 cm³** |
| 1 L = 100 mL | ❌ 错。**1000 mL** |
| 1 L = 1 cm³ | ❌ 错。1 L = **1000 cm³** = 1 dm³ |
| 容积 = 体积（都一样） | 容器**容积 ≤ 体积** |
| 矿泉水瓶 500 L | ❌ 错。500 **mL** |

## 与相邻概念关系

| 相邻概念 | 关系 |
|---------|------|
| 长度 / 面积单位 | 进率分别是 10 / 100 / 1000 |
| 立体图形体积 | 长方体 / 圆柱 / 圆锥体积都用 cm³ / m³ |
| 排水法 | 测不规则物体体积 |
| 烹饪 / 化学 | 常用 mL（容积）单位 |
| 比例 | 相似立体体积比 = 边长比的立方 |
